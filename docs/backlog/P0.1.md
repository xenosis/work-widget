# P0.1 — 스택 결정 및 폴더 구조 설계

## 목적

프로젝트의 기술 스택을 확정하고, 코드를 구성할 폴더 구조를 설계한다. 이는 후속 작업들이 일관된 구조 내에서 진행될 수 있도록 하는 초기 결정 단계다.

## 쉬운 설명

애플리케이션을 만들기 위해 어떤 도구와 언어를 사용할지 결정하는 것이다. 이 프로젝트는 Electron(Windows 앱 만드는 도구) + Vite(빠른 빌드 도구) + React(화면 그리기)를 선택했다. 또한 폴더를 electron/(메인 프로세스)과 src/(렌더러)로 나누어 관리하기로 결정했다.

## 필요한 입력

- 요구사항 문서(work-widget-requirements.md) Part A — 사용 환경(Windows), 기술 스택(Electron 추천)
- 개발자의 기존 경험과 성과 (Flutter, React Native+Expo 등과의 중복성)

## 결과물

- 스택 결정: Electron (React/JS) + Vite + electron-builder
- 폴더 구조 설계: `electron/`(메인 프로세스), `src/`(렌더러), `docs/`(문서) 등의 구성
