# P0.1 — 스택 결정 및 폴더 구조 설계

## 목적

이 프로젝트에서 사용할 기술 스택(Electron + Vite + React)을 확정하고, 메인 프로세스(electron/)와 렌더러(src/) 폴더를 분리한 프로젝트 구조를 설계한다. 이후 모든 개발의 기초가 되는 아키텍처 결정이다.

## 쉬운 설명

어떤 기술을 써서 이 앱을 만들지 결정하고, 코드를 어디에 어떤 폴더에 둘지 정하는 작업이다. Windows 위젯 형태로 동작하려면 Electron을 써야 하고, React로 UI를 만들고, Vite로 빌드하기로 결정했다는 뜻이다.

## 필요한 입력

- 요구사항 문서(work-widget-requirements.md) Part A: 기술 스택이 언급된 부분
- 개발자의 기술 스택 선호도/경험

## 결과물

- 확정된 기술 스택: Electron (메인) + React (렌더러) + Vite (빌드)
- 폴더 구조 설계: electron/ (메인 프로세스), src/ (렌더러), scripts/ (유틸리티) 등
