# P0.2 — 빌드 설정 파일 작성

## 목적

Vite 번들러, Electron 앱 패키징, npm 스크립트 등을 설정하는 파일들을 작성하여 npm run dev/build/dist 명령이 정상 작동하도록 한다.

## 쉬운 설명

package.json에 의존성과 빌드 명령을 정의하고, vite.config.js에서 React/JSX를 어떻게 번들링할지 설정하고, index.html을 만들어서 전체 빌드 파이프라인이 작동하게 하는 것이다.

## 필요한 입력

- Node.js 및 npm 설치
- Electron, Vite, React, electron-builder 패키지 이해

## 결과물

- package.json (의존성, npm 스크립트: dev/build/dist, electron-builder 설정)
- vite.config.js (React/JSX 번들링 설정, base: './' 지정)
- index.html (렌더러 진입점)
- .gitignore (node_modules, dist 등 제외)

## 선행 작업

- P0.1: 스택 결정

## 수행 순서에서의 위치

P0.2는 P0.1 이후에 실행되며, P0.3(데이터 저장 계층)과 함께 병렬 진행 가능하다. P0.2와 P0.3이 모두 완료되어야 P0.6(npm install)을 시작할 수 있다.

## done_when을 확인하는 방법

네 파일(package.json, vite.config.js, index.html, .gitignore)이 모두 작성되었고, npm install을 실행했을 때 에러 없이 진행되는지 확인한다.
