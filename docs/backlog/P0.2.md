# P0.2 — 빌드 설정 파일 작성

## 목적

프로젝트가 빌드되고 실행될 수 있도록 필수 설정 파일들을 작성한다. npm이 어떤 의존성을 설치할지, Vite가 어떻게 React 코드를 번들할지, index.html이 어디에서 렌더러를 불러올지 등을 정의한다.

## 쉬운 설명

요리를 하기 전에 주방 도구(냄비, 프라이팬)를 꺼내고 레시피를 확인하는 것처럼, 코드를 실행하기 전에 도구가 어떻게 작동할지 설정 파일에 적어둬야 한다. 이 작업에서 작성하는 파일들은 package.json, vite.config.js, index.html, .gitignore이다.

## 필요한 입력

- P0.1에서 확정된 스택 정보 (Electron, React, Vite 선택)
- Node.js의 npm 버전 확인 (일반적으로 14.x 이상)
- 프로젝트명, 버전 정보 (예: "work-widget", "0.1.0")
- 요구사항 문서 검토 완료
