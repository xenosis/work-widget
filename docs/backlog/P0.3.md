# P0.3 — 데이터 저장 계층(dataStore.js) 작성

## 목적

로컬 JSON 파일(data.json)을 읽고 쓰는 기본 함수들을 작성하여, 앱의 모든 데이터(프로젝트, 할일, 메모, 일정)가 영구저장될 수 있도록 한다.

## 쉬운 설명

유저의 개인 데이터 폴더(app.getPath('userData'))에 data.json 파일을 만들고, 그 안에서 4개 배열(projects, todos, memos, schedules)을 읽고 쓰는 loadData/saveData 함수를 만드는 것이다. 파일이 없거나 형식이 잘못되었을 때는 기본 빈 구조로 자동 생성된다.

## 필요한 입력

- Electron 앱의 userData 경로 접근 권한
- 요구사항 문서 B3: 데이터 스키마 정의 (Project/Todo/Memo/Schedule 필드)
- Node.js fs 모듈을 이용한 파일 읽기/쓰기

## 결과물

electron/dataStore.js 파일에 다음이 포함됨:
- loadData() 함수: data.json을 읽고 파싱, 실패 시 기본값 반환
- saveData(data) 함수: 데이터를 data.json에 쓰기
- 자동 생성 기본 구조: { projects: [], todos: [], memos: [], schedules: [] }

3. saveData({...}) 호출 후 파일이 올바른 JSON 형식으로 저장되는지 확인
