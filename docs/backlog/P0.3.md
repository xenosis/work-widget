# P0.3 — 데이터 저장 계층(dataStore.js) 작성

## 목적

프로젝트의 상태(프로젝트, 할일, 메모, 일정)를 파일에서 읽고 쓰는 기본 기능을 구현한다. 앱이 시작될 때 data.json을 메모리로 로드하고, 사용자가 데이터를 변경할 때마다 저장한다.

## 쉬운 설명

스마트폰 앱이 기록(연락처, 메모)을 폰의 저장소에 저장했다가 나중에 불러오는 것처럼, 이 위젯도 프로젝트/할일/메모/일정을 로컬 파일에 저장했다가 필요할 때 읽어야 한다. 이 작업에서 구현하는 loadData()와 saveData() 함수가 그 역할을 한다.

## 필요한 입력

- Node.js의 `fs` 모듈 (기본 제공)
- Electron의 `app.getPath('userData')` API 이해
- work-widget-requirements.md의 B3 섹션 (데이터 스키마) 검토

## 결과물

`electron/dataStore.js` 파일: loadData(), saveData() 함수, 기본 스키마 정의 (projects: [], todos: [], memos: [], schedules: [])
