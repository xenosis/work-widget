# P0.4 — Electron 메인 프로세스(main.js, preload.js) 작성

## 목적

Electron 메인 프로세스를 구현해서 앱 창을 띄우고, Windows 트레이에 아이콘을 표시하고, 렌더러 프로세스(React)와 안전하게 데이터를 주고받기 위한 IPC 채널을 설정한다.

## 쉬운 설명

Electron은 두 부분으로 작동한다: 메인 프로세스(앱의 "뇌", 창 관리)와 렌더러 프로세스(React가 실행되는 곳). 이 작업에서 main.js에는 창 생성, 트레이 아이콘, 닫기=숨김 처리를 구현하고, preload.js에는 렌더러가 안전하게 접근할 IPC API를 노출한다.

## 필요한 입력

- P0.3에서 작성한 dataStore.js (loadData, saveData 함수)
- Electron 라이브러리의 BrowserWindow, Tray, ipcMain, contextBridge API 이해
- work-widget-requirements.md의 B5 섹션 (위젯 운영 동작) 검토

## 결과물

두 개의 파일: electron/main.js (BrowserWindow, Tray, IPC 핸들러), electron/preload.js (contextBridge 기반 API)

## 선행 작업

**P0.3** — dataStore.js 완료.

## 수행 순서에서의 위치

P0.3 후, P0.5(렌더러) 이전. 렌더러가 IPC를 통해 메인과 통신하므로 메인이 먼저 준비되어야 한다.
