# P0.4 — Electron 메인 프로세스(main.js, preload.js) 작성

## 목적

Electron의 메인 프로세스에서 BrowserWindow를 생성하고, 트레이 아이콘을 만들고, 렌더러와의 IPC(프로세스 간 통신) 핸들러를 등록한다. 또한 B5.1대로 창 닫기 시 숨김 처리와 시스템 종료 시 앱 종료를 구현한다.

## 쉬운 설명

Electron의 진입점인 main.js에서 창을 띄우고, 시스템 트레이에 아이콘을 만들고, 렌더러가 요청하는 데이터 로드/저장을 IPC로 받아서 처리하는 기본 틀을 만드는 것이다. preload.js에서는 contextBridge를 통해 안전한 API만 렌더러에 노출한다.

## 필요한 입력

- P0.3 완료 (loadData/saveData 함수 존재)
- 요구사항 B5 (창 닫기=숨김, 별도 종료 메뉴 없음 등)
- Electron API 문서 (BrowserWindow, Tray, ipcMain, contextBridge 등)

## 결과물

- electron/main.js: BrowserWindow, Tray, ipcMain.handle(data:load, data:save), close='hide', 종료 로직
- electron/preload.js: contextBridge 기반 window.api.loadData/saveData 노출

## 선행 작업

- P0.3: 데이터 저장 계층

## 수행 순서에서의 위치

P0.4는 P0.3 후에 실행되며, P0.5(렌더러 뼈대)와 함께 병렬로 진행 가능하다. P0.4와 P0.5가 모두 완료되어야 P0.8(실제 기동 테스트)을 시작할 수 있다.

## done_when을 확인하는 방법

1. electron/main.js와 electron/preload.js 파일이 작성되었는지 확인
2. main.js에 BrowserWindow, Tray, ipcMain.handle 관련 코드 확인
3. 창 close 이벤트가 hide()를 호출하고 destroy가 아님을 확인
4. before-quit 또는 Windows session-end에 종료 로직 확인
