# P0.5 — React 렌더러 뼈대 작성

## 목적

React 컴포넌트 구조를 작성해서 앱의 화면을 그린다. 5개 주요 화면(대시보드/프로젝트/할일전체/메모/일정)을 placeholder로 만들고, 사이드바를 통해 화면을 전환하는 기본 라우팅을 구현한다.

## 쉬운 설명

빈 집을 임대했을 때 먼저 벽, 문, 기본 배치를 만드는 것처럼, React UI도 먼저 구조를 만들고 내용은 나중에 채운다. 이 작업에서는 사이드바에서 메뉴를 클릭하면 화면이 전환되는 기본 레이아웃만 구현한다.

## 필요한 입력

- React 기본 개념 (functional components, useState, JSX)
- P0.2의 vite.config.js와 index.html (렌더러 진입 경로)
- 사이드바 메뉴 항목명과 순서 (work-widget-requirements.md B1.3)

## 결과물

src/ 폴더: main.jsx, App.jsx, Sidebar.jsx, screens/(Dashboard/Projects/Todos/Memos/Schedule.jsx), 기본 레이아웃 CSS
