# P0.5 — React 렌더러 뼈대 작성

## 목적

React를 사용한 렌더러 폴더(src/)에 기본 레이아웃과 5개 화면의 placeholder 컴포넌트를 만들어, 사이드바를 통해 화면 간 이동이 가능한 상태까지 구성한다.

## 쉬운 설명

src/main.jsx 진입점부터 App.jsx, Sidebar.jsx(네비게이션 메뉴 5개), 그리고 각 화면의 placeholder 컴포넌트(Dashboard, Projects, Todos, Memos, Schedule)를 만드는 것이다. 기본 CSS로 레이아웃만 잡아두고 각 화면의 실제 기능은 나중에 채운다.

## 필요한 입력

- 요구사항 B1.3: 사이드바 메뉴 구성 (대시보드/프로젝트/할일전체/메모/일정)
- React 함수형 컴포넌트 및 useState, useEffect 기본 이해

## 결과물

- src/main.jsx: React 앱 진입점
- src/App.jsx: 화면 전환 로직 (useState로 currentScreen 상태 관리)
- src/Sidebar.jsx: 5개 메뉴 버튼
- src/screens/: Dashboard, Projects, Todos, Memos, Schedule (placeholder)
- src/index.css: 기본 레이아웃 스타일

## 선행 작업

- P0.2: 빌드 설정 — index.html과 vite.config.js가 있어야 React가 번들링됨

## 수행 순서에서의 위치

P0.5는 P0.2 후에 실행되며, P0.4(메인 프로세스)와 병렬 진행 가능하다. P0.5 완료 후 P0.7(vite build 테스트)과 P0.8(실제 기동)을 순차 실행한다.

## done_when을 확인하는 방법

3. 각 화면에 최소한 placeholder 텍스트나 제목 표시
