# P0.6 — npm install 의존성 설치 완료

## 목적

npm install을 성공적으로 실행해서 프로젝트에 필요한 모든 의존성 패키지(electron, react, vite 등)를 다운로드하고 설치한다. 특히 Electron 바이너리를 올바르게 다운로드해야 한다.

## 쉬운 설명

프로젝트에 필요한 모든 도구를 설치하는 단계다. package.json에 나열된 라이브러리들을 npm 저장소에서 다운로드해서 node_modules/ 폴더에 설치한다. 특히 Electron은 설치 후 postinstall 스크립트로 바이너리를 다운로드하는데, 이것이 성공적으로 완료되어야 앱을 실행할 수 있다.

## 필요한 입력

- P0.2에서 작성한 package.json (의존성 목록 포함)
- npm 6.x 이상 설치
- 인터넷 연결 (npm 패키지 저장소 접근)
- 디스크 공간 최소 2-3GB 여유

## 결과물

- node_modules/ 디렉토리 (모든 의존성 설치)
- node_modules/electron/dist/electron.exe (Electron 바이너리)
- package-lock.json (설치 스냅샷)

## 선행 작업

**P0.2** — package.json 작성 완료.
