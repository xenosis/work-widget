# P0.6 — npm install 의존성 설치 완료

## 목적

npm install 명령이 모든 의존성을 성공적으로 설치하고, 특히 Electron 바이너리(node_modules/electron/dist/)가 정상적으로 다운로드되어 앱을 실행할 수 있는 상태가 되도록 한다.

## 쉬운 설명

프로젝트의 모든 npm 패키지(Electron, React, Vite 등)가 설치되는 작업이다. 초기 시도 시 Windows 보안 소프트웨어가 디렉토리 핸들을 잠궈 재설치가 반복 실패했지만, PC 재부팅 후 정상 완료되었다. 지금은 설치가 성공적으로 완료되었고, Electron 바이너리(v31.7.7)가 node_modules/electron/dist/ 아래에 존재한다.

## 필요한 입력

- package.json과 package-lock.json이 작성된 상태 (P0.2 완료)
- npm 및 Node.js 설치
- 네트워크 연결 (Electron 바이너리 다운로드)

## 결과물

- node_modules/ 폴더: 모든 의존성이 설치됨
- node_modules/electron/dist/electron.exe: Electron 실행 파일 (v31.7.7)
- 설치 로그: npm install exit code 0 (465 packages installed)

## 선행 작업

- P0.2: 빌드 설정 — package.json이 있어야 npm install 가능

## 수행 순서에서의 위치

P0.6은 P0.2의 직접적 후속이다. P0.6이 성공해야 P0.7(vite build), P0.8(실제 기동)을 진행할 수 있다. 이것이 모든 후속 개발의 전제 조건이다.

## done_when을 확인하는 방법

1. `npm install` 명령 실행, exit code 0 확인
2. node_modules/electron/dist 폴더 존재 확인
3. `node_modules/electron/dist/electron.exe --version` 실행해 v31.7.7 이상 확인
4. npm install이 에러 없이 완료된 상태 유지

## 확인 필요

- npm audit 명령으로 12개의 보안 취약점(critical 1건 포함)이 보고되는데, 이들의 심각도와 영향 범위를 별도로 검토해야 함
