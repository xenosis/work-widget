# P0.7 — vite build 렌더러 컴파일 검증

## 목적

`npm run build` 명령으로 React/JSX 렌더러 코드가 에러 없이 번들링되고, dist/ 폴더에 번들 산출물이 생성되는지 확인한다. 이는 실제 Electron 앱이 패키징될 때 사용될 최종 번들이다.

## 쉬운 설명

Vite 빌드 도구가 src/ 폴더의 JSX 코드를 JavaScript로 변환하고, 의존성들을 합쳐서 최소화된 번들 파일(dist/index.html, dist/assets 등)을 만드는 것이다. 이 단계에서 문법 오류나 빌드 설정 오류가 감지된다.

## 필요한 입력

- P0.5 완료 (React 렌더러 코드 존재)
- P0.6 완료 (node_modules 설치, Vite 바이너리 존재)
- vite.config.js 설정 (P0.2에서 작성)

## 결과물

- dist/ 폴더: 번들 산출물
  - dist/index.html: 렌더러 진입점 (Electron이 이걸 로드)
  - dist/assets: 번들 파일들 (JS, CSS 등)
- 빌드 로그: exit code 0, 완료 시간 기록

## 선행 작업

- P0.6: npm install — 이 이전에는 vite 바이너리가 없어 실행 불가

## 수행 순서에서의 위치

P0.7은 P0.6 직후에 실행된다. P0.7 성공이 P0.8(실제 기동)의 전제 조건이다.

## done_when을 확인하는 방법

1. `npm run build` 명령 실행, exit code 0 확인
2. dist/ 폴더 생성 확인
3. dist/index.html과 dist/assets 폴더 존재 확인
4. Vite 모듈 번들링 통계(예: "37 modules, 984ms") 표시 확인
