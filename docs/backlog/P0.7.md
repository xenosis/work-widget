# P0.7 — vite build 렌더러 컴파일 검증

## 목적

Vite 빌드 도구를 실행해서 React/JSX 코드가 에러 없이 번들되는지 확인한다. 이를 통해 코드 문법 오류를 조기에 발견하고, 배포용 최적화 번들(dist/)을 생성한다.

## 쉬운 설명

npm run dev는 개발 중에만 사용하는 빠른 개발 서버다. npm run build는 배포용 최적화 번들을 만드는 명령이다. 이 작업에서는 npm run build를 성공적으로 실행할 수 있는지 테스트한다.

## 필요한 입력

- P0.6 완료: npm install로 vite와 react 설치됨
- P0.5 완료: src/ 폴더의 React 코드가 준비됨
- vite.config.js가 올바르게 설정됨 (P0.2)

## 결과물

- dist/ 디렉토리: dist/index.html, dist/assets/ (번들된 JS, CSS), 기타 정적 파일

## 선행 작업

**P0.6** — npm install 완료.

## 수행 순서에서의 위치

P0.6 직후. P0.8(electron 앱 기동 테스트)에서 번들된 dist/를 참조한다.
