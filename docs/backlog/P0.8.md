# P0.8 — electron 앱 기동 테스트

## 목적

`npm run dev` 명령으로 Electron 앱을 실제로 기동하여, 창이 표시되고, 사이드바 메뉴가 작동하고, 트레이 아이콘이 생성되고, 닫기 버튼 시 창이 숨겨지는 B5.1 동작이 정상임을 확인한다.

## 쉬운 설명

Electron 앱을 실제로 실행해서 모든 기본 기능(창 띄우기, 메뉴 클릭, 트레이 숨김)이 작동하는지 직접 눈으로 확인하는 테스트이다.

## 필요한 입력

- P0.6 완료 (npm install, Electron 바이너리 설치됨)
- P0.7 완료 (vite build 성공, dist/ 생성됨)
- electron/main.js, electron/preload.js 작성 완료 (P0.4)
- src/ 렌더러 코드 완성 (P0.5)

## 결과물

- 실행 중인 Electron 프로세스: 메인 + 렌더러 + GPU + Utility 프로세스
- 화면에 표시되는 창: 사이드바(5개 메뉴) + 대시보드 placeholder 확인
- 트레이 아이콘: Windows 시스템 트레이에 표시

## 선행 작업

- P0.4, P0.5, P0.6, P0.7 모두 완료

## 수행 순서에서의 위치

P0.8은 P0 단계의 마지막 검증 작업이다. P0.8 완료 시 P0 전체가 완료되며, P1(대시보드) 이상의 모든 기능 개발이 가능해진다.

## done_when을 확인하는 방법

1. `npm run dev` 실행 후 Electron 창이 띄어지는지 확인
2. 사이드바의 5개 메뉴가 모두 보이는지 확인
3. 각 메뉴 클릭 시 화면 전환 확인 (대시보드/프로젝트/할일전체/메모/일정)
4. 창의 X(닫기) 버튼 클릭 시 창이 숨겨지는지 확인 (완전 종료되지 않고 트레이에 남음)
5. 콘솔/프로세스에 앱 관련 에러 없음 확인
