# P0.8 — electron 앱 기동 테스트

## 목적

npm run dev를 실행해서 Electron 앱이 실제로 시작되는지 확인한다. 창이 뜨고, 사이드바로 화면을 전환할 수 있으며, 닫기(X) 버튼이 트레이로 숨김 처리하는지 확인한다.

## 쉬운 설명

지금까지의 모든 작업(설정, 코드, 빌드)이 실제로 작동하는지 최종 검증하는 단계다. npm run dev 명령으로 앱을 시작하면 Electron 창이 떠야 하고, 사이드바 메뉴를 클릭하면 화면이 전환되어야 하며, 창의 X 버튼을 누르면 트레이로 숨겨져야 한다.

## 필요한 입력

- P0.6 완료: npm install이 성공
- P0.7 완료 또는 생략 가능: npm run dev는 자동으로 번들링 처리
- main.js, preload.js, 렌더러 코드 모두 작성됨
- dataStore.js가 loadData/saveData를 export함

## 결과물

실행 중인 Electron 프로세스와 화면에 떠있는 Electron 창, 작동하는 사이드바 네비게이션, 트레이에 보이는 아이콘

## 선행 작업

**P0.6** — npm install 완료.

## 수행 순서에서의 위치

P0.6 이후, 전체 P0 완료의 최종 단계. P0.8이 완료되면 P1(대시보드) 이상의 모든 기능 구현이 시작 가능하다.

## done_when을 확인하는 방법

1. `npm run dev` 실행 후 몇 초 내에 Electron 창이 화면에 나타나는가?
2. 사이드바가 보이고 5개 메뉴 항목(대시보드, 프로젝트, 할일전체, 메모, 일정)이 표시되는가?
3. 사이드바 메뉴를 클릭하면 화면이 전환되는가?
4. 창의 X 버튼을 클릭하면 창이 닫히지 않고 트레이로 숨겨지는가? — 실제로는 마우스 클릭 대신 `WM_CLOSE`(X 버튼과 동일한 OS 신호)를 창에 직접 보내 `IsWindowVisible`이 true→false로 바뀌고 프로세스는 계속 실행됨을 확인했다.
5. 트레이에 아이콘이 표시되어 있는가? — 현재 `nativeImage.createEmpty()`(빈 아이콘, P7.1에서 교체 예정)라 육안 확인은 못 했다.

검증 중 `electron/main.js`의 실제 버그 2건이 드러나 함께 고쳐졌다(P0.4 로그 참고): `window-all-closed` 핸들러가 인자 없는 이벤트에 `event.preventDefault()`를 호출해 항상 TypeError였던 것, 그리고 `before-quit`이 Windows 종료/로그아웃 시 발생하지 않아 B5.2("OS 종료 시 함께 종료")의 실행 경로가 없었던 것 — `session-end` 리스너 추가로 보강.
