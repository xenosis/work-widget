# P0 — Phase 0 스캐폴딩 — Electron+React 뼈대, 데이터 저장 계층

## 목적

Windows 트레이 상주형 위젯 애플리케이션의 초석을 구축하는 단계. Electron 메인 프로세스와 Vite+React 렌더러를 이어 연결하고, 로컬 JSON 파일에 데이터를 저장하는 기반을 만든다. 이 단계가 완료되면 화면 기능을 채워나갈 수 있는 준비가 된다.

## 쉬운 설명

애플리케이션의 틀을 만드는 작업이다. 프로젝트 폴더를 구성하고, npm 패키지를 설치하고, 빌드 설정(vite.config.js, package.json)을 작성한 다음, Electron이 창을 띄우고 React 코드를 렌더링할 수 있도록 한다. 마지막으로 npm run dev를 실행했을 때 실제로 창이 뜨고 메인 화면(대시보드)이 보이는지 확인하는 것이 목표다.

## 필요한 입력

- Node.js(npm) 설치 상태 (개발 환경에서 npm install, npm run build 명령 실행 가능해야 함)
- 요구사항 문서(work-widget-requirements.md) — Part A 개요와 Part B.5(위젯 운영 동작)에서 창 닫기=숨김, 트레이 아이콘 등의 동작 기준

## 결과물

다음 폴더/파일 구조가 완성되고 npm install이 성공하며, npm run dev로 Electron 앱이 기동:
- `package.json` — 의존성(electron, react, vite, electron-builder 등) 및 빌드 스크립트(dev, build, dist) 정의
- `vite.config.js` — React/JSX 번들링 설정
- `index.html` — 렌더러 진입점
- `.gitignore` — node_modules, dist, 빌드 산출물 제외
- `electron/main.js` — BrowserWindow, 트레이 아이콘, IPC 핸들러 기본 구조
- `electron/preload.js` — contextBridge 기반 렌더러 ↔ 메인 프로세스 통신 인터페이스
- `electron/dataStore.js` — data.json 로드/저장 함수
- `src/main.jsx`, `src/App.jsx`, `src/screens/*` — React 렌더러, 사이드바, 5개 화면 placeholder

## 수행 순서에서의 위치

프로젝트 전체의 첫 단계. 이 단계가 완료되어야 P1(대시보드)부터 P10까지의 모든 기능 개발이 가능하다. P0의 하위 항목들(P0.1~P0.8)이 순차적으로 진행되며, P0.8(electron 앱 기동 테스트)이 끝나면 P0 전체가 완료된다.

## done_when을 확인하는 방법

1. `npm install` 실행 시 exit code 0으로 정상 종료 (node_modules/electron/dist 존재 확인)
2. `npm run build` 실행 시 exit code 0으로 정상 종료, dist/ 디렉토리 생성 확인
3. `npm run dev` 실행 시 Electron 프로세스 기동, 창이 표시되고 대시보드 placeholder 보임
4. 창의 X 버튼 클릭 시 창이 숨겨지고 트레이에만 남음, 트레이 아이콘 클릭으로 다시 표시 가능
