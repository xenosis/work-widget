# P1.1 — 오늘 마감 할일 목록

## 목적

대시보드에서 오늘 마감 기한을 가진 할일들을 필터링해서 목록으로 표시한다.

## 쉬운 설명

data.json에 저장된 모든 할일(todos 배열) 중에서 due_date가 오늘 날짜인 것만 찾아서 화면에 표시한다. 예를 들어 2026-09-15가 오늘이면, due_date가 "2026-09-15"인 할일들만 보여준다.

## 필요한 입력

- P6.1 완료: 필터링/계산 로직 구성 경험
- todos 데이터 구조 이해 (work-widget-requirements.md B3.2)
- 오늘 날짜를 구하는 로직 (JavaScript Date 또는 라이브러리)

## 결과물

대시보드의 "오늘 마감 할일" 섹션: 목록 형식으로 오늘 마감 todo들 표시, 각 항목은 제목, 우선순위, 프로젝트명 표시

## 선행 작업

**P6.1** — Project.progress 계산 함수. (같은 데이터 처리 패턴 참고)

## 수행 순서에서의 위치

P1 내에서 P1.1, P1.2, P1.3, P1.4는 병렬 진행 가능하지만, P1.5(데이터 IPC 연동) 전에 완료되어야 한다.

## done_when을 확인하는 방법

1. 대시보드 화면을 본다
2. "오늘 마감 할일" 섹션에 항목이 표시되는가?
3. 테스트 데이터 추가: data.json에서 due_date를 오늘로 설정한 할일을 추가하고, 대시보드에 나타나는가?
4. 다른 날짜의 할일은 나타나지 않는가?
