# P1.1 — 오늘 마감 할일 목록

## 목적

대시보드에서 오늘 마감 기한을 가진 할일들을 필터링해서 목록으로 표시한다.

## 쉬운 설명

data.json에 저장된 모든 할일(todos 배열) 중에서 due_date가 오늘 날짜인 것만 찾아서 화면에 표시한다. 각 항목은 제목, 우선순위, 프로젝트명을 함께 표시하고 우선순위(상→중→하) 순서로 정렬한다. 완료된 할일은 취소선으로 표시되어 계속 보인다.

## 필요한 입력

- todos 데이터 구조 이해 (work-widget-requirements.md B3.2)
- 오늘 날짜를 구하는 로직
- 우선순위 정렬 함수 (PRIORITY_ORDER)
- window.api.loadData() IPC 연동 (P1.5에서 제공)

## 결과물

대시보드의 "오늘 마감 할일" 섹션: 목록 형식으로 오늘 마감 todo들 표시, 각 항목은 제목, 우선순위, 프로젝트명 표시

## 선행 작업

- **P1.5** (대시보드 데이터 IPC 연동): window.api.loadData()를 통해 data.json의 todos 배열을 읽어야 함

## 수행 순서에서의 위치

P1(대시보드) 내에서 P1.1, P1.2, P1.3은 P1.5(IPC 연동)가 먼저 완료된 후 진행 가능하다. P1.5 완료 후 이 세 task는 병렬 진행 가능하고, 모두 완료되면 P1.6(트레이 재표시 시 데이터 재조회)을 진행할 수 있다.

## done_when을 확인하는 방법

1. npm run dev로 앱 실행 후 대시보드 화면 진입
2. data.json의 todos 배열에 due_date가 오늘인 할일 추가
3. 대시보드 "오늘 마감 할일" 섹션에 즉시 표시되는지 확인
4. 완료된 오늘 마감 할일은 취소선으로 표시되는지 확인
5. 내일이나 다른 날짜의 할일은 이 섹션에 나타나지 않는지 확인
6. 여러 우선순위(상/중/하)를 시딩했을 때 상→중→하 순서로 정렬되는지 확인

## 확인 필요

- deps가 원래 P6.1이라고 로그에 명시되었으나 실제로는 P1.5가 필요함을 구현 과정에서 발견하고 P11.1로 정정됨. 이는 P1.6 설계 시 window.api.loadData() 호출이 필수인 것이 명확해진 후의 정정이었음
