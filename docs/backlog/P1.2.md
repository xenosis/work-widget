# P1.2 — 이번주 마감 할일 목록

## 목적

대시보드의 두 번째 섹션으로 이번주 마감일을 가진 할일들을 필터링하고 표시한다.

## 쉬운 설명

할일(todos)의 due_date를 확인해서 오늘을 제외하고 이번주(월~일) 범위 안에 있는 항목만 걸러낸다. 마감일 순서대로, 같은 날이면 우선순위(상→중→하) 순서대로 정렬해서 Dashboard 화면에 표시한다. 이번주 중 이미 지난 날짜(예: 오늘이 수요일이면 월/화)의 할일도 포함된다.

## 필요한 입력

- P1.1(오늘 마감 할일)에서 완성된 필터링·정렬 패턴
- src/lib/dateRange.js (이번주 범위 계산 함수들)
- work-widget-requirements.md의 B1.2, B2.2 — 대시보드와 할일전체 화면의 "이번주" 정의

## 결과물

Dashboard.jsx의 "이번주 마감" 섹션에 이번주(월~일, 오늘 제외)에 마감인 할일들이 날짜순·우선순위순으로 표시되는 코드

## 선행 작업

- P1.1: 오늘 마감 할일 (필터링/정렬/우선순위 처리 로직)

## 수행 순서에서의 위치

P1(대시보드) 내에서 P1.1 이후 단계. P1.1의 필터링·정렬 패턴을 따르므로 상대적으로 빠르게 진행 가능.

## done_when을 확인하는 방법

1. Dashboard.jsx의 "이번주 마감" 섹션 렌더링 확인
2. npm run dev로 실행해 오늘/이번주 다른날짜/다음주/마감없음 혼합 데이터 시딩
3. 다음 항목들이 이번주 섹션에 정상 표시되는지 확인:
   - 오늘과 이번주 중 이미 지난 날짜 항목들
   - 마감일 순, 동일 날짜 내 우선순위순으로 정렬
4. 오늘, 다음주, 마감없음 항목은 이번주 섹션에서 제외되는지 확인
5. lint 통과, npm run build 성공, 콘솔 에러 없음
