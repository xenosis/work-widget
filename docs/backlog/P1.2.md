# P1.2 — 이번주 마감 할일 목록

## 목적

대시보드의 두 번째 섹션으로 이번주 마감일을 가진 할일들을 필터링하고 표시하는 기능을 구현한다. 오늘보다 미래이면서 이번주 범위(월요일~일요일) 내의 마감일을 가진 할일을 날짜순·우선순위순으로 정렬해 보여준다.

## 쉬운 설명

할일(todos)의 due_date를 확인해서 오늘을 제외하고 이번주(월~일) 범위 안에 있는 항목만 걸러낸다. 그리고 마감일 순서대로, 같은 날이면 우선순위(상→중→하) 순서대로 정렬해서 Dashboard 화면에 표시한다.

## 필요한 입력

- P1.1(오늘 마감 할일)에서 완성된 필터링·정렬 패턴
- P1.2 리뷰에서 만들어진 src/lib/dateRange.js (이번주 범위 계산 함수들)
- work-widget-requirements.md의 B1.2, B2.2 — 대시보드 구성과 할일 표시 방식

## 결과물

Dashboard.jsx의 "이번주 마감" 섹션에 이번주(월~일, 오늘 제외)에 마감인 할일들이 날짜순·우선순위순으로 표시되는 코드. 필요시 기존 Dashboard의 오늘 마감 섹션 콘텐츠 재사용.

## 선행 작업

- P1.1: 오늘 마감 할일 (필터링/정렬/우선순위 처리 로직, lint 통과, 검증 완료)
- P6.1: backlog에는 deps가 있으나 실제로는 P1.5(IPC 연동)이 먼저 필요함 — CLI 필드 수정 제한으로 이대로 유지

## 수행 순서에서의 위치

P1(대시보드) 내에서 P1.1 이후 단계. P1.1의 필터링·정렬 패턴을 그대로 따르므로 상대적으로 빠르게 진행 가능. 이어서 P1.3(프로젝트 현황), P1.4(오늘 일정)이 순서. P1 전체가 완료되면 대시보드의 4개 핵심 섹션(오늘/이번주/프로젝트/일정)이 준비된다.

## done_when을 확인하는 방법

1. Dashboard.jsx의 "이번주 마감" 섹션 렌더링 확인
2. npm run dev로 실행해 userData/data.json에 오늘/이번주 다른 날짜(과거 포함)/다음주/마감없음 혼합 데이터 시딩
3. PrintWindow API로 앱 창만 캡처해 다음 확인:
   - 오늘과 이번주 중 이미 지난 날짜 항목들이 이번주 섹션에 정상 표시됨(P1.2 리뷰에서 fixed)
   - 오늘, 다음주, 마감없음 항목은 이번주 섹션에서 제외됨
   - 항목들이 마감일 순(가장 가까운 것부터), 동일 날짜 내 우선순위순(상→중→하)으로 정렬됨
4. lint 통과, npm run build 성공, 콘솔 에러 없음

## 확인 필요

- 이번주 범위의 정확한 정의: 월요일~일요일인지, 특수한 로케일 규칙이 적용되는지 (현재 월요일 시작으로 구현 중)
- 요구사항 B1.2에 "이번주 마감" 섹션이 명시되어 있는가 (확인됨 — "이번주 마감인 할일 목록")
