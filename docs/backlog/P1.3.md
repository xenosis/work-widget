# P1.3 — 진행중 프로젝트 현황 카드

## 목적

대시보드에 진행 중인 프로젝트들의 현황을 카드 형식으로 표시한다. 진행중인 프로젝트의 개수, 평균 진행률, 개별 프로젝트별 진행률 등을 한눈에 볼 수 있게 한다.

## 쉬운 설명

projects 배열에서 status가 "진행중"인 프로젝트들을 찾아서 진행 중인 프로젝트 개수와 평균 진행률을 계산해 표시한다. 각 프로젝트의 진행률을 시각적으로(프로그레스 바 등) 표시할 수 있다.

## 필요한 입력

- **P6.1 필수**: Project.progress 계산 함수 (각 프로젝트의 진행률을 구하기 위해)
- projects 데이터 구조 이해 (work-widget-requirements.md B3.1)
- todos와의 관계 이해 (progress는 해당 프로젝트의 todo 완료 비율)

## 결과물

대시보드의 "진행 중인 프로젝트" 섹션: 카드형 UI로 프로젝트 현황 표시, 총 프로젝트 개수와 평균 진행률 표시, 개별 프로젝트 진행률 표시

## 선행 작업

**P6.1** — Project.progress 계산 함수 완료 필수.

## 수행 순서에서의 위치

P1 내에서 P1.1, P1.2와 병렬 진행 가능. P1.5(IPC 연동) 전에 완료.

## done_when을 확인하는 방법

1. 대시보드에서 "진행 중인 프로젝트" 섹션을 본다
2. 진행 중인 프로젝트 개수가 표시되는가?
3. 평균 진행률이 계산되어 표시되는가?
4. 각 프로젝트의 개별 진행률이 표시되는가?
5. 테스트: projects에서 일부 프로젝트를 "보류" 또는 "완료"로 변경 후 개수가 정확히 갱신되는가?
