# P1.4 — 오늘 일정 표시

## 목적

대시보드의 네 번째 섹션으로 오늘의 일정(일회성 및 반복 규칙 전개 결과)을 표시한다.

## 쉬운 설명

schedules 배열에서 오늘과 일치하는 항목들을 찾아낸다. date가 오늘인 일회성 일정들과, recurrence_days에 오늘의 요일이 포함된 반복 규칙들을 모두 수집해서 Dashboard의 "오늘 일정" 섹션에 표시한다. 각 일정은 제목, 시간대(있으면), 반복 배지(반복일정이면), 개수 요약 배지로 표시된다.

## 필요한 입력

- P5.1: getSchedulesForDate 함수 (오늘 해당 일정 계산)
- P5.4: 반복 일정 등록 UI (이미 완료, 반복 규칙 데이터 구조 확인)
- P5.6: 비반복 일정 CRUD (이미 완료, 일회성 일정 데이터 확인)
- work-widget-requirements.md의 B1.2, B3.4, B2.4

## 결과물

Dashboard.jsx의 "오늘 일정" 섹션:
- 오늘 해당하는 모든 일정 표시 (일회성 + 반복 규칙 전개)
- 각 일정의 제목, 반복 배지, 개수 배지 렌더링
- 빈 상태("오늘 일정이 없습니다.") 처리
- id 없는 레코드는 필터링하고 notice 표시

## 선행 작업

- P5.1: getSchedulesForDate 함수 정의 (필요한 실제 기능)
- P5.6: 비반복 일정 CRUD (일회성 일정 데이터 검증)

(참고: deps=[P5.4]로 등록되어 있으나 실제로는 P5.1만 필요. P5.4와 P5.6은 검증을 위해 필요함. CLI에 deps 수정 명령이 없어 기록만 남김)

## 수행 순서에서의 위치

P1(대시보드) 내에서 마지막 섹션. P5.1 함수 정의만 있으면 진행 가능하나, 반복 규칙 데이터 구조를 검증하기 위해 P5.4/P5.6도 먼저 완료되는 것이 권장됨. 이 작업 완료 후 P1도 done 처리 예정.

## done_when을 확인하는 방법

1. Dashboard.jsx에 "오늘 일정" 카드 렌더링 확인
2. npm run dev로 실행해 다음을 검증:
   - 오늘 일회성 일정이 표시됨
   - 오늘의 요일을 포함한 반복 규칙이 자동 전개되어 표시됨
   - 다른 날짜 일정은 제외됨
   - 일정이 0건일 때 "오늘 일정이 없습니다." 문구 표시
   - id 없는 일정은 제외되고 notice 표시
3. scheduleGrid.js(P5.1)의 getSchedulesForDate 회귀 테스트(npm test) 통과
4. 전체 lint, vitest, vite build 통과
5. 콘솔 에러 없음
