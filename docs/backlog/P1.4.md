# P1.4 — 오늘 일정 표시

## 목적

대시보드의 네 번째 섹션으로 오늘의 일정을 표시하는 기능을 구현한다. 일회성 일정과 반복 일정(recurrence_days 규칙) 모두를 처리해서 오늘 해당하는 항목들을 화면에 보여준다.

## 쉬운 설명

schedules 배열에서 오늘과 일치하는 항목들을 찾아낸다. date가 오늘인 일회성 일정들과, recurrence_days에 오늘의 요일(예: 월/화/수/목/금/토/일)이 포함된 반복 규칙들을 모두 수집해서 Dashboard의 "오늘 일정" 섹션에 표시한다.

## 필요한 입력

- P5.4(반복 일정 등록): recurrence_days 필드의 구조 및 요일 format 확인
- work-widget-requirements.md의 B1.2(대시보드 구성), B3.4(Schedule 데이터 구조), B2.4(반복 규칙)
- 현재 날짜를 기준으로 요일을 판별하는 로직

## 결과물

Dashboard.jsx의 "오늘 일정" 섹션에 오늘 해당하는 일회성 + 반복 전개 일정들이 시간 순서대로(또는 추가 순서대로) 표시되는 코드.

## 선행 작업

- P5.4: 반복 일정(요일 지정) 등록 기능 — 이 기능이 완료되어야 recurrence_days 데이터가 존재하고 이를 처리할 수 있음

## 수행 순서에서의 위치

P1(대시보드) 내에서 P1.1, P1.2, P1.3 이후의 마지막 섹션. P5(일정 화면) 전체가 아직 미구현이라도, P5.4 정의만 있으면 진행 가능. 이 섹션이 완료되면 대시보드의 4개 핵심 섹션(오늘 마감/이번주 마감/프로젝트 현황/오늘 일정)이 모두 준비된다.

## done_when을 확인하는 방법

1. Dashboard.jsx의 "오늘 일정" 섹션 렌더링 확인
2. npm run dev로 실행해 userData/data.json에 오늘 일회성 일정 1개 + 오늘의 요일을 포함한 반복 규칙 1개 + 다른 날짜의 일정 혼합 데이터 수기 작성
3. PrintWindow API로 앱 창 캡처해 다음 확인:
   - 오늘 일회성 일정이 표시됨
   - 오늘의 요일(예: 월요일)을 recurrence_days에 포함한 반복 규칙이 자동 전개되어 표시됨
   - 다른 날짜 또는 다른 요일 일정은 제외됨
4. lint 통과, 콘솔 에러 없음

## 확인 필요

- schedules 배열의 현재 실제 상태 및 구조 (P5.4가 미구현이면 테스트 데이터는 수기 생성 필요)
- recurrence_days의 요일 문자열 format ("월"/"화"/... vs "Monday"/"Tuesday"/... vs "1"/"2"/... 등) 확인 필요
- 오늘 일정들의 정렬 기준 (시간순 vs 추가순 vs 다른 규칙) — 요구사항 문서에 명시 없음
