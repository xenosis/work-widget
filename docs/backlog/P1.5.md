# P1.5 — 대시보드 데이터 IPC 연동

## 목적

대시보드의 모든 섹션(P1.1~P1.4)을 실제 data.json의 데이터와 연결한다.

## 쉬운 설명

지금까지 P1.1~P1.4는 "데이터가 있다고 가정하고" UI를 만들었다. 이제 그 UI를 실제 데이터와 연결한다. 컴포넌트가 마운트될 때 window.api.loadData()를 호출해 data를 state에 저장하고, 그 state를 기반으로 P1.1~P1.4의 필터/계산 함수들이 동작하게 한다.

## 필요한 입력

- P0.4 완료: IPC 채널(data:load) 구현됨
- P0.8 완료: 앱이 실행되고 preload.js가 로드됨
- P1.1~P1.4 완료: UI 컴포넌트들 준비됨

## 결과물

Dashboard.jsx의 로직: useEffect로 mount 시 window.api.loadData() 호출, 받은 data를 로컬 state에 저장, P1.1~P1.4의 필터/계산 함수들이 state 데이터 기반으로 동작, 에러/로딩 상태 처리

## 선행 작업

- P0.8: Electron 앱이 실행되고 IPC가 작동함

## 수행 순서에서의 위치

P1 내에서 가장 마지막. P1.1~P1.4가 모두 완료된 후 이 작업으로 P1을 마무리.

5. 로딩/에러 상태 처리가 정상인가?
