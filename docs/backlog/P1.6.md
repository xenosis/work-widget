# P1.6 — 트레이 재표시 시 대시보드 데이터 재조회

## 목적

대시보드가 최신 data.json을 항상 반영하도록 개선한다.

## 쉬운 설명

현재는 컴포넌트가 mount할 때 1회만 loadData()를 호출한다. 하지만 창이 숨겨졌다가 다시 표시될 때(트레이에서 복귀) 그 사이 변경된 data.json을 반영하지 못한다. 창이 다시 표시될 때 fresh 데이터를 다시 불러와야 한다.

## 필요한 입력

- P1.5(대시보드 IPC 연동): window.api.loadData() 구현 및 사용 패턴
- electron/main.js의 BrowserWindow show 이벤트
- work-widget-requirements.md의 B5.1(창 닫기=숨김)

## 결과물

대시보드 컴포넌트에 창 재표시 감지 및 재조회 로직 추가. 공용 훅(useAppData.js)에서 show/restore 이벤트 구독해 재조회 자동화.

## 선행 작업

- P1.5: 대시보드 IPC 연동

## 수행 순서에서의 위치

P1(대시보드) 내에서 P1.5 이후의 보완 작업.
