# P1.7 — 오늘/이번주 마감 할일 행에 프로젝트명 표시

## 목적

대시보드와 할일전체 화면에서 각 할일이 속한 프로젝트명을 태그로 표시하여, 사용자가 어느 프로젝트의 일인지 한눈에 알 수 있게 한다.

## 쉬운 설명

대시보드의 "오늘 마감", "이번주 마감" 섹션과 할일전체 화면(Todos.jsx)의 각 할일 옆에 소속 프로젝트명을 작은 태그로 표시한다. 프로젝트가 없는 할일(project_id=null)은 태그를 표시하지 않는다. 프로젝트명이 길면 말줄임 처리되어 레이아웃이 깨지지 않는다.

## 필요한 입력

- P1.1/P1.2 완료: 오늘/이번주 마감 할일 필터링 로직
- P3.1 완료: 할일전체 화면 구현
- projects 배열: project_id로 프로젝트명을 조회하기 위해 필요
- src/lib/projectLookup.js: project_id로 프로젝트명을 조회하는 getProjectName 함수

## 결과물

- Dashboard.jsx의 오늘/이번주 섹션 할일 행에 프로젝트명 태그(.todo-project-tag) 표시
- Todos.jsx(할일전체 화면)의 모든 그룹(오늘/이번주/나중)에 프로젝트명 태그 표시
- src/components/TodoRow.jsx: 할일 행의 공유 컴포넌트(Dashboard/Todos/Projects 상세 화면에서 재사용)
- src/lib/projectLookup.js: getProjectName 함수로 project_id → 프로젝트명 조회
- src/index.css: .todo-project-tag, .todo-main, .todo-meta 스타일

## 선행 작업

- **P1.1** (오늘 마감 할일 목록): 할일 필터링 및 표시 로직이 먼저 필요
- 암시적: P3.1 (할일전체 화면) 및 P2.2 (프로젝트 상세 화면)

## 수행 순서에서의 위치

P1 내 순환 작업으로, P1.1~P1.6 완료 후 P1.7이 진행된다. 동시에 P2.2에서 프로젝트 상세 화면의 할일 목록도 같은 TodoRow 컴포넌트를 재사용하게 되어, 세 화면(Dashboard/Todos/Projects 상세)이 시각적으로 일관성을 유지한다.

## done_when을 확인하는 방법

1. npm run dev로 앱 실행
2. 다양한 프로젝트가 지정된 할일들을 data.json에 시딩
3. 대시보드의 "오늘 마감", "이번주 마감" 섹션에서 각 할일 옆에 프로젝트명 태그가 표시되는지 확인
4. 할일전체 화면(Todos.jsx)의 오늘/이번주/나중 모든 섹션에도 태그가 표시되는지 확인
5. project_id가 없는 할일은 태그 없이 표시되는지 확인
6. 긴 프로젝트명(30자 이상)은 말줄임으로 처리되고 가로 스크롤이 생기지 않는지 확인
7. 프로젝트가 존재하지 않는 project_id를 가진 할일은 안전하게 처리되는지 확인(보통 경고 배지 표시)
