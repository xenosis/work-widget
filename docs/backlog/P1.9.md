# P1.9 — [검증용] parent 자동추론

## 목적

backlog.json 구조 정리 관련 기술 작업. 이 task 자체는 사용자 기능이 아니며, backlog 스키마 검증 로직 개발 또는 사용 도구 자체의 기능 확장을 다루는 내부 작업이다.

## 쉬운 설명

id 체계(P1.1, P1.2, P1.3 등)를 보면 parent가 자동 추론 가능한 패턴이 있다. 새 task를 add할 때 parent 필드를 직접 지정하지 않아도 id의 prefix(P1)로부터 parent(P1)를 자동 결정할 수 있는 로직 확인 또는 개발. 이는 backlog CLI나 검증 로직의 개선 사항.

## 필요한 입력

- scripts/backlog/lib 의 현재 add/validation 로직 검토
- backlog.json의 실제 id 체계 및 parent 관계 패턴 분석

## 결과물

backlog CLI 또는 검증 도구에서 parent를 자동 추론하는 로직 (또는 로직이 이미 있다면 검증 완료).

## 선행 작업

없음 (내부 backlog 도구 작업)

## 수행 순서에서의 위치

이 task는 사용자 기능과 무관한 내부 작업(개발 과정 최적화)이므로, 메인 개발 흐름(P0~P10)과는 독립적. 필요시 추후에 진행.

## done_when을 확인하는 방법

- scripts/backlog/cli.js add 시 동작 테스트 (parent 자동 추론 여부)
- 수동 backlog.json 편집 후 scripts/backlog/lib의 validation이 정확히 작동하는지 확인

## 확인 필요

- 이 작업이 실제로 필요한 기능인지, 아니면 backlog.json 구조 정리 차원의 test task인지 확인 필요
- 현재 backlog CLI에서 parent 자동추론 기능 존재 여부
