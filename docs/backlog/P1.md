# P1 — 대시보드 화면 (B1.2)

## 목적

앱 시작 시 가장 먼저 보이는 "오늘의 할일 요약" 대시보드를 구현한다. 사용자가 앱을 열었을 때 오늘 해야 할 일, 이번주 해야 할 일, 프로젝트 진행률, 오늘 일정을 한눈에 볼 수 있게 한다.

## 쉬운 설명

대시보드는 회사 입사하면 받는 "오늘의 업무 현황판"처럼, 사용자가 앱을 열었을 때 가장 먼저 보는 화면이다. 여기서 보이는 것은 오늘 마감인 할일, 이번주 마감인 할일, 진행 중인 프로젝트의 개수와 진행률, 오늘 예정된 일정들이다.

## 필요한 입력

- P0 완료: 앱이 실행되고 React 렌더러가 로드됨
- P6.1 필수: Project.progress 계산 함수 (진행률 표시에 필요)
- work-widget-requirements.md의 B1.2, B3 섹션 검토
