# P1 — 대시보드 화면 (B1.2)

## 목적

앱의 초기 진입 화면인 대시보드를 구현한다. 오늘과 이번주 마감 할일, 진행중 프로젝트 현황, 오늘 일정을 한눈에 볼 수 있는 요약 화면이다.

## 쉬운 설명

앱을 열면 가장 먼저 보는 화면이다. 바쁜 사용자가 빠르게 오늘/이번주 해야 할 일과 진행 중인 프로젝트들을 파악할 수 있도록 요약 정보를 보여준다. 각 섹션(오늘 마감 할일, 이번주 마감 할일, 프로젝트 현황, 오늘 일정)은 독립적인 하위 작업으로 분리되어 있고, 모두 완료되었다.

## 필요한 입력

- 요구사항 B1.2: 대시보드 구성 요소 정의
- P0 완료: 기본 앱 프레임워크
- P1.1~P1.7: 각 섹션별 하위 작업 완료

## 결과물

src/screens/Dashboard.jsx:
- 오늘 마감 할일 목록
- 이번주 마감 할일 목록 (오늘 제외, 이번주 범위 포함)
- 진행중 프로젝트 요약 (개수/평균 진행률)
- 오늘 일정 표시 (일회성 + 반복 규칙 전개)
- 각 할일 항목에 프로젝트명 태그 표시

## 선행 작업

- P0: 기본 앱 프레임워크 (완료)

## 수행 순서에서의 위치

P1은 기능 개발의 첫 번째 phase이다. 모든 하위 항목(P1.1~P1.7)이 완료되면 P1도 완료된다. P1과 P2/P3/P4/P5는 독립적으로 병렬 진행 가능하다.

- P1.4: 오늘 일정 표시 (done)
