# P10 — 화면 공통 IPC 로딩 훅 추출

## 목적
Dashboard, Projects 등 여러 화면이 중복하는 window.api.loadData() 보일러플레이트를 useAppData 훅으로 통합하여, 로딩/에러/재조회 로직을 한 곳에서 관리한다.

## 쉬운 설명
여러 화면이 모두 같은 방식으로 데이터를 로드하는 코드를 반복 작성하고 있다. 이를 하나의 React 훅으로 만들어 재사용하면, 로딩 상태와 에러 처리가 일관되고 수정이 쉬워진다.

## 필요한 입력
- P1.5, P2.1 등: 각 화면의 IPC 로딩 보일러플레이트
- React 커스텀 훅 패턴

## 결과물
- src/lib/useAppData.js: 훅(apiAvailable/data/error state, useEffect, ignore flag)
- Dashboard.jsx, Projects.jsx: useAppData 훅 사용으로 보일러플레이트 제거

## 선행 작업
- P1.5 (Dashboard IPC): done
- P2.1 (Projects IPC): done

## 수행 순서에서의 위치
P1-P4 로딩 로직 완성 후 리팩터링. 이후 P9(디자인) 등 진행 가능.

## done_when을 확인하는 방법
1. Dashboard, Projects 화면이 useAppData 훅 사용
2. 보일러플레이트 코드 제거됨
3. npm run build 통과
4. npm run dev로 로딩 동작 정상(리팩터링 전후 동일)
