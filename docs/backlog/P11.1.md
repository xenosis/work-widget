# P11.1 — set-field로 누적된 stale 필드 정정 적용

## 목적

P11에서 만들어진 `set-field` 명령을 실제로 사용해서, 이전 critical-reviewer 리뷰들에서 지적했지만 고칠 수단이 없어 방치된 stale 메타데이터들을 정정한다. 이를 통해 backlog.json의 메타데이터 무결성을 회복한다.

## 쉬운 설명

지금까지 개발 과정에서 여러 task들의 필드(title, summary, deps, where)가 실제 코드나 상황과 맞지 않는 것이 발견되었다:

- **P0.6**: summary가 "설치 미완료(EBUSY 장애)"라는 낡은 서술 → "설치 완료, 과거 장애는 해소됨"으로 정정
- **P1.7**: title에 "[확인 필요]" 접두어가 달려 있음 → 제거
- **P7.1**: summary가 "교체할 예정"이라는 낡은 서술 → "실제 구현(pure Node PNG 생성 스크립트)" 기준으로 정정
- **P1.1, P2.1, P3.1**: deps 필드가 의미상 틀림 → 실제 의존 대상으로 정정
- **P2.10**: where 필드가 실제 변경한 파일들을 정확히 가리키지 못함 → 전체 파일 목록으로 확장

이제 P11에서 만들어진 set-field 명령을 사용해서 이 필드들을 실제로 정정하고, 각 정정마다 --note로 근거를 남긴다. 각 정정 후 task의 log에 field_edit(before/after) 기록이 자동으로 추가된다.

## 필요한 입력

- **P11 완료**: set-field 명령이 scripts/backlog/cli.js와 scripts/backlog/lib/fieldMutations.js에 구현되어 있어야 함
- **정정할 대상들의 식별**:
  - P0.6: summary
  - P1.7: title
  - P7.1: summary
  - P1.1: deps (P6.1 → P1.5)
  - P2.1: deps (P6.2 → P6.1, P6.2)
  - P3.1: deps (정정 필요한 부분)
  - P2.10: where (ProjectDetail.jsx, ProjectEditForm.jsx, index.css 등 누락된 파일 추가)

## 결과물

다음 7개 task의 메타데이터가 정정되고, 각각의 log에 field_edit 기록(before/after)이 남음:

1. **P0.6** — summary 정정
2. **P1.7** — title 정정 (접두어 제거)
3. **P7.1** — summary 정정
4. **P1.1** — deps 정정 (P6.1 → P1.5)
5. **P2.1** — deps 정정 (P6.2 → P6.1, P6.2)
6. **P3.1** — deps 정정 (별도 논의)
7. **P2.10** — where 확장 (누락된 파일 추가)

각 정정은 `node scripts/backlog/cli.js set-field <id> --<field>=<value> --note=<근거>`로 실행되며, backlog.json이 자동 갱신된다.

## 선행 작업

- **P11** (backlog CLI에 필드 수정 명령 도입): set-field 명령이 구현되어 있어야 함

## 수행 순서에서의 위치

P11.1은 P11의 직접 후속 작업으로, P11이 완료되자마자 진행할 수 있는 cleanup 작업이다. backlog 메타데이터 정정을 완료시키는 마지막 단계이며, 이 작업 완료 후 backlog.json의 모든 메타데이터가 실제 코드/상황과 일치하게 된다.

## done_when을 확인하는 방법

1. 다음 7개 task에 대해 `node scripts/backlog/cli.js show <id>` 실행:
   ```bash
   node scripts/backlog/cli.js show P0.6
   node scripts/backlog/cli.js show P1.7
   node scripts/backlog/cli.js show P7.1
   node scripts/backlog/cli.js show P1.1
   node scripts/backlog/cli.js show P2.1
   node scripts/backlog/cli.js show P3.1
   node scripts/backlog/cli.js show P2.10
   ```

2. **각 task별 확인**:
   - P0.6: summary가 "설치 완료, 과거 장애는 해소됨" 기준으로 서술되어 있는지 확인
   - P1.7: title에 "[확인 필요]" 접두어가 없는지 확인
   - P7.1: summary가 "pure Node PNG 생성" 구현 기준으로 서술되어 있는지 확인
   - P1.1/P2.1/P3.1: deps 배열이 실제 의존 대상을 정확히 가리키는지 확인
   - P2.10: where가 ProjectDetail.jsx, ProjectEditForm.jsx, index.css 등 모든 변경 파일을 포함하는지 확인

3. **log 기록 확인**:
   - 각 task의 log 배열에서 마지막 항목이 다음을 포함하는지 확인:
     ```json
     {
       "at": "2026-09-25...",
       "owner": "claude",
       "status": "done",
       "note": "P11.1: ...",
       "field_edit": {
         "before": { "<field>": "..." },
         "after": { "<field>": "..." }
       }
     }
     ```

4. **npm test, lint, build 통과** 확인

## 확인 필요

없음 — 모든 정정이 P11.1 착수 시점에 실제로 적용되었으며, 각 task의 log에 field_edit 기록이 남아있음
