# P12.1 — 기본 애플리케이션 메뉴 제거

## 목적

Electron이 기본으로 제공하는 애플리케이션 메뉴(File/Edit/View/Window/Help)를 완전히 제거해서 트레이 상주 위젯의 UI를 깔끔하게 정리하고, 메뉴의 Quit(Ctrl+Q) 항목이 의도적인 종료 경로(B5.2: "종료 메뉴 없음")를 우회하는 보안 허점을 막습니다.

## 쉬운 설명

Electron 애플리케이션은 아무 설정을 하지 않으면 창 상단에 File, Edit, View, Window, Help 메뉴를 자동으로 표시합니다. 이 업무 위젯에는 이 메뉴들이 필요 없으므로 `Menu.setApplicationMenu(null)`로 메뉴 바를 아예 없앱니다. 

다만 개발 중에는 페이지 새로고침(Ctrl+R)과 개발자 도구(Ctrl+Shift+I)가 유용하므로, dev 모드에서만 `webContents`의 `before-input-event` 리스너를 등록해 이 두 단축키를 직접 감지하고 처리합니다. 메뉴 바는 dev에서도 보이지 않으면서 개발 편의는 유지하는 방식입니다.

기본 메뉴가 함께 제공하던 다른 단축키(확대/축소, F11 전체화면, Ctrl+W 창 닫기)는 의도적으로 범위 밖에 둡니다. 이 위젯은 always-on-top이 아닌 일반 창이고 확대/축소나 전체화면 요구가 명시된 적이 없기 때문입니다.

## 필요한 입력

- `electron/main.js` 파일 (BrowserWindow 생성 구간 및 app.whenReady() 핸들러)
- `work-widget-requirements.md` 중 B1.1 섹션 (결정 사항 기록 위치)
- Electron 라이브러리의 Menu API (`Menu.setApplicationMenu`) 및 BrowserWindow의 `before-input-event` 이벤트
