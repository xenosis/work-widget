# P12.12 — 프로젝트 상세 할일 카드 안내 문구 간격 보정

## 목적

프로젝트 상세 화면(ProjectDetail)에서 요약을 수정하는 모드와 일반 조회 모드 사이에 할일 목록의 위치가 흔들리는 현상을 없애기 위함. 편집 모드에서 표시되는 안내 문구("요약 수정을 마치거나 취소한 뒤 할일을 추가할 수 있습니다")와 할일 목록 사이의 간격을, 비편집 모드에서 할일 입력 폼(AddTodoForm)이 이미 제공하는 간격과 일치시켜 화면 레이아웃의 일관성을 확보한다.

## 쉬운 설명

프로젝트 상세 화면에는 두 가지 상태가 있습니다:

**비편집 모드(일반 상태)**:
- 요약 텍스트와 수정 버튼 표시
- 그 아래 할일 추가 입력창(AddTodoForm)이 있고, margin-bottom은 10px
- 그 아래 할일 목록 또는 "할일이 없습니다" 안내 문구

**편집 모드**:
- 요약 편집 폼이 표시됨 (저장/취소 버튼)
- 그 아래 안내 문구가 표시됨: "요약 수정을 마치거나 취소한 뒤 할일을 추가할 수 있습니다"
- 그 아래 할일 목록 또는 "할일이 없습니다" 안내 문구

문제: 편집 모드의 안내 문구는 margin이 0이었으므로, 할일 목록이 문구에 바짝 붙어있었습니다. 비편집 모드의 입력창은 margin-bottom이 10px이므로, 두 모드 간의 시각적 일관성이 없었습니다.

해결책: 편집 모드 안내 문구에만 적용되는 새로운 CSS 클래스(project-detail-editing-notice)를 만들고, margin-bottom: 10px을 지정했습니다. 이제 두 모드 모두에서 할일 목록의 위치가 같게 유지됩니다.

## 필요한 입력

- `src/components/ProjectDetail.jsx` — 편집 모드에서 안내 문구를 렌더링하는 부분 (조건부 렌더링)
- `src/index.css` — `.todo-add-form`의 기존 margin-bottom 값(10px) 참고
- **P12.5 완료** — AddTodoForm의 최종 레이아웃이 확정되어 비교 기준이 제공됨

## 결과물

1. **src/components/ProjectDetail.jsx**:
   - 편집 모드의 안내 문구 `<p>` 태그의 className에 새 클래스 `project-detail-editing-notice` 추가
   - 안내 문구 텍스트: "요약 수정을 마치거나 취소한 뒤 할일을 추가할 수 있습니다"

2. **src/index.css**:
   - 새로운 CSS 규칙 추가: `.project-detail-editing-notice { margin-bottom: 10px; }`
   - `.empty-text` 자체는 그대로 유지(margin: 0) — 다른 화면의 "목록 없음" 문구들은 영향받지 않음

## 선행 작업

**P12.5** (AddTodoForm 레이아웃 및 입력 폼 분리) — 필수 선행 작업

이유: P12.12가 비교 기준으로 삼는 AddTodoForm의 margin-bottom 값(10px)을 P12.5가 정의합니다. P12.5가 그 폼의 구조나 스타일을 변경하면 P12.12의 비교 기준이 달라질 수 있으므로, P12.5가 먼저 완료되어야 P12.12의 기준값이 확정됩니다. critical-reviewer 지적으로 P12.5가 deps에 명시적으로 추가됨.
