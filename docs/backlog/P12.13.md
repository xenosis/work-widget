# P12.13 — select/date 입력 트리거 테마 통일

## 목적

앱 전체에 흩어진 select(드롭다운) 입력과 date(날짜) 입력을 시각적으로 통일하고 다크 테마에 맞춘 커스텀 화살표, 아이콘, 상태 피드백(hover, focus, disabled)을 제공하기 위함. 다양한 화면에서 이 입력들을 일관되게 제시해 사용자가 앱의 시각 언어를 쉽게 이해할 수 있게 한다.

## 쉬운 설명

이 작업은 처음엔 "모든 select와 date 입력을 CSS만으로 다크 테마에 맞춘 모양으로 통일하자"는 계획이었습니다.

**착수 시점의 발견과 정정:**

계획 당시 "select 7곳 + date 입력 4곳"이라고 파악했는데, 착수하면서 실제 코드를 grep으로 세어보니:
- date 입력이 실제로는 7곳이었음 (Projects.jsx, ProjectDetail.jsx가 초기 분석에서 누락됨)
- 정정 후: select 7곳, date 입력 7곳

**초기 구현 계획:**

CSS의 `appearance: none`으로 OS 기본 화살표를 숨기고, `linear-gradient`로 만든 커스텀 chevron 화살표를 모든 select에 그리며, date 입력의 달력 아이콘도 opacity로 상태 피드백을 주는 방식으로 전부 통일하려 했습니다.

**구현 중 발견된 결정적인 제약:**

Playwright로 실제 화면을 찍어 실측한 결과:

> **Windows에서 select의 옵션 팝업(드롭다운 목록)은 Chromium 렌더 엔진이 OS 네이티브 콤보박스 컨트롤로 직접 그려내기 때문에**, CSS의 `option` 배경색 지정도, `:root`의 `color-scheme: dark` 설정도, 심지어 Electron의 `nativeTheme.themeSource = 'dark'` 강제도 전부 무시되고 Windows의 밝은 기본색(흰색 배경, 검은색 텍스트)으로만 떠버린다는 뜻입니다.

이는 CSS/Electron API로 해결 불가능한 플랫폼 제약입니다.

**사람 결정(2026-09-25) - 범위 재조정:**

옵션 수에 따라 두 가지로 나눴습니다:

1. **고정 소수 옵션 select 3종류·4곳** (장기/단기 선택, 진행중/완료/보류, 우선순위)
   - 팝업 자체를 없애기 위해 새 컴포넌트 **`FieldToggleGroup`** (토글 버튼 그룹)으로 **교체**
   - Projects.jsx의 AddProjectForm(유형 선택, 2개 버튼)
   - ProjectEditForm.jsx(유형 선택, 2개 버튼 + 상태 선택, 3개 버튼)
   - TodoEditForm.jsx(우선순위 선택, 4개 버튼)
   - 팝업이 없으니 테마 미적용 문제가 원천적으로 생기지 않음
   - 옵션을 모두 펼쳐 놓는 형태이므로 420px 제약에서 텍스트 잘림 위험 발생 → 하단 참고

2. **가변 옵션 select 3곳** (프로젝트 선택 — TodoAddForm/TodoEditForm/Memos.jsx)
   - 항목 수가 늘어날 수 있어 토글 버튼으로 대체 불가
   - 네이티브 select를 **유지**
   - 옵션 팝업의 다크 테마 미적용은 **알려진 한계로 문서화하고 수용**
   - 닫힌 상태의 필드 모양(배경, 테두리, 반경, 커스텀 화살표)은 여전히 다른 select들과 통일됨

3. **date 입력 7곳**
   - 모두 CSS로 통일
   - 달력 아이콘은 `:root`의 `color-scheme: dark`가 이미 브라우저에서 밝은 기본 아이콘을 렌더하므로 별도 색 필터는 쓰지 않음
   - hover/disabled에서 opacity만 조절해 상태 피드백 제공

**구현 중 추가 발견 - 420px 폭 레이아웃 문제:**

토글 버튼 그룹으로 교체한 후 Playwright로 다시 확인하니, 창 폭이 420px(최소값)일 때:
- ProjectEditForm: 프로젝트 상태 토글(3개 버튼) + 마감일 입력 + 저장·취소 버튼이 한 줄에 몰렸을 때 텍스트 잘림
- TodoEditForm: 상태 토글(3개) + 우선순위 토글(4개) = 총 7개 버튼이 한 줄에 들어가지 않아 줄바꿈 + 텍스트 잘림

해결책: 상태·우선순위 토글을 **별도 행으로 분리** (ProjectEditForm에서 프로젝트 상태 토글은 첫 줄에, TodoEditForm에서 우선순위 토글은 별도 줄로)
