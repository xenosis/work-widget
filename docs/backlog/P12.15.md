# P12.15 — 테마 적용 커스텀 드롭다운/날짜 선택 컴포넌트 구현

## 목적

P12.14에서 커스텀 컴포넌트 교체를 결정한 경우, 완전한 다크 글래스 테마를 적용한 드롭다운과 날짜 선택기 컴포넌트를 만들어 기존 select/date 입력들을 교체합니다.

## 쉬운 설명

P12.14에서 "(2) 자체 구현" 또는 "(3) 라이브러리"를 선택한 경우, 이 task에서 구현합니다:

**자체 구현 경우:**
- `src/components/CustomSelect.jsx` — select 대체 컴포넌트
  - 펼침/접힘 상태 관리
  - 키보드 조작(↑/↓/Home/End/Enter/Esc)
  - listbox ARIA role 적용
  - 테마 색 적용
  
- `src/components/CustomDatePicker.jsx` — date 입력 대체 컴포넌트
  - `scheduleGrid.getMonthGrid` 재사용 (주말/공휴일 색 공유)
  - 월 이동 네비게이션
  - 날짜 선택
  - 테마 색 적용
  
- 기존 11곳(select 7 + date 4) 모두 교체

**라이브러리 도입 경우:**
- 선택된 라이브러리(react-select, react-datepicker 등) 설치
- 기존 마크업 교체
- 테마 색 맞춤 설정

## 필요한 입력

- P12.14 결정 결과: 자체 구현 vs 라이브러리
- P12.13 결과: 트리거 테마 스타일
- P12.6 결과: 주말 색 토큰, `scheduleGrid.getMonthGrid` 구현
- P12.8 (있다면): 공휴일 정보/판정 함수
