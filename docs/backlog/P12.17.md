# P12.17 — 일정 추가/수정 폼 + 달력에 카테고리 색상 반영

## 목적

P12.16에서 만든 카테고리를 ScheduleAddForm과 ScheduleEditForm에서 선택할 수 있도록 UI를 추가하고, 월간/주간 뷰 셀과 날짜 상세 카드에서 일정별 카테고리 색상을 시각적으로 표시한다. 이를 통해 일정을 한눈에 카테고리로 구분할 수 있게 한다.

## 쉬운 설명

일정을 추가하거나 수정할 때, 제목/시간 외에 "어느 카테고리인가"를 선택할 수 있도록 드롭다운을 추가합니다. 그러면 달력에서 그 일정이 해당 카테고리의 색으로 표시됩니다. 예를 들어 "회의" 카테고리는 빨간색, "보고서" 카테고리는 파란색처럼 각각 다른 색으로 보여집니다.

또한 날짜를 선택했을 때 그 날의 일정 목록 왼쪽에 색깔 있는 막대가 나타나 카테고리를 한눈에 알 수 있게 합니다. 반복 일정은 달력 점 주위에 반짝이는 링이 생겨 반복 여부를 구분할 수 있습니다.

## 필요한 입력

- **P12.16** 완료 — schedule_categories 데이터 모델, 카테고리 CRUD 로직, getUsableCategories 헬퍼 함수
- **P12.9** 완료 — 월간/주간 셀 일정 정보 표시 개선 (셀 레이아웃)
- **P12.3** 완료 — 다크 글래스 테마 색상 및 CSS 토큰
- **categoryPalette.js** — 카테고리 색상 팔레트(red/orange/yellow/green/blue/purple/gray) 및 resolveCategoryColor 함수
- **scheduleGrid.js** — getScheduleCellSummary, getScheduleDotClassName 헬퍼 함수
- `src/index.css` — 카테고리 색상 클래스(`is-red`, `is-blue` 등)와 `.schedule-item-colorbar`, `is-recurring-ring` 스타일

    - 미분류면: `schedule-item-colorbar is-none` (옅은 테두리)
  - 이 색상 언어는 달력 점의 색상과 일치하므로 사용자가 카테고리를 일관되게 인식할 수 있음

### CSS 추가 (src/index.css)
- `.schedule-item-colorbar` — 일정 행 왼쪽 색상 막대 스타일
  - 너비 4px, 높이 전체
  - 각 카테고리 색상별 클래스 (is-red/is-orange/is-yellow/is-green/is-blue/is-purple/is-gray, is-none)
- `is-recurring-ring` — 반복 일정을 나타내는 점 주위 링 스타일
  - `box-shadow: inset 0 0 0 1.5px currentColor` 등으로 점 테두리 표시

### 데이터 정규화
- 폼에서 선택한 `categoryId` (문자열 또는 '')를 일정 저장 시 `category_id: categoryId || null`로 정규화
- 수정 폼에서 손상된 타입의 category_id를 초기 state에서 '' (미분류)로 정규화

## done_when을 확인하는 방법

### 1. 폼에서 카테고리 선택 가능
- `npm run dev`로 앱 시작
- 일정 추가 화면(Schedule 탭 → "새 일정 제목" 입력창 아래)에서 카테고리 `<select>` 엘리먼트가 보이는가
- "미분류"를 포함해 P12.16에서 만든 카테고리 목록이 표시되는가
- 카테고리를 선택하고 일정을 저장했을 때, data.json의 해당 schedule 레코드에 `"category_id": "<선택한 id>"`가 저장되는가 (또는 미분류면 `"category_id": null`)
- 수정 화면에서 기존 카테고리가 선택된 상태로 표시되고 변경 가능한가

### 2. 달력 셀에 카테고리 색상 표시
- 월간 뷰의 각 셀에 있는 일정 점들이 카테고리 색으로 표시되는가
  - 다양한 카테고리가 있는 일정들을 몇 개 만들어 본다
  - 각 점이 해당 카테고리의 색(빨강/파랑/초록 등)으로 보이는가
  - 미분류 일정은 옅은 테두리만 있는 빈 점(is-none)으로 보이는가
- 주간 뷰에서도 동일하게 색상 표시되는가
- 같은 셀에 여러 카테고리 일정이 있을 때 각각 구분되는가

### 3. 반복 일정 링 표시
- 반복 일정의 점 주위에 반짝이는 링(box-shadow로 그린 테두리)이 보이는가
- 일회성 일정은 링이 없는가 (색상 점만 있는가)
- 반복 일정의 링과 카테고리 색상이 동시에 표시되는가 (색상은 점, 링은 테두리)

### 4. 날짜 상세 카드에 색상 표시
- 달력에서 날짜를 클릭하면 그 날의 일정 목록 카드가 나타난다
- 각 일정 행의 왼쪽에 카테고리 색상 막대(4px 너비)가 표시되는가
- 막대 색상이 달력 점의 색상과 일치하는가
- 미분류 일정은 옅은 회색 막대(is-none)로 보이는가

### 5. 카테고리 미지정 일정 안정성
- 카테고리를 선택하지 않고 일정을 추가했을 때, 달력과 상세 카드에서 정상 표시되는가
- 에러 콘솔에 경고나 오류가 없는가
- 미분류 일정과 카테고리가 있는 일정이 섞여 있어도 정상 표시되는가

### 6. 데이터 형식 검증
- 손상된 data.json (category_id가 숫자, 불린, 객체 등 문자열이 아닌 경우)에서도 앱이 정상 로드되는가
- 수정 폼에서 손상된 category_id를 '' (미분류)로 정규화해서 보여주는가
- 저장 시 올바른 형식(문자열 또는 null)으로 정규화되는가
