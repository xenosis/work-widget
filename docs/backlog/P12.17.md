# P12.17 — 일정 추가/수정 폼 + 달력에 카테고리 색상 반영

## 목적

P12.16에서 만든 카테고리를 ScheduleAddForm과 ScheduleEditForm에서 선택할 수 있도록 UI를 추가하고, 월간/주간 뷰 셀과 날짜 상세 카드에서 일정별 카테고리 색상을 시각적으로 표시한다.

## 쉬운 설명

일정을 추가하거나 수정할 때, 제목/시간 외에 "어느 카테고리인가"를 선택할 수 있도록 드롭다운을 추가합니다. 그러면 달력에서 그 일정이 해당 카테고리의 색으로 표시됩니다. 예를 들어 "회의" 카테고리는 빨간색, "보고서" 카테고리는 파란색처럼 각각 다른 색으로 보여집니다.

## 필요한 입력

- P12.16에서 구현된 카테고리 데이터 모델 및 CRUD 로직
- P12.9의 일정 정보 표시 개선 (셀에 여러 일정이 표시될 때의 UI)
- scheduleGrid.js의 주말/공휴일 색상 정보 (P12.6, P12.8)
- 카테고리 미지정 일정의 기본 색상 (예: 회색, 또는 색상 없음)

## 결과물

### 폼 UI
- ScheduleAddForm.jsx와 ScheduleEditForm.jsx에 카테고리 선택 드롭다운 추가:
  - P12.16에서 만든 카테고리 목록 표시
  - 카테고리 미지정 옵션 (예: "분류 없음" 또는 빈 선택)
  - 선택한 카테고리의 색상 미리보기

### 데이터 저장
- 폼에서 선택한 category_id를 일정 객체에 저장
- 기존 due_date 처리와 동일한 방식으로 정규화

### 달력 표시
- 월간 뷰(ScheduleMonthView.jsx) 및 주간 뷰(ScheduleWeekView.jsx):
  - 각 일정 점/마크에 카테고리 색상 적용
  - P12.9의 일정 개수/유형 표시와 함께 색상으로 구분
  - 같은 날에 여러 카테고리의 일정이 있으면 각각 다른 색으로 표시
  
- 날짜 상세 카드(ScheduleDateDetail.jsx):
  - 일정 목록에서 각 일정 옆에 카테고리 색상 표시 (색상 박스 또는 왼쪽 테두리)
  - 카테고리명 표시 (선택사항)

### CSS
- 카테고리별 색상 클래스 동적 생성 또는 인라인 스타일 적용
- 주말/공휴일 색상과의 레이어링 (둘 다 적용되는 경우 처리)

### 테스트
- 카테고리 미지정 일정도 정상 표시되는지 확인
- 같은 날에 여러 카테고리 일정 혼합 시 색상 구분 가능한지

## 선행 작업

- **P12.16** — 일정 카테고리 데이터 모델 + 관리 화면 (카테고리 CRUD 로직이 먼저 필요)
- **P12.9** — 월간/주간 셀 일정 정보 표시 개선 (셀 레이아웃이 정해져야 색상 추가 가능)

## 수행 순서에서의 위치

P12.16과 P12.9가 모두 완료된 후 시작할 수 있습니다. P12 배치의 마지막 구현 task 중 하나입니다.

**선행**: P12.16(데이터 모델 + 관리 화면), P12.9(셀 정보 표시 개선)
**완료 후**: P12 배치 완료로 다크 글래스 테마 전체 완성도가 향상

## done_when을 확인하는 방법

다음 절차로 확인합니다:

1. **폼에서 카테고리 선택 가능**:
   - 일정 추가 화면에서 카테고리 드롭다운이 보이고, 클릭하면 목록이 펼쳐지는지 확인
   - 카테고리를 선택하고 일정을 저장했을 때, 그 일정의 category_id가 정상 저장되는지 (data.json 확인)
   - 수정 화면에서 기존 카테고리가 표시되고 변경 가능한지

2. **달력에서 카테고리 색상 표시**:
   - 월간 뷰에서 각 일정이 해당 카테고리의 색으로 표시되는지 (스크린샷)
   - 주간 뷰에서도 동일하게 색상 표시되는지
   - 같은 날에 여러 카테고리 일정이 있을 때 각각 구분되는지 확인

3. **날짜 상세 카드**:
   - 날짜를 선택하면 그 날의 일정 목록이 보이는데, 각 일정의 카테고리 색이 표시되는지
   - 카테고리명도 함께 표시되면 더 좋음 (선택사항)

4. **카테고리 미지정 일정**:
   - 카테고리를 선택하지 않고 일정을 추가했을 때, 달력에서 기본 색(또는 색상 없음)으로 표시되는지
   - 에러 없이 정상 로드/표시되는지

5. **스크린샷**:
   - 추가/수정 폼에서 드롭다운 및 색상 미리보기
   - 월간/주간 뷰에서 다양한 카테고리가 색으로 구분되는 모습
   - 날짜 상세 카드에서 색상 표시

6. **Lint/테스트/빌드 통과**:
   - `npm run lint` 통과
   - `npm test` 통과 (관련 테스트, scheduleGrid.js 등)
   - `npm run build` 통과

## 확인 필요

- **카테고리 색상 적용 방식**: 각 일정이 카테고리 색상을 어떻게 표시할지 구체적으로 결정 필요:
  - 일정 점/마크 전체를 카테고리 색으로 채울지
  - 아니면 테두리나 아이콘으로만 표시할지
  - 날짜 상세 카드에서는 어떻게 표시할지 (색상 박스, 왼쪽 테두리, 배경색 등)
  
- **주말/공휴일 색상과의 조합**: 공휴일이면서 특정 카테고리의 일정이 있을 때, 두 색상을 어떻게 동시에 표시할지 (예: 배경은 공휴일 색, 텍스트/테두리는 카테고리 색, 또는 둘 다 표시하기 어려우면 카테고리 색만 우선 등).

- **드롭다운 구현**: P12.14/P12.15에서 커스텀 DatePicker/Select를 구현할 예정인데, 이 task에서 카테고리 선택 드롭다운을 어떻게 구현할지:
  - P12.15의 커스텀 Select 컴포넌트를 재사용할지
  - 아니면 기존 HTML `<select>`를 사용할지 (P12.14 결정 범위에 포함되지 않을 수 있음)
