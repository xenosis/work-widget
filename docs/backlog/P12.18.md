# P12.18 — 삭제 2단계 확인 취소 버튼 스타일 정리(폰트 크기 불일치)

## 목적

프로젝트, 할일, 일정 편집 폼과 메모 화면의 삭제 2단계 확인 대화창에서 삭제 확인/취소 버튼 쌍의 폰트 크기가 서로 다르고, 취소 버튼의 `:hover` 상태에 `:disabled` 가드가 없어 비활성 중에도 마우스 효과가 보이는 두 가지 문제를 해결합니다. 이 작업은 P12.11(편집 폼 저장/취소 버튼 통일) 리뷰 중에 발견된 별도 이슈로 분리되었습니다.

## 쉬운 설명

프로젝트, 할일, 일정을 삭제하려고 하면 "정말 삭제할까요?"라는 확인 창이 뜹니다. 이 창의 "확인"과 "취소" 버튼을 보면 폰트 크기가 안 맞습니다:
- 프로젝트 "확인" 버튼(`.project-delete-button`): 11.5px
- 할일 "확인" 버튼(`.todo-delete-toggle`): 11px
- "취소" 버튼(`.back-button`): 12.5px

더 심각한 문제는 "취소" 버튼이 마우스를 올렸을 때의 효과를 정의하지만, 삭제가 진행 중일 때(disabled=true) 그 효과를 빼지 않아서, 사용자가 "아직 눌릴 수 있나?"라고 헷갈릴 수 있다는 것입니다.

이를 P12.11에서 저장/취소 버튼에 적용한 것과 같은 방식으로 고치겠습니다: `:hover:not(:disabled)` 선택자를 사용해 비활성 중엔 마우스 효과를 끕니다. 그리고 두 "확인" 버튼의 폰트 크기를 하나로 통일합니다.

## 필요한 입력

- `src/index.css`: 기존 스타일 정의
  - `.project-delete-button` (11.5px)
  - `.todo-delete-toggle` (11px)
  - `.back-button` (:hover 정의, 현재 :disabled 가드 없음)
  - `.project-delete-confirm`, `.todo-delete-confirm` 등 확인 대화창 컨테이너
- `src/components/ProjectEditForm.jsx` (DeleteProjectButton): `.project-delete-button` 정의 위치
- `src/components/TodoEditForm.jsx` (DeleteTodoButton): `.todo-delete-toggle` 정의 위치, 취소 버튼이 `.back-button` 사용 (196줄)
- `src/components/ScheduleEditForm.jsx`: 삭제 버튼 구조 (일정은 할일과 유사)
- `src/screens/Memos.jsx`: 메모 삭제 2단계 확인 대화창 구조

## 결과물

1. **CSS 폰트 크기 통일**: `src/index.css`에서 다음 클래스들의 폰트 크기를 통일
   - `.project-delete-button`: 현재 11.5px
   - `.todo-delete-toggle`: 현재 11px
   - 어느 값으로 통일할지는 요구사항 문서의 지침 또는 실측을 기준으로 결정 필요 (P12.11은 12.5px로 했으나, 이들은 더 가벼운 텍스트링크 패턴이므로 더 작은 값일 수 있음)

2. **`:hover` 가드 추가**: `.back-button:hover:not(:disabled)` 선택자로 변경
   - 현재 (756~758줄):
     ```css
     .back-button:hover {
       color: var(--text);
     }
     ```
   - 변경 후: `:disabled` 상태에서는 hover 효과 없음

3. **컴포넌트 변경**: 특별한 컴포넌트 변경은 필요 없음 (이미 `disabled` prop을 button에 전달하고 있음)
   - TodoEditForm의 DeleteTodoButton (196줄): `className="back-button" disabled={busy}`
   - CSS 수정만으로 동작 개선
