# P12.18 — 삭제 2단계 확인 취소 버튼 스타일 정리(폰트 크기 불일치)

## 목적

프로젝트, 할일, 일정, 메모 네 개 화면의 "삭제 확인/취소" 버튼 쌍이 각각 다른 폰트 크기(11.5px, 11px, 12.5px)를 사용하고 있어 사용자 경험이 일관되지 않다. 이를 통일하고, 비활성화된 상태에서도 마우스 호버 효과가 보이는 문제를 함께 해결한다.

## 쉬운 설명

삭제 대화창의 두 버튼(확인/취소)이 화면마다 글씨 크기가 다르다. 또한 삭제 처리 중에 취소 버튼이 비활성화되는데도 마우스를 올리면 색이 변해서 "아직도 누를 수 있나?"라고 헷갈린다. 이 작업은 네 군데 모두를 11.5px, padding 4px 0으로 통일하고, 비활성 상태에서는 호버 효과가 없도록 한다. 뒤로가기 버튼(실제 페이지 이동용, 12.5px)과 혼동하지 않도록 취소 버튼을 별도 클래스(.delete-cancel-button)로 분리한다.

## 필요한 입력

- P12.11 완료: 저장/취소 버튼 쌍의 :hover:not(:disabled) 가드 패턴
- src/index.css의 기존 .back-button, .project-delete-button, .todo-delete-toggle 규칙들
- 프로젝트/할일/일정/메모 4곳 삭제 확인 대화의 JSX 마크업

## 결과물

1. src/index.css에 새 클래스 .delete-cancel-button 추가 (폰트 11.5px, padding 4px 0, :hover:not(:disabled) 가드, :disabled에 opacity 0.6과 cursor default)
2. .project-delete-button에 padding 추가, :hover:not(:disabled) 및 :disabled 규칙 추가
3. 삭제 확인 컨텍스트(.todo-delete-confirm .todo-delete-toggle)로 범위 축소해 목록 행의 토글 버튼(11px)은 원래대로 유지
4. ProjectEditForm.jsx, TodoEditForm.jsx, ScheduleEditForm.jsx, Memos.jsx의 취소 버튼을 .back-button에서 .delete-cancel-button으로 변경
5. ProjectDetail.jsx의 실제 뒤로가기 버튼(.back-button, 12.5px)은 유지

## 선행 작업

- P12.11: 편집 폼 저장/취소 버튼 스타일 통일 및 :hover:not(:disabled) 패턴 도입

## 수행 순서에서의 위치

P12의 UI 폴리시 배치 중 하나. P12.11에서 확립한 호버 가드 패턴을 삭제 확인 버튼에도 동일하게 적용해 전체 폼의 버튼 상호작용을 일관되게 만든다. 이 작업 완료 후 P12.20(프로젝트 삭제 확인 호버 반응 추가)이 시작될 수 있다.

## done_when을 확인하는 방법

1. npm run dev로 앱을 띄운다.
2. 프로젝트/할일/일정/메모 네 화면 각각에서 삭제를 시도해 2단계 확인 대화를 연다.
3. 각 화면의 "확인" 버튼과 "취소" 버튼이 동일한 크기(11.5px, padding 4px 0)를 가지는지 DevTools 검사 또는 스크린샷으로 확인한다.
4. 취소 버튼을 마우스로 호버했을 때 색이 변하지 않는다(비활성화 시).
5. ProjectDetail의 실제 "뒤로가기" 버튼은 여전히 12.5px이고 호버에 반응함을 확인한다.
6. npm run lint — 0 errors
7. npm run build — 성공
