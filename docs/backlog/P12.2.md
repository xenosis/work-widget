# P12.2 — 타이틀바/창 컨트롤 다크 테마 적용 방식 결정

## 목적

Windows 창의 타이틀바와 최소화/최대화/닫기 버튼이 애플리케이션의 다크 글래스 테마와 시각적으로 일치하도록 구현 방식을 결정한다. 현재 Electron은 OS 기본 프레임을 사용하고 있어, 네이티브 버튼과 렌더러의 다크 톤이 맞지 않는 상태이다.

## 쉬운 설명

앱의 타이틀바(위쪽 회색 막대)와 창 컨트롤 버튼(최소화/최대화/X)이 앱의 어두운 배경색과 어울리지 않습니다. 이를 해결하는 방법이 세 가지 있는데:
- **(a)** OS 다크 모드만 적용 — 가장 간단하지만 색상을 정밀하게 맞출 수 없음
- **(b)** 타이틀바는 숨기고 네이티브 버튼만 유지 — 중간 난이도, 드래그 영역과 제목을 직접 구현해야 함
- **(c)** 완전 커스텀(frame:false) — 가장 복잡하지만 버튼까지 직접 만들 수 있음

**결정 결과 (2026-09-25)**: 완전 커스텀(frame:false)으로 진행 — 최소화/최대화/닫기 버튼까지 직접 구현하기로 결정했습니다.

## 필요한 입력

- 현재 `electron/main.js`의 BrowserWindow 설정 상태 확인
- 다크 테마의 구체적 색상값 (src/index.css에 정의된 토큰 참고)
- 창 드래그 영역과 타이틀바 높이에 대한 요구사항

## 결과물

- `electron/main.js`에 `frame:false` 설정 적용
- 커스텀 타이틀바 컴포넌트 (드래그 가능 영역, 앱 이름 표시, 최소화/최대화/닫기 버튼)
- `electron/preload.js`에 창 컨트롤용 IPC 핸들러 추가 (최소화, 최대화, 닫기)
- 타이틀바 스타일 CSS (다크 글래스 테마 적용)
- 새 프레임 기준으로 최소 창 높이 재측정 및 `MIN_WINDOW_SIZE` 업데이트
