## 배운 점: 왜 cancelled인가, 구현하지 않는가

1. **P12.13이 이미 검증 완료**: CSS 개선만으로도 select 외형을 충분히 개선 가능하다는 것을 확인했다.
2. **구현 비용 vs 효과**: 
   - 커스텀 드롭다운 = 새 컴포넌트 + max-lines 300 제약 하에서 ARIA/키보드 접근성 직접 구현 + 유지보수
