# P12.22 — electron/main.js 창 제어 IPC를 별도 파일로 분리(300줄 한도 여유 확보)

## 목적

P12.3(타이틀바/창 컨트롤 다크 글래스 테마 구현)이 완료된 후 electron/main.js가 299줄까지 증가했다. 프로젝트의 eslint.config.js 규칙에서 한 파일의 최대 길이를 300줄로 제한하므로, 다음에 이 파일을 수정하려는 어떤 작업이 단 한 줄만 추가해도 lint가 깨진다. 창 제어 관련 IPC 핸들러 4개(window:minimize, window:toggle-maximize, window:close, window:is-maximized)와 창 상태 변화 이벤트 리스너(maximize/unmaximize)를 별도 모듈로 분리하여 main.js에 여유(최소 20줄 이상)를 확보하고, 향후 작업들이 main.js를 자유롭게 수정할 수 있도록 한다.

## 쉬운 설명

Electron 앱의 메인 프로세스를 담당하는 electron/main.js 파일이 299줄까지 차 있고, 프로젝트의 코드 스타일 규칙(eslint)이 한 파일의 최대 길이를 300줄로 제한합니다. 따라서 지금 이 파일에 코드를 1줄만 추가하면 린트 검사에 걸립니다.

P12.3에서 추가한 창 제어 코드(최소화, 최대화, 닫기, 상태 조회의 IPC 핸들러 4개와 최대화 상태 변화 이벤트)를 `electron/windowControls.js`라는 별도 파일로 모아 main.js에서 분리하면:
- main.js 라인 수를 299줄에서 277줄로 줄여 23줄의 여유 확보
- 창 제어 로직만 깔끔하게 한 곳에 모을 수 있음
- 앱 시작 시 main.js는 단지 이 모듈을 불러와 등록하면 됨

이는 프로젝트에 이미 있는 windowState.js가 사용 중인 패턴과 동일합니다 — main.js의 복잡도를 줄이기 위해 관련 기능을 별도 모듈로 분리해 두는 구조입니다.

## 필요한 입력

- **P12.3 완료** — electron/main.js에 창 제어 IPC 핸들러 4개와 창 상태 이벤트 리스너가 이미 구현되어 있어야 함:
  - `ipcMain.on('window:minimize', ...)`
  - `ipcMain.on('window:toggle-maximize', ...)`
  - `ipcMain.on('window:close', ...)`
  - `ipcMain.handle('window:is-maximized', ...)` (Promise 반환)
  - `mainWindow.on('maximize'/'unmaximize', ...)` (렌더러로 상태 변화 전달)

- **기존 코드 참고**:
  - `electron/windowState.js` — 분리 패턴의 예시
  - `electron/main.js` — 분리할 코드 영역

## 결과물

**새로 생기는 것:**
- `electron/windowControls.js` — 신규 모듈
  - `registerWindowControls(getMainWindow)` — IPC 핸들러 4개 등록
    - `window:minimize`: 창 최소화
    - `window:toggle-maximize`: 창 최대화/복원 토글
    - `window:close`: 창 닫기 (실제 트레이 숨김 로직은 main.js의 'close' 이벤트 핸들러에서 처리, P12.3/B5.1 참고)
    - `window:is-maximized`: 현재 최대화 여부 조회
    - mainWindow는 getter 함수로 받아 항상 최신 참조 유지 (let으로 재할당되는 변수이므로)
  - `forwardMaximizeState(win)` — 창의 maximize/unmaximize 이벤트를 렌더러의 'window:maximized-changed' 채널로 전달 (TitleBar.jsx의 버튼 아이콘 동기화)
  - `module.exports = { registerWindowControls, forwardMaximizeState }`

**수정되는 것:**
- `electron/main.js`
  - 분리할 IPC 핸들러 4개와 이벤트 리스너 제거 (~16줄 절감)
  - `const { registerWindowControls, forwardMaximizeState } = require('./windowControls')` 추가
  - `createWindow()` 내부에서 `forwardMaximizeState(mainWindow)` 호출
  - 파일 하단에서 `registerWindowControls(() => mainWindow)` 호출
  - 최종 라인 수: 277줄 (299줄 → 277줄, 22줄 절감으로 요구한 최소 20줄 초과 달성)
