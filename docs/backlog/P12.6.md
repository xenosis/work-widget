# P12.6 — 달력 주말(토/일) 색 구분

## 목적

업무용 달력(월간/주간 뷰)에서 주중과 주말을 시각적으로 빠르게 구분할 수 있게 하는 것입니다. 주말 날짜(토/일)를 평일과는 다른 색으로 표시해 사용자가 한눈에 주중/주말 일정을 파악할 수 있게 합니다. 또한 후속 작업인 P12.8(공휴일 표시)의 기반이 되는 요일 판정 로직을 확립합니다.

## 쉬운 설명

현재 위젯의 달력 화면(월간 뷰, 주간 뷰)에서 모든 날짜가 같은 색으로 표시되어 주중/주말 구분이 어렵습니다. 이 작업에서는:

1. **요일 판정 함수** (`getWeekdayKind`)를 추가해 날짜에서 요일(평일/토/일)을 판단합니다.
2. **달력 렌더링 컴포넌트**에서 각 셀과 요일 헤더에 요일에 맞는 CSS 클래스(`is-saturday`, `is-sunday`)를 붙입니다.
3. **CSS 스타일**에서 토요일과 일요일에 고유한 색을 정의합니다:
   - 토요일: 파란 계열 색 (`--weekend-sat-text`)
   - 일요일: 빨간 계열 색 (기존 `--danger` 토큰)

4. **중요한 회귀 버그와 해결**: 초기 구현에서 `is-outside`(다른 달) 셀에 주말 색을 직접 지정했더니, 다른 달의 주말이 마치 이번 달 주말처럼 진하게 보여서 "다른 달이네"라는 흐린 신호가 사라지는 문제가 발생했습니다. 이를 해결하기 위해 `.schedule-day-cell.is-outside.is-saturday/is-sunday` 규칙에 `opacity: 0.55`를 추가해, 주말 색 자체를 흐리게 적용함으로써 두 신호(주말 색, 다른 달의 흐림)를 동시에 유지하게 되었습니다. Playwright로 실측 확인: 이번 달 토요일(oklch(0.72 0.13 250)/opacity 1) vs. 다른 달 토요일(같은 색/opacity 0.55)이 명확히 구분됩니다.

결과적으로 토요일은 파란 계열, 일요일은 빨간 계열로 표시되어, 사용자가 주중/주말을 한눈에 구분할 수 있게 됩니다.

## 필요한 입력

- **요일 판정 로직**: `src/lib/scheduleGrid.js`의 `getDayLabel` 함수가 이미 날짜에서 요일을 판정하고 있어서 같은 패턴으로 `getWeekdayKind` 함수를 만들 수 있습니다.
- **CSS 색상 토큰**: `--weekend-sat-text` (토요일 텍스트색, oklch(72% 0.13 250)) 토큰이 이미 정의돼 있고, 일요일은 기존 `--danger` 토큰(빨간 계열)을 재사용합니다.
- **달력 컴포넌트**: `ScheduleMonthView.jsx`, `ScheduleWeekView.jsx`에서 각 셀과 요일 헤더의 클래스명을 동적으로 조정할 수 있는 구조입니다.

## 결과물

1. **`src/lib/scheduleGrid.js`에 `getWeekdayKind` 함수 추가**: 
   - 입력: `dateString` (YYYY-MM-DD 형식)
   - 로직: 날짜의 요일(0=일~6=토)을 판정해 Saturday(6)면 `'saturday'`, Sunday(0)면 `'sunday'`, 그 외 평일이면 `'weekday'` 반환
   - 구현: `getDayLabel`과 동일하게 `split('-').map(Number)`로 파싱 후 `new Date(y, m-1, d).getDay()`로 요일 판정

2. **`src/lib/scheduleGrid.test.js`에 테스트 케이스 추가**: 
   - 기본 케이스 3개: 토요일(2026-09-26) → `'saturday'`, 일요일(2026-09-27) → `'sunday'`, 평일(2026-09-21 월, 2026-09-24 목) → `'weekday'`
   - **월 경계 포함 전수 검증** 1개: 3개월(9월 8/31 월요일 시작, 12월 연 경계, 11월 10/31 토 포함)의 모든 주를 순회하며 5,6번째 열이 정확히 토/일인지 확인 (총 26개 주)

3. **`ScheduleMonthView.jsx` 수정**:
   - 헤더: `WEEKDAY_HEADER_KINDS` 배열(["weekday", "weekday", ..., "saturday", "sunday"])로 고정
   - 셀: 각 cell마다 `getWeekdayKind(cell.date)` 호출해 weekday가 아니면 `is-${weekdayKind}` 클래스 추가

4. **`ScheduleWeekView.jsx` 수정**:
   - 7개 셀 각각에 `getWeekdayKind(date)` 호출해 weekday가 아니면 `is-${weekdayKind}` 클래스 추가
   - 요일 레이블(`getDayLabel` 출력)을 감싼 span 요소에도 weekday가 아니면 `is-${weekdayKind}` 클래스 추가

5. **`src/index.css` 색상 규칙**:
   - 기본 셀/헤더 규칙: `.schedule-day-cell.is-saturday .schedule-day-number`, `.is-sunday .schedule-day-number`, `.schedule-month-grid th.is-saturday/is-sunday`, `.schedule-weekday-label.is-saturday/is-sunday`로 색 적용
   - **`is-today` 조합**: `.schedule-day-cell.is-today.is-saturday`, `.schedule-day-cell.is-today.is-sunday` 선택자로 주말 색 우선순위 고정 (font-weight는 `.is-today` 값 상속, color만 주말 색)
   - **`is-outside` 조합 (회귀 수정)**: `.schedule-day-cell.is-outside.is-saturday .schedule-day-number`, `.is-outside.is-sunday .schedule-day-number`에 `opacity: 0.55` 적용 — 이 규칙이 없으면 다른 달 토/일이 이번 달처럼 진하게 보여 흐린 신호가 사라지므로, opacity로 주말 색을 흐리게 함
