# P12.8 — 달력 공휴일 표시

## 목적

P12.7(공휴일 데이터 출처 결정)에서 결정한 npm `korean-holidays` 패키지를 사용하여, 달력의 월간/주간 뷰에서 한국 공휴일(고정일, 음력 기반, 대체공휴일 포함)을 시각적으로 구분하고 이름을 확인할 수 있도록 하는 기능을 구현합니다.

## 쉬운 설명

## 결과물

### 1. 공휴일 판정 함수

**파일**: `src/lib/scheduleGrid.js`

```javascript
export function getHolidayInfo(dateString) {
  const [y, m, d] = dateString.split('-').map(Number);
  const holiday = isHoliday(new Date(y, m - 1, d));
  if (!holiday) return null;
  return { name: holiday.nameKo, isSubstitute: holiday.isSubstitute, isLunar: holiday.isLunar };
}
```

- 입력: "YYYY-MM-DD" 형식의 날짜 문자열 (예: "2026-09-25")
- 출력: 공휴일이면 `{ name: "공휴일명", isSubstitute: boolean, isLunar: boolean }` 객체, 평일이면 `null`
- 주의: 이 라이브러리는 Date 객체의 로컬 연/월/일만 사용하며 UTC 변환을 하지 않음 (테스트 주석에 문서화)

### 2. 달력 셀 공휴일 색상 및 CSS 규칙

**파일**: `src/index.css`

공휴일은 주말과 같은 색상 계열(`--danger` 빨간색, 일요일과 동일)을 사용합니다.

**색상 우선순위 및 겹침 처리**:
- `is-saturday` + `is-holiday`: 명시적 조합 선택자 `is-saturday.is-holiday { color: var(--danger); }`로 공휴일 색이 항상 우선
- `is-today` + `is-holiday`: 공휴일 색 유지, 오늘 신호는 굵기(font-weight)로만 표현
- `is-outside` + `is-holiday`: `opacity: 0.55`로 흐리게 표시하되 공휴일 색 신호 유지
- 주간 뷰 요일 라벨도 동일 규칙 적용 (critical-reviewer 지적 후 추가)

### 3. 공휴일 이름 표시
