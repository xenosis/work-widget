# P12.9 — 월간/주간 셀 일정 정보 표시 개선(개수·유형·제목 미리보기)

## 목적

사용자가 월간 및 주간 캘린더의 날짜 셀에서 클릭 없이도 그 날에 어떤 일정들이 있는지(개수, 반복/일회성 구분, 제목 목록)를 한눈에 파악할 수 있도록 셀의 정보 표시를 개선하는 것. P5.2의 의도된 설계에 따라 420px 폭 제약으로 "일정 유무"만 점 하나로 표시하기로 했으나, 스키마 변경 없이 클릭 없는 정보 제공을 늘려 사용성을 개선하는 것이 목표입니다.

## 쉬운 설명

**이전**: 날짜 셀에 검은 점 하나만 표시 → "이 날에 일정이 있다"는 사실만 알 수 있고, 몇 개인지, 무엇인지는 클릭해야 봄

**이후**: 
- 점을 여러 개 표시(최대 3개, 초과하면 "+2" 같은 개수 텍스트로 표시)
- 반복 일정은 한 색(--accent, 파란 톤), 일회성 일정은 다른 색(--priority-mid, 오렌지 톤)으로 구분하고 **범례로 설명**
- 마우스로 셀 위에 올리면 공휴일 이름과 일정 제목들이 **네이티브 툴팁**(title 속성)에 떠서 클릭 없이 정보 확인 가능
- 키보드/스크린리더 사용자를 위해 셀 버튼의 `aria-label`에 "{n}일, 일정 {count}개"(주간뷰는 요일 포함) 명시

예: 9월 26일(추석 연휴) 셀에 반복 회의 1개 + 일회성 병원 예약 1개가 있으면:
- 파란 점 1개 + 오렌지 점 1개 표시
- 마우스 호버 시 "추석 연휴 · 주간 회의, 병원 예약" 네이티브 툴팁 표시
- 버튼 이름은 "26일, 일정 2개" (스크린리더용)

## 필요한 입력

- **전체 일정 데이터** (`data.json`의 `schedules` 배열): Schedule 스키마는 변경 없음 (B3.4 기준).
- **월간/주간 뷰 렌더링 컴포넌트**: ScheduleMonthView.jsx, ScheduleWeekView.jsx가 이미 존재하고 날짜 셀 구조를 가지고 있음.
- **일정 그리드 계산 라이브러리**: scheduleGrid.js가 이미 있어서 getSchedulesForDate() 같은 헬퍼 함수를 재사용 가능.

## 결과물

   - `getScheduleCellSummary(schedules, dateString, maxDots=3)`: 주어진 날짜의 일정 목록을 반복/일회성 점 정보(최대 maxDots개) + 초과 카운트 + 제목 목록으로 요약하는 순수 함수

## done_when을 확인하는 방법

다음을 모두 확인:

1. **다중 점 표시 및 색 구분 확인**:
   - 테스트 데이터에서 일정 2개 이상(반복 1개 + 일회성 1개 이상)이 있는 날짜를 월간 뷰에서 찾기
   - 그 셀을 보면 점이 여러 개 표시되고, 반복(파란색) vs 일회성(오렌지색)이 색으로 구분되는지 확인
   - 주간 뷰에서도 동일하게 작동하는지 확인
   - 범례가 Schedule.jsx에 표시되는지 확인

2. **초과 표시 확인**:
   - 일정 4개 이상이 있는 날짜에서 점 3개 + "+1"(또는 초과분 개수) 텍스트가 8.5px 크기로 보이는지 확인

3. **호버 툴팁 확인**:
   - 마우스를 일정이 있는 셀에 올리면 공휴일 이름(있을 경우, 예: "추석 연휴")과 일정 제목들("주간 회의, 병원 예약" 형태)이 네이티브 OS 툴팁으로 떠야 함
   - 공휴일이 없는 일정만 있는 날은 제목만 표시되어야 함

4. **접근성 확인** (키보드/스크린리더):
   - 셀 버튼에 `aria-label` 속성이 있고, "+N" 텍스트가 `aria-hidden`으로 숨겨져 있는지 개발자 도구로 확인
   - 스크린리더(예: NVDA) 시뮬레이션으로 "26일, 일정 2개" 같은 라벨이 읽히는지 확인
   - 제목 목록은 aria-label에 포함되지 않고 title에만 있음을 확인 (의도된 설계)

5. **셀 높이 안정성 확인**:
   - 창 폭을 420px로 고정해서 월간 뷰와 주간 뷰 스크롤
   - 점이 0개인 셀, 1~3개인 셀, "+N" 오버플로우가 있는 셀이 모두 동일한 높이를 유지하는지 확인 (높이 흔들림 없음)
   - 가로 스크롤이 생기지 않는지 확인
   - 다른 달 날짜(is-outside)의 점이 흐려지는지(opacity:0.55) 확인
   - **실제 Playwright 검증 결과**: 혼합 2개 셀과 4개(overflow 발생) 셀, 0개 셀의 `.schedule-day-cell` 높이가 월간 38px, 주간 52px로 모두 동일하며, 420px 창에서 가로 스크롤 없음을 확인 완료

6. **테스트 통과**:
   - `npm test` 실행 → vitest 테스트가 모두 통과하는지 확인 (scheduleCellSummary.test.js의 10개 신규 테스트 포함, 전체 240개 통과 확인됨)

7. **린트와 빌드**:
   - `npm run lint` → 0 errors 확인 (최종 확인: lint 0 errors)
   - `npm run build` → 성공 확인 (최종 확인: build 성공)
