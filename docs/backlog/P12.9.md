# P12.9 — 월간/주간 셀 일정 정보 표시 개선(개수·유형·제목 미리보기)

## 목적

달력 셀이 '일정이 있다'는 점만 보여주고 내용을 알 수 없는 문제를 개선해서, 셀만 보고도 무슨 일정이 있는지 미리 알 수 있게 합니다.

## 쉬운 설명

현재 달력 월간/주간 뷰에서 일정이 있는 날짜는 점(●) 하나만 표시됩니다. 어떤 일정이 있는지 알려면 그 날짜를 클릭해서 상세 정보를 봐야 합니다.

이 작업은 뷰를 개선해서:
1. **점의 개수/색**: 반복/일회성 일정을 색으로 구분하고, 일정 2개 이상이면 점 여러 개 표시(예: 점 2개, 또는 '+2' 표시)
2. **Hover tooltip**: 셀 위에 마우스를 올리면 일정 제목 목록을 tooltip으로 표시
3. **aria-label**: 스크린 리더 사용자도 일정 개수/제목을 알 수 있도록 접근성 개선
4. **폭 제약 준수**: 420px 창에서도 셀 높이가 변하지 않고 가로 오버플로 없음

## 필요한 입력

- `src/lib/scheduleGrid.js` — 월간 그리드 데이터 구조
- `src/components/ScheduleMonthView.jsx` — 월간 셀 렌더링
- `src/components/ScheduleWeekView.jsx` — 주간 셀 렌더링
- `src/index.css` — 셀 스타일
- `work-widget-requirements.md` B2.4 절 — 원래 설계 의도(P5.2 "420px 폭 제약 때문에 점 하나만")

## done_when을 확인하는 방법

1. **시각적 확인 (일정 2개 이상인 날짜)**:
   - 같은 날짜에 일정 2개 이상이 있는 날을 찾음
   - 달력 셀에서 점이나 배지로 개수를 표시하는지 확인
   - 반복/일회성을 색으로 구분하는지 확인
   - 스크린샷 1장

2. **Hover/Tooltip 확인**:
   - 일정이 있는 셀 위에 마우스를 올리면 tooltip이 나타나는지 확인
   - Tooltip에 일정 제목(들)이 보이는지 확인
   - 스크린샷 1장

3. **레이아웃 확인**:
   - 420px 폭 창에서 셀의 높이가 일정 개수에 따라 변하지 않는지 확인 (고정 높이 유지)
   - 셀이 가로로 잘리거나 오버플로되지 않는지 확인
   - 스크린샷 1장

4. **접근성 확인**:
   - 개발자 도구에서 셀의 `aria-label` 속성 확인
   - 예: `aria-label="October 15, 2026. 2 recurring, 1 one-time schedule"` 형태

5. **코드 검증**:
   - `npm run build` — 빌드 성공
   - `npm test` — vitest로 셀 요약 계산 함수 테스트 통과
   - `npm run lint` — eslint 통과

6. **문서**:
   - `work-widget-requirements.md` B2.4 절에 구현 결과 기록

## 확인 필요

- **일정 개수 표시 방식**: 점 여러 개(●●) vs 배지('+2') vs 혼합 — 명확한 디자인 정의 필요
- **점의 크기/색**: 반복과 일회성을 구분할 색 정의 필요 (예: 반복은 밝은 파랑, 일회성은 회색)
- **Tooltip 구현**: 기존 tooltip 라이브러리 있는지, 아니면 CSS :hover로 구현할지 확인 필요
