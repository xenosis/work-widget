# P13 — 앱 이름/아이콘 리브랜딩

## 목적

사용자 피드백에 따라 현재 앱의 이름("업무 위젯")과 아이콘(청록 원+흰 체크마크)을 더 세련되고 전문적인 것으로 변경한다. 이는 P12 배치와 무관한 별개의 범주적 개선으로, 앱의 브랜딩과 시장성을 높인다.

## 쉬운 설명

지금 앱의 이름이 "업무 위젯"이고 아이콘이 단순한 원 모양에 체크마크인데, 이것이 너무 투박해 보인다는 사용자 피드백이 있습니다. 더 나은 이름과 아이콘으로 바꾸고 싶은데, 구체적으로:
- **이름 방향**: 영문/한글/병기 중 무엇을 원하는지, 어떤 느낌(미니멀, 전문적, 친근함 등)을 원하는지
- **아이콘 스타일**: 현재의 단순 심볼에서 벗어나 어떤 방향으로 할지(복잡한 일러스트, 더 정교한 심볼, 특정 색상 등)

이것을 결정해야 실제 변경 작업(이름 변경, 새 아이콘 디자인, 패키징 설정 수정 등)을 할 수 있습니다.

## 필요한 입력

현재 사람 판단이 필요한 상태입니다. 다음을 결정해 주세요:

1. **새 이름 방향**:
   - 언어: 영문 / 한글 / 영문+한글 병기 / 기타
   - 어감: 미니멀/모던, 전문적, 친근함, 기타 느낌
   - 후보 키워드나 참고하고 싶은 이름이 있다면

2. **아이콘 스타일**:
   - 지금은: 단색 원(청록) + 흰 체크마크
   - 원하는 방향: 더 복잡한 일러스트, 미니멀 심볼, 특정 색상 계열, 참고하고 싶은 다른 앱 아이콘 등

3. **appId 변경 여부**:
   - 현재 appId: `app.workwidget.desktop` (P8.1에서 사람 확인을 거쳐 확정, NSIS 설치 GUID에 사용됨)
   - 새 이름으로 이것도 바꿀지 확인 필요

## 결과물

(결정 후 변경할 범위)

- **package.json**: `productName` 필드 변경 (표시 이름)
- **앱 아이콘**: `electron/assets/app-icon.ico` 교체 (윈도우 실행 파일 아이콘)
- **트레이 아이콘**: `electron/assets/tray-icon.png`, `tray-icon-hover.png` 등 교체
- **아이콘 생성 스크립트**: 
  - `scripts/lib/pngIcon.js` — 소스 SVG → PNG 생성 로직 수정
  - `scripts/gen-tray-icon.js`, `scripts/gen-app-icon.js` — 새 아이콘으로 재생성
- **UI 내 앱 이름 표기**: `src/components/Sidebar.jsx` 등에서 앱 이름 표시 부분 수정
- **요구사항 문서**: `work-widget-requirements.md`에 새 브랜딩 결정 문단 추가 (선택사항)
- **appId** (필요시): electron 설정과 NSIS 설치 스크립트에서 변경

## 선행 작업

없음 (최상위 task, parent=null)

## 수행 순서에서의 위치

P12 배치와는 무관한 별개 task입니다. P13은 사용자의 피드백 사항으로 새로 등록되었으며, 현재 **needs_info** 상태이므로 실제 구현은 위의 세 가지 질문에 대한 답변을 받은 후에 가능합니다.

**의존 task 없음** — 이름/아이콘 변경 자체는 다른 기능에 영향을 주지 않음 (단, 패키징/배포 설정 변경 필요)

## done_when을 확인하는 방법

이 task는 현재 **needs_info** 상태이므로, 다음이 완료될 때 done으로 전환됩니다:

1. **사람이 위 세 가지 결정을 제공**:
   - 새 이름 방향 (언어, 어감, 후보)
   - 아이콘 스타일 방향
   - appId 변경 여부

2. **새 이름과 아이콘 방향을 기록**:
   - `work-widget-requirements.md` 또는 별도 문서에 결정 내용 기록

3. **(필요시) 새 아이콘 디자인 제공 또는 지침**:
   - 디자이너가 새 아이콘을 만들거나
   - 기존 아이콘 생성 스크립트(scripts/lib/pngIcon.js)를 수정해 새 아이콘 생성

4. **설정 파일 및 UI 업데이트**:
   - `package.json`의 `productName` 변경
   - 아이콘 파일(electron/assets/) 교체
   - src의 UI에서 앱 이름 표시 부분 수정
   - `npm run build`/`npm run dist` 통과 확인

5. **스크린샷/확인**:
   - 새 이름과 아이콘이 적용된 창 (트레이 아이콘 포함)
   - Windows 설치 프로그램(electron-builder)에서 새 이름/아이콘 표시

## 확인 필요

**(매우 중요) 현재 needs_info 상태입니다. 다음 질문들에 대한 구체적인 답변이 필요합니다:**

1. **새 이름**:
   - 영문/한글/병기 중 무엇을 원하시나요?
   - 어떤 어감이나 스타일을 선호하시나요? (예: 미니멀/모던, 전문적, 친근함, 우아함 등)
   - 구체적 후보 이름이나 참고하고 싶은 비슷한 앱/서비스가 있나요?

2. **아이콘**:
   - 현재 "단색 원+체크마크"에서 벗어나 어떤 방향으로 원하시나요?
   - 더 복잡한 일러스트? 미니멀 심볼? 특정 색상 계열?
   - 참고하고 싶은 다른 앱 아이콘(예: Notion, Todoist, Microsoft To Do 등)이 있나요?

3. **appId**:
   - 현재 `app.workwidget.desktop`을 새 이름에 맞춰 변경할까요?
   - (주의: appId는 Windows 설치 GUID에 사용되므로 변경 시 기존 설치본과의 호환성 고려 필요)

**위 세 가지가 모두 결정되면 "결정 결과" 섹션을 업데이트하고 구현을 진행할 수 있습니다.**
