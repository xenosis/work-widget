# P13 — 앱 이름/아이콘 리브랜딩

## 목적

사용자 피드백(2026-09-26)에 따라 현재 앱의 이름("업무 위젯")과 아이콘(청록 원에 흰 체크마크)을 더 세련되고 전문적인 것으로 변경합니다. 이는 단순한 표시 이름 변경을 넘어, 패키징·배포 설정(appId, executableName)과 아이콘 생성 파이프라인까지 함께 리팩터링하는 작업입니다.

## 쉬운 설명

이 앱의 이름이 "업무 위젯"이고 아이콘이 단순한 원 모양에 체크마크인데, 사용자 피드백에서 이것이 너무 투박해 보인다고 했습니다. 새로운 이름(TaskDock)과 더 세련된 아이콘으로 바꾸고, 그에 맞춰:

- **package.json**에서 앱 이름(`name`, `productName`) 변경
- **Windows 설치 시 ID**(appId) 변경  
- **아이콘 파일** 교체 (트레이 아이콘, 실행 파일 아이콘)
- **아이콘 생성 스크립트** 재작성 (기존 원형 생성 로직 대신 새 원본 이미지에서 여러 크기로 리사이징)
- **사이드바와 타이틀바**에서 보이는 앱 이름 표시 변경

## 필요한 입력

- **새 이름**(TaskDock으로 이미 결정됨)
- **새 아이콘 원본 이미지** (사용자가 GPT 아이콘 생성기로 만든 이미지 — 1254×1254 PNG, 알파 채널 없음)
- **appId 변경 여부 승인** (기존: `app.workwidget.desktop` → 새: `app.taskdock.desktop` 또는 유사)

## 결과물

### 1. 설정 파일 업데이트 (`package.json`)
- `name`: "work-widget" → "taskdock"
- `productName`: "업무 위젯" → "TaskDock"
- `appId`: "app.workwidget.desktop" → "app.taskdock.desktop"
- `executableName`: "업무위젯" → "TaskDock"

### 2. 아이콘 원본 저장 (`scripts/assets/icon-source.png`)
- 사용자가 제공한 GPT 생성 아이콘 원본(1254×1254 PNG)을 이 경로에 저장
- 이를 여러 크기로 리사이징하는 새 파이프라인의 입력으로 사용

### 3. 아이콘 생성 파이프라인 재작성
- **`scripts/lib/resizePng.js`** (신규):
  - `pngjs` 라이브러리 기반 PNG 리사이징 함수
  - 원본 이미지를 지정된 크기(16, 32, 48, 256 등)로 리사이징
  - 출력: PNG 형식

- **`scripts/gen-app-icon.js`** (수정):
  - `scripts/assets/icon-source.png`에서 다양한 크기(16×16, 32×32, 48×48, 256×256)의 PNG 생성
  - 이들을 `electron/assets/app-icon.ico`에 PNG-in-ICO 형식으로 패킹

- **`scripts/gen-tray-icon.js`** (수정):
  - `scripts/assets/icon-source.png`에서 16×16, 32×32 PNG 생성
  - `electron/assets/tray-icon.png` 및 `tray-icon@2x.png`로 저장

- **`scripts/lib/pngIcon.js`** (삭제):
  - 기존 원형 아이콘 생성 로직(circle + checkmark) — 더 이상 필요 없음

### 4. 아이콘 파일 업데이트 (`electron/assets/`)
- `app-icon.ico`: 16×16, 32×32, 48×48, 256×256 PNG를 포함한 멀티 레졸루션 ICO 파일
- `tray-icon.png`: 16×16 PNG (표준 DPI)
- `tray-icon@2x.png`: 32×32 PNG (고해상도 DPI)

### 5. UI 내 앱 이름 표기 업데이트
- **`src/components/TitleBar.jsx`**: "업무 위젯" → "TaskDock"
- **`electron/main.js`**: 트레이 아이콘 툴팁 텍스트 "업무 위젯" → "TaskDock"
- **`index.html`**: 표시 이름 변경

### 6. 요구사항 문서 (선택)
- **`work-widget-requirements.md`**: 새 이름과 아이콘 변경 결정 사항 기록 (추적성)
