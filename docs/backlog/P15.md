# P15 — 설정 탭 추가 및 화면 재구성

## 목적

이 위젯의 사이드바는 원래 5개 탭으로 고정 운영되었고, 자주 쓰지 않는 기능(일정 카테고리 관리, 외부 백로그 소스 관리)은 관련 화면 안에 접이식 패널로 숨겨두는 방침을 따랐습니다. 하지만 실제 사용 피드백(2026-09-26)에서 그 반대가 더 불편하다는 것이 밝혀졌습니다 — 일정 화면을 열 때마다 관리 토글이 캘린더보다 먼저 보여서 "캘린더가 화면을 열자마자 바로 보였으면 좋겠다"는 요청을 받았습니다. P15는 이전 결정(P12.16)을 번복하여 사이드바에 6번째 메뉴 "설정"을 추가하고, 두 관리 UI를 그곳으로 옮기며, 함께 외부 백로그 현황 패널을 일정 화면 맨 아래로 이동시켜 캘린더-우선 노출을 달성합니다.

## 쉬운 설명

이 위젯이 사이드바를 5개 탭(대시보드/프로젝트/할일전체/메모/일정)으로 유지해온 이유는, "자주 쓰지 않는 설정 기능을 위해 메뉴를 늘리기보다 관련 화면 안에 숨겨두는 게 낫다"는 판단 때문이었습니다.

그런데 실제로 앱을 쓰다 보니 이것이 역효과였습니다:
- 일정 화면을 열면 가장 먼저 보이는 게 "카테고리 관리 ▼" 토글
- 그다음 "외부 백로그(.json) 소스 관리 ▼" 토글
- 스크롤을 내려야 캘린더가 보임

사용자 피드백: "캘린더가 화면을 열자마자 바로 보였으면 좋겠습니다."

**P15가 하는 일:**

1. **새 탭 추가**: 사이드바에 6번째 메뉴 "설정"을 추가합니다. 아이콘은 톱니바퀴 모양(SettingsIcon)입니다.
2. **관리 UI 이동**: 일정 카테고리 관리와 백로그 소스 관리를 "설정" 탭의 전용 화면(Settings.jsx)으로 옮깁니다.
3. **접이식 토글 제거**: 이제 관리 UI가 자신의 화면을 가지므로, "펼침/접힘" 토글을 없애고 항상 펼친 상태로 보여줍니다.
4. **일정 화면 정리**: 일정 화면은 이제 탭(월간/주간) 바로 다음에 캘린더가 나타납니다.
5. **백로그 현황 이동**: 외부 백로그 현황 조회 패널(읽기 전용)은 설정이 아닌 "조회"라 일정 화면에 남겨두되, 위치를 맨 아래(날짜 상세 카드 다음)로 옮겨 캘린더 우선 노출을 지킵니다.

## 필요한 입력

- **기능적 기반**: P14.1(외부 백로그 소스 관리 UI), P12.16(일정 카테고리 관리 UI), P14.2(백로그 현황 패널)이 이미 구현돼 있어야 합니다.
- **아이콘 시스템**: 다른 사이드바 아이콘(DashboardIcon, ProjectIcon 등)과 동일한 스타일로 SettingsIcon을 정의합니다(SVG, 24 viewBox, stroke 기반).
- **레이아웃 구조**: 기존 화면 라우팅 시스템(App.jsx의 SCREENS 객체)에 새 화면을 추가할 수 있어야 합니다.

## 결과물

### 1. 새로운 설정 화면 (`src/screens/Settings.jsx`)
- 다른 화면들과 동일하게 `useAppData()`로 데이터를 로드
- `ScheduleCategorySection` 컴포넌트를 렌더(카테고리 관리)
- `BacklogSourcesSection` 컴포넌트를 렌더(백로그 소스 관리)
- 두 섹션 모두 이제 접이식 토글이 아닌 항상-펼침 상태로 보여짐
- 기존 액션 팩토리 재사용(로직 이원화 방지)

### 2. 아이콘 추가 (`src/components/icons.jsx`)
- `SettingsIcon` 함수형 컴포넌트 추가
- SVG 톱니바퀴 모양, 24 viewBox, stroke 기반 렌더링
- 다른 사이드바 아이콘과 동일한 SVG_PROPS 적용

### 3. 사이드바 업데이트 (`src/components/Sidebar.jsx`)
- MENU 배열에 `{ key: 'settings', label: '설정', Icon: SettingsIcon }` 추가
- 총 6개 메뉴 항목으로 확장

### 4. 앱 라우팅 업데이트 (`src/App.jsx`)
- 임포트: `import Settings from './screens/Settings.jsx'`
- SCREENS 객체에 `settings: Settings` 추가

### 5. 일정 화면 정리 (`src/screens/Schedule.jsx`)
- `ScheduleCategorySection` 임포트 및 렌더 제거
- `BacklogSourcesSection` 임포트 및 렌더 제거
- `BacklogStatusSection`을 맨 아래(날짜 상세 카드 다음)로 이동
- 월간/주간 탭 바로 다음에 캘린더가 나타나는 구조 완성

### 6. 섹션 컴포넌트 업데이트
- **`ScheduleCategorySection.jsx`**: 접이식 토글 제거, 항상 펼친 상태로 렌더
- **`BacklogSourcesSection.jsx`**: 접이식 토글 제거, 항상 펼친 상태로 렌더

## 선행 작업

### deps 배열
- P14.1 (외부 백로그 소스 등록 및 관리 기능)
- P12.16 (일정 카테고리 관리 기능)
- P14.2 (외부 백로그 현황 조회 패널)

### 왜 필요한가
- P14.1과 P12.16이 구현한 관리 UI들을 이동시키는 작업이기 때문에, 그 UI들이 이미 존재하고 정상 작동해야 합니다.
- P14.2의 백로그 현황 패널을 일정 화면에 재배치하기 때문에, 그 패널이 이미 렌더 가능해야 합니다.
