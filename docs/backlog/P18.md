# P18 — 캘린더 주 시작 요일: 월요일 → 일요일

## 목적

사용자 피드백(2026-09-26)에 따라 이 위젯의 캘린더 및 일정 기능의 주(週) 시작 요일을 월요일에서 일요일로 변경합니다. 실제 세계의 대부분 달력(특히 Windows, Google Calendar 등)은 일요일을 주의 첫날로 표시하는데, 이 위젯은 기술적 편의상 월요일을 기준으로 구현돼 있어 사용자 경험이 어색했습니다.

## 쉬운 설명

달력을 보면 보통 다음과 같이 표시됩니다:

```
일 월 화 수 목 금 토
        1  2  3  4
```

하지만 이 위젯은 지금 월요일부터 시작해서:

```
월 화 수 목 금 토 일
1  2  3  4  5  6  7
```

이렇게 표시돼 있어서 어색합니다. 이를 표준 달력처럼 일요일부터 시작하도록 바꾸고, 동시에:

- **일정 화면의 월간/주간 캘린더**: 일-토 순서로 표시
- **주간 범위 계산** (대시보드/할일 화면의 "이번 주" 정의): 일요일~토요일로 기준 변경
- **마감일 선택 팝오버**: 일-토 요일 순서로 표시
- **반복 일정 요일 설정**: 체크박스 순서를 일-월-화-수-목-금-토로 정렬

## 필요한 입력

- 없음 (기술 변경만 필요, 요구사항 수준의 결정 사항 없음)
- 다만 주 시작이 월요일에서 일요일로 바뀌므로, 기존 테스트가 기댓값을 조정해야 함

## 결과물

### 1. 주 범위 계산 함수 업데이트 (`src/lib/dateRange.js`)
- **`getThisWeekRange(date)`**:
  - 이전: 월요일 시작 (예: 월-일)
  - 변경: 일요일 시작 (예: 일-토)
  - 반환값: `{ weekStart: "YYYY-MM-DD", weekEnd: "YYYY-MM-DD" }` (일요일~토요일 범위)

### 2. 월간 그리드 계산 업데이트 (`src/lib/scheduleGrid.js`)
- **`getMonthGrid(year, month)`**:
  - 월간 캘린더 그리드의 첫 행이 일요일부터 시작하도록 변경
  - 반환되는 그리드: 첫 열이 일요일(빈 셀 포함 가능), 마지막 열이 토요일

### 3. 주간 그리드 계산 업데이트 (`src/lib/scheduleGrid.js`)
- **`getWeekDates(date)`**:
  - 지정된 날짜를 포함하는 주의 일~토 날짜 배열 반환
  - 이전: [월, 화, ..., 일]
  - 변경: [일, 월, 화, ..., 토]

### 4. UI 컴포넌트 업데이트 (`src/components/ScheduleMonthView.jsx`)
- 월간 캘린더 헤더: "월 화 수 목 금 토 일" → "일 월 화 수 목 금 토"
- 그리드 셀 배치: 일요일이 맨 왼쪽이 되도록 재정렬

### 5. 주간 캘린더 헤더 업데이트 (`src/components/ScheduleMonthView.jsx`의 주간 뷰)
- 주간 뷰 헤더: 일-토 순서로 표시

### 6. 마감일 선택 팝오버 업데이트 (`src/components/DueDatePicker.jsx`)
- 요일 선택 칩(chip) 또는 캘린더 헤더: 일-토 순서로 표시

### 7. 반복 일정 설정 폼 업데이트
- **`src/components/ScheduleAddForm.jsx`** (반복 일정 추가):
  - 요일 체크박스 순서: "월 화 수 목 금 토 일" → "일 월 화 수 목 금 토"
  - 예: 월, 수, 금마다 반복 → 체크박스 위치 변경 (순서만, 값은 유지)

- **`src/components/ScheduleEditForm.jsx`** (반복 일정 수정):
  - 동일하게 요일 체크박스 순서 변경

### 8. 테스트 스위트 업데이트 (`src/lib/dateRange.test.js`, `src/lib/scheduleGrid.test.js`)
- `getThisWeekRange()`: 월요일 기준 테스트 → 일요일 기준 테스트로 변경
  - 예: 2026-09-23(화)를 넣으면 weekStart = 2026-09-20(일), weekEnd = 2026-09-26(토) 반환
- `getMonthGrid()`: 9월 2026 그리드가 일요일 열로 시작하는지 확인
- `getWeekDates()`: 반환 배열이 [일, 월, ..., 토] 순서인지 확인
- 기존 테스트에서 기댓값 조정 (월요일 기준 → 일요일 기준)

### 9. 요구사항 문서 업데이트 (`work-widget-requirements.md`)
