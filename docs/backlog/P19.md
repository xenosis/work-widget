# P19 — 외부 백로그 현황: 전용 탭으로 분리 + 통합 주간 변경 목록

## 목적

사용자 피드백(2026-09-26)과 최종 목표(백로그 기반 주간보고 자동 생성)를 감안해, P14.2와 P17에서 구현된 외부 백로그 현황 기능을 일정 탭에서 분리해 전용 사이드바 탭으로 만들고, 모든 등록 소스의 변화를 통합해서 보여주는 기능을 추가합니다. 이를 통해 백로그 추적이 캘린더와 무관한 독립적인 작업이 되고, 향후 Codex 보고서 자동 생성의 입력으로 쓰일 수 있습니다.

## 쉬운 설명

지금까지 외부 프로젝트의 backlog.json을 읽어 작업 목록을 보여주는 기능은 일정(Schedule) 탭의 맨 아래에 붙어 있었습니다. 하지만 이것은:
1. **논리적 연결이 약함**: 백로그(다른 프로젝트의 작업 목록)와 캘린더(이 위젯의 일정)는 전혀 다른 용도
2. **공간 낭비**: 등록된 소스가 2개만 있어도 전부 펼쳐져 보여 스크롤이 길어짐
3. **통합 보기 부족**: "이번 주 들어 등록된 모든 백로그에서 뭐가 바뀌었는가"를 한눈에 보기 어려움

**P19가 하는 일**:

1. **새 탭 추가**: 사이드바에 6번째 메뉴 "백로그"(📚 모양 아이콘) 추가
2. **전용 화면**: 새로운 `Backlog.jsx` 화면 구성
3. **통합 주간 변경**: 맨 위에 "이번 주 전체 변경 사항" — 모든 소스의 추가/상태변경/삭제 항목을 합쳐서 표시
4. **소스별 축약**: 각 소스는 기본적으로 "총 12개 · changed this week: 2" 같은 한 줄 요약만 보여줌
5. **상세 펼침**: 소스를 클릭하면 기존 상태별 전체 목록+해당 소스 단독 주간 변경 내역이 펼쳐짐

## 필요한 입력

- **기능적 기반**: P14.1(백로그 소스 데이터 모델 및 IPC), P14.2(백로그 task 읽기 및 표시), P17(주간 변경 추적)이 모두 구현돼 있어야 함
- **UI 컴포넌트**: 기존 `BacklogStatusPanel.jsx`(P14.2), `BacklogWeeklyOverview.jsx`(P17) 등이 동작 중이어야 함
- **사이드바 확장 가능성**: P15에서 "설정" 탭이 추가된 이후 사이드바가 6개 메뉴를 수용할 수 있어야 함

## 결과물

### 1. 새 화면 컴포넌트 (`src/screens/Backlog.jsx`)
- 다른 화면들과 동일하게 `useAppData()`로 데이터 로드
- 맨 위에 **`BacklogWeeklyOverview`** 컴포넌트 렌더 (통합 주간 변경 목록)
- 그 아래 등록된 소스마다 **`BacklogSourceCard`** 컴포넌트 렌더 (축약/펼침 토글)

### 2. 소스 카드 컴포넌트 확장 (`src/components/BacklogSourceCard.jsx`)
- **축약 상태** (기본 표시):
  - 소스 이름
  - 총 작업 개수 (예: "총 12개")
  - 이번 주 변경 배지 (예: "↻ 2건" — 빨간 배지로 강조)
  - 화살표 아이콘 (펼침/접힘 표시)
  - 클릭 가능한 상태로, 전체 행이 버튼처럼 동작

- **펼침 상태** (클릭 후):
  - 위 축약 정보 유지 (또는 접힘 버튼으로 변경)
  - 기존 "상태별 작업 목록" 섹션 (P14.2의 SourceTaskGroups)
  - "이 소스의 이번 주 변경 사항" 섹션 (P17의 주간 변경 목록)

### 3. 통합 주간 변경 컴포넌트 (`src/components/BacklogWeeklyOverview.jsx`)
- 모든 등록 소스의 주간 변경을 합친 목록
- 포맷:
  ```
  이번 주 전체 변경 사항 (전체 N건)
  
  + 새로 추가 (2건)
    - ProjectA/P2.1 — 예제 작업
    - ProjectB/P1.5 — 다른 작업 [외 0건]
  
  ↻ 상태 변경 (1건)
    - ProjectA/P2.2 — 상태명 (in_progress → done)
  
  − 사라짐 (1건)
    - ProjectA/P2.3 — 삭제된 작업
  
  (변화 없으면: "이번 주 전체 변경 사항 없음.")
  ```
- 각 항목에 **소스 태그** 추가 (예: [ProjectA], [ProjectB]) — 어느 소스에서 온 변경인지 구분

### 4. 아이콘 추가 (`src/components/icons.jsx`)
- **`BacklogIcon`**: 사이드바 백로그 메뉴용 아이콘
  - SVG 기반, 24 viewBox, stroke 렌더링
  - 쌓인 책/층 모양(📚) — "여러 소스를 한 번에 본다"는 의미
  - 다른 사이드바 아이콘과 동일한 스타일

### 5. 사이드바 업데이트 (`src/components/Sidebar.jsx`)
- MENU 배열에 `{ key: 'backlog', label: '백로그', Icon: BacklogIcon }` 추가
- 순서: 대시보드 / 프로젝트 / 할일전체 / 메모 / 일정 / **백로그(신규)** / 설정(P15 추가)
