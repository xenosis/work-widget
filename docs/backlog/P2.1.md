# P2.1 — 프로젝트 목록 카드 UI

## 목적

프로젝트들을 장기/단기로 구분해서 카드 형식으로 표시한다.

## 쉬운 설명

projects 배열을 type 필드로 필터링해서 "장기" 프로젝트들과 "단기" 프로젝트들을 별도 섹션에 표시한다. 각 프로젝트는 카드로 렌더되며, 프로젝트명, 진행률 바, 마감일, 상태 표시를 포함한다.

## 필요한 입력

- projects 데이터 구조 (work-widget-requirements.md B3.1)
- P6.1: progress 계산 함수

## 결과물

Projects.jsx의 목록 보기: 장기 섹션과 단기 섹션이 분리된 레이아웃, 각 섹션의 프로젝트 카드들, 카드 내 정보 (프로젝트명, 상태, 진행률, 마감일)

## 선행 작업

없음 (UI만 구현, 데이터 연동은 P2.5).

## 수행 순서에서의 위치

P2 내에서 가장 먼저 구현되는 UI 레이아웃.
