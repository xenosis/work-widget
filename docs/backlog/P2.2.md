# P2.2 — 프로젝트 상세 화면

## 목적

프로젝트 카드를 클릭했을 때 그 프로젝트의 상세 정보(소속 할일, 메모, 진행률, 마감일)를 보여주는 상세 화면으로 전환되도록 구현한다.

## 쉬운 설명

프로젝트 목록에서 카드를 클릭하면 상세 정보를 보여주는 별도 화면으로 전환된다. 상세 화면에는 해당 프로젝트의 소속 할일 목록, 프로젝트 메모, 요약 정보(상태, 진행률, 마감일)가 표시되며, 뒤로가기 버튼으로 목록으로 돌아올 수 있다.

## 필요한 입력

- P2.1: 프로젝트 목록 카드 UI (클릭 가능)
- data.json의 projects와 todos 배열
- P6.1: calculateProjectProgress 함수
