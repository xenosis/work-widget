# P2.2 — 프로젝트 상세 화면

## 목적

프로젝트 카드를 클릭했을 때 상세 화면으로 전환되는 라우팅/레이아웃을 구현한다.

## 쉬운 설명

Projects.jsx 컴포넌트 내에서 로컬 state로 어느 프로젝트가 선택되었는지 추적한다. 선택된 프로젝트가 있으면 상세 화면을, 없으면 목록을 렌더한다.

## 필요한 입력

- React 라우팅/상태 관리 (useState)
- 선택된 프로젝트 객체 추적

## 결과물

Projects.jsx의 상세 보기: 프로젝트 정보 헤더, 할일 섹션, 메모 섹션, 뒤로가기 버튼 또는 라우팅

## 선행 작업

**P2.1** — 카드 목록이 렌더되는 상태 필요.

## 수행 순서에서의 위치

P2 내에서 P2.1 다음.

## done_when을 확인하는 방법

1. 목록에서 프로젝트 카드를 클릭한다
2. 상세 화면으로 전환되는가?
3. 프로젝트 정보가 표시되는가?
4. 뒤로가기 또는 다른 방식으로 목록으로 돌아갈 수 있는가?
