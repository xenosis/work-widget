# P2.3 — 상세화면 내 할일 인라인 추가

## 목적

프로젝트 상세 화면에서 사용자가 입력 필드에 할일 제목을 직접 입력한 후 엔터를 누르면, 그 프로젝트에 새로운 할일이 즉시 추가되도록 구현한다.

## 쉬운 설명

상세 화면 하단에 입력 필드를 추가해서, 사용자가 그 자리에서 새로운 할일 제목을 타이핑하고 엔터를 누르면 새 할일이 프로젝트에 추가된다.

## 필요한 입력

- P2.2 완료: 상세 화면 레이아웃 준비
- B3.2 스키마: todo 데이터 구조 이해
- P0.3, P0.4: 데이터 저장 기반

## 결과물

- 상세화면에 AddTodoForm 컴포넌트 추가
- handleAddTodo 함수로 B3.2 스키마 필드 채우고 저장
- src/lib/todoFactory.js 신규 (createTodo 함수)

## 선행 작업

- P2.2: 상세 화면 레이아웃

## 수행 순서에서의 위치

P2의 세 번째 단계. P2.3이 첫 번째 쓰기 경로이므로 B4.3도 이 작업에서 검증됨.

## done_when을 확인하는 방법

1. npm run dev로 앱 실행
2. 프로젝트 상세 화면에 입력 필드 확인
3. 텍스트 입력 후 Enter 누르기
4. UI 즉시 갱신 (새 할일이 목록에 추가됨)
5. data.json에 실제 저장 확인
6. 완료 프로젝트에 할일 추가 시 상태 자동 전환 확인
7. lint/test/build 통과, 콘솔 에러 없음
