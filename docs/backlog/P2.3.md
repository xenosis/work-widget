# P2.3 — 상세화면 내 할일 인라인 추가

## 목적

프로젝트 상세 화면에서 입력창에 타이핑한 후 엔터를 누르면 새로운 할일이 해당 프로젝트에 추가된다.

## 쉬운 설명

상세 화면의 할일 섹션 하단에 입력 필드가 있다. 사용자가 "새로운 할일"을 입력하고 엔터를 누르면 새 todo 객체가 생성되어 todos 배열에 추가되고, 입력 필드가 초기화되며 화면이 갱신된다.

## 필요한 입력

- 할일 데이터 구조 (work-widget-requirements.md B3.2)
- state 관리 (입력값, 입력 완료 후 처리)

## 결과물

상세 화면의 할일 섹션 아래: 텍스트 입력 필드, 엔터 키 이벤트 핸들러 (새 할일 추가 로직)

## 선행 작업

**P2.2** — 상세 화면 레이아웃 완료.

## 수행 순서에서의 위치

P2 내에서 P2.2 이후.

## done_when을 확인하는 방법

1. 상세 화면에서 할일 입력 필드를 본다
2. 텍스트를 입력하고 엔터를 누른다
3. 새로운 할일이 목록에 추가되는가?
4. 입력 필드가 초기화되는가?
