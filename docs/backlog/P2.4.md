# P2.4 — 상세화면 메모/진행률/마감일 요약

## 목적

프로젝트 상세 화면에서 프로젝트의 진행률, 마감일, 소속 메모들을 함께 표시해 프로젝트 현황을 한눈에 파악하도록 한다.

## 쉬운 설명

프로젝트 상세 화면의 요약 카드에 진행률(%), 마감일이 표시되고, 하단에 그 프로젝트의 메모 목록이 표시된다.

## 필요한 입력

- P2.2 완료: 상세 화면 라우팅과 요약 카드
- P6.1 완료: calculateProjectProgress 함수
- data.json의 memos 배열 구조 이해

## 결과물

- src/lib/projectMemos.js (getMemosForProject 함수)
- Projects.jsx의 ProjectDetail에 메모 카드 추가
- 메모 정렬(updated_at 내림차순), 오버플로우 보호

## 선행 작업

- P2.2: 상세화면 라우팅
- P6.1: progress 계산

## 수행 순서에서의 위치

P2의 마지막 정보 표시 작업. P2.5의 저장 연동 전에 읽기 부분을 완성한다.

## done_when을 확인하는 방법

1. data.json에 프로젝트와 메모를 함께 넣고 project_id 설정
2. npm run dev로 앱 띄운 후 프로젝트 상세 화면 확인
3. 진행률, 마감일, 메모 목록이 모두 표시되는가?
4. 프로젝트 불일치 메모는 표시 안 됨
5. lint/test/build 통과, 콘솔 에러 없음
