# P2.4 — 상세화면 메모/진행률/마감일 요약

## 목적

프로젝트 상세 화면에서 프로젝트의 설명, 진행률, 마감일, 소속 메모들을 함께 표시한다.

## 쉬운 설명

상세 화면의 상단부에 프로젝트 정보를 정리해서 보여준다: 프로젝트명, 설명, 마감일, 상태, 진행률, 소속 메모들. 이 섹션은 "프로젝트 현황을 한눈에 보는" 용도다.

## 필요한 입력

- **P6.1 필수**: progress 계산 함수 (진행률을 구하기 위해)
- projects와 memos의 관계 이해 (memos에 project_id 필드)

## 결과물

상세 화면 상단: 프로젝트명, 설명, 마감일, 상태 표시, 진행률 시각화, 소속 메모 목록

## 선행 작업

**P6.1** — progress 계산 함수 완료.
**P2.2** — 상세 화면 레이아웃 완료.

## 수행 순서에서의 위치

P2 내에서 P2.2 이후 병렬 진행 가능 (P2.3과 독립적).

## done_when을 확인하는 방법

1. 상세 화면에서 프로젝트 정보 섹션을 본다
2. 프로젝트명, 설명, 마감일, 상태가 표시되는가?
3. 진행률이 정확하게 계산되고 표시되는가?
4. 소속 메모들이 나열되는가?
5. 메모 개수가 일치하는가?
