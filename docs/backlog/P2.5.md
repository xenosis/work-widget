# P2.5 — 프로젝트 CRUD IPC 연동

## 목적

프로젝트 생성/수정/삭제 작업을 data.json에 반영한다. window.api.loadData()로 데이터를 읽고, 변경 후 window.api.saveData()로 저장한다.

## 쉬운 설명

P2.1~P2.4는 UI를 만들고, P2.5는 그 UI가 실제 파일과 연결되도록 한다. 화면 로드 시 window.api.loadData() 호출로 projects 배열을 가져오고, 추가/수정/삭제 시마다 saveData()를 호출해서 변경사항을 파일에 저장한다.

## 필요한 입력

- P0.4 완료: IPC 채널 구현
- P0.8 완료: 앱이 실행 중
- P2.1~P2.4 완료: UI 준비됨

## 결과물

Projects.jsx의 로직: useEffect에서 window.api.loadData() 호출 및 state 관리, 프로젝트 추가/수정/삭제 함수들이 saveData() 호출, 저장 후 state 갱신 및 화면 재렌더

## 선행 작업

**P0.8** — IPC가 작동하는 상태.
**P2.1~P2.4** — UI 완료.

## 수행 순서에서의 위치

P2의 마지막 작업. P2.1~P2.4가 모두 완료되어야 이 작업 시작 가능.

## done_when을 확인하는 방법

1. 앱을 실행한다
2. 프로젝트 화면에 기존 프로젝트들이 표시되는가?
3. 새 프로젝트를 추가한다
4. 앱을 종료하고 다시 실행했을 때 새 프로젝트가 유지되는가?
5. 프로젝트를 수정/삭제했을 때 변경사항이 유지되는가?
