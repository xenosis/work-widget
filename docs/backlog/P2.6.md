# P2.6 — 단기 프로젝트 전용 뷰

## 목적

요구사항 Part A 5.1의 "단기 프로젝트만 별도로 모아서 볼 수 있는 뷰"를 구현한다.

## 쉬운 설명

프로젝트 화면에 탭 또는 필터를 추가해서 "전체 보기" / "단기만 보기" 중 선택 가능하게 한다.

## 필요한 입력

- P2.1: 프로젝트 목록 카드 UI와 groupProjectsByType
- work-widget-requirements.md Part A 5.1

## 결과물

Projects.jsx에 탭/필터 UI 추가로 type=단기인 프로젝트만 필터링 표시 가능

## 선행 작업

- P2.1: 프로젝트 목록

## 수행 순서에서의 위치

P2 내 선택 기능 확장

## done_when을 확인하는 방법

1. 프로젝트 화면에 탭/필터 UI 확인
2. "단기" 선택 시 type=단기인 프로젝트만 표시
3. "전체" 탭으로 돌아오면 장기+단기 모두 표시
4. lint 통과, 콘솔 에러 없음
