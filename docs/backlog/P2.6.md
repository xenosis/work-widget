# P2.6 — 단기 프로젝트 전용 뷰

## 목적

요구사항 Part A 5.1에서 요구한 "단기 프로젝트만 별도로 모아서 볼 수 있는 뷰"를 구현한다. 현재 P2.1(프로젝트 화면)은 장기와 단기를 한 화면에 세로로 나열하기만 하므로, 단기만 집중해서 보는 방법이 없다.

## 쉬운 설명

프로젝트 화면(Projects.jsx)에 탭 또는 필터 버튼을 추가해서 "전체 보기" / "단기만 보기" 중 선택 가능하게 한다. "단기만 보기"를 클릭하면 type이 "단기"인 프로젝트만 화면에 표시된다.

## 필요한 입력

- P2.1(프로젝트 목록 카드 UI): 기존 전체 프로젝트 리스트 렌더링 코드 및 groupProjectsByType 함수
- work-widget-requirements.md Part A 5.1 — "단기 프로젝트만 별도로 모아서 볼 수 있는 뷰 필요" 요구사항

## 결과물

Projects.jsx에 탭/필터 UI 추가. "전체" 탭은 현재 화면 그대로(장기+단기), "단기" 탭은 type=단기인 프로젝트만 필터링해서 표시.

## 선행 작업

- P2.1: 프로젝트 목록 카드 UI (groupProjectsByType 함수 및 전체 목록 렌더링 패턴)

## 수행 순서에서의 위치

P2(프로젝트 화면) 내에서 P2.1 이후의 선택 기능 확장. 핵심 기능(P2.1~P2.5)이 완료된 이후에 UX 개선 차원으로 추가. 메인 기능 개발 흐름(P3~P6)과는 병렬 진행 가능.

## done_when을 확인하는 방법

1. npm run dev로 실행
2. 프로젝트 화면에 탭/필터 UI 존재 확인
3. 탭/필터를 "단기"로 선택 시 type=단기인 프로젝트만 표시되는지 확인
4. "전체" 탭으로 돌아오면 장기+단기 모두 표시되는지 확인
5. lint 통과, 콘솔 에러 없음

## 확인 필요

- 탭 vs 필터 vs 토글 중 어느 UI 패턴이 가장 적절한지 (요구사항에 "뷰"만 명시, UI 형태는 미정)
- 단기 전용 뷰 진입 후 장기로의 복귀 흐름이 자연스러운지
