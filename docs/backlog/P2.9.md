# P2.9 — 재표시 데이터 재조회와 열려있는 프로젝트 수정 폼의 충돌 정책 결정

## 목적

P1.6(트레이 재표시 시 데이터 재조회)이 열려있는 프로젝트 수정 폼과 만났을 때 발생하는 데이터 충돌 문제를 정책으로 해결한다.

## 쉬운 설명

사용자가 프로젝트 이름을 수정하는 폼을 열어둔 채로 앱을 트레이로 숨겼다. 그 사이 다른 곳에서 데이터가 바뀌고 앱을 다시 열었을 때, 폼의 옛 내용을 저장하면 최신 변경분을 덮어버리는 문제다.

## 필요한 입력

- P1.6 완료: 데이터 재조회 기능
- B5.1: 창 숨김/표시 동작
- React 폼 상태 관리 패턴

## 결과물

정책 결정: last-write-wins 유지, 개발/테스트 중 수기 편집 경로 인정

## 선행 작업

- P1.6: 트레이 재표시 시 데이터 재조회

## 수행 순서에서의 위치

P2.9는 P1.6과 P2.5 사이의 의존성 관계를 명확히 하는 정책 결정 작업이다.

## done_when을 확인하는 방법

사람이 정책(last-write-wins 유지, 수기 편집 경로 인정)을 검토하고 동의할 때이다.
