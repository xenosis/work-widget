# P2 — 프로젝트 화면 (B2.1)

## 목적

프로젝트 관리 화면을 구현한다. 장기/단기 프로젝트를 구분해서 카드로 표시하고, 각 프로젝트를 클릭하면 상세 화면에서 소속 할일, 메모, 진행률, 마감일을 볼 수 있게 한다.

## 쉬운 설명

프로젝트 화면은 두 부분으로 구성: 1) 목록 화면 (장기/단기 프로젝트 카드 분리 표시), 2) 상세 화면 (프로젝트 정보, 소속 할일, 메모, 진행률 표시, 할일 추가 입력창)

## 필요한 입력

- P0 완료: 앱이 실행되고 React 렌더러가 로드됨
- P6.1 필수: Project.progress 계산 함수
- work-widget-requirements.md의 B2.1, B3.1, B4.3 섹션

## 결과물

src/screens/Projects.jsx — 프로젝트 화면 컴포넌트: 목록 보기(장기/단기 카드 구분), 상세 보기(할일/메모/진행률 통합 표시), 할일 인라인 추가 입력 창

## 선행 작업

**P0** — 기본 스캐폴딩 완료 필수.

## 수행 순서에서의 위치

P0 완료 후 시작 가능. P2 내에는 5개의 하위 작업(P2.1~P2.5)이 있으며, 모두 완료되어야 P2가 done.

## done_when을 확인하는 방법

**하위 항목 P2.1 ~ P2.5가 모두 done 상태이면 P2도 완료.**
