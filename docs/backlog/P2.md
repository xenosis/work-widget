# P2 — 프로젝트 화면 (B2.1)

## 목적

프로젝트 목록과 상세 화면을 구현한다. 장기/단기로 구분된 프로젝트 카드 목록과 각 프로젝트의 상세 정보(할일, 메모, 진행률)를 보여주는 화면이다.

## 쉬운 설명

모든 프로젝트를 카드로 모아 볼 수 있는 화면이고, 각 프로젝트를 클릭하면 그 안의 할일과 메모, 진행률을 볼 수 있는 상세 화면으로 들어간다. 이 부모 작업은 P2.1~P2.10의 10개 하위 작업이 모두 완료될 때 함께 완료되는 작업이다.

## 필요한 입력

- 요구사항 B2.1: 프로젝트 화면 UI 흐름
- P0 완료: 기본 앱 프레임워크
- P6 라이브러리 작성: progress 계산 등 공통 로직

## 결과물

P2.1~P2.10의 모든 하위 작업이 함께 제공하는 것들:
- src/screens/Projects.jsx: 장기/단기 카드 목록, 상세 화면, 할일 추가/수정/삭제 폼, 메모 표시, 진행률 바
- src/lib/projectGrouping.js, src/lib/projectTodos.js, src/components/TodoRow.jsx 등 공유 유틸리티
- 관련 CSS 스타일 (src/index.css)

## 선행 작업

- P0: 기본 앱 프레임워크 필수

## 수행 순서에서의 위치

P1(대시보드) 다음에 시작하는 두 번째 주요 기능 화면. P2.1~P2.10을 순차적으로 완료한 뒤, 모든 하위 작업이 done이 되면 P2도 자동으로 완료로 표시된다. 본래 P2.1~P2.10이 먼저 완료되었으나, 부모 작업 P2의 상태 업데이트가 지연되었다가 2026-09-24에 일괄 정리됨.

## done_when을 확인하는 방법

**P2.1부터 P2.10까지 10개 모든 하위 작업이 done 상태인지 확인**합니다. CLI 명령으로 확인:
```
node scripts/backlog/cli.js list | grep "P2\." | grep '"status"'
```
위 결과가 모두 `"status": "done"`이면 P2도 완료입니다.
