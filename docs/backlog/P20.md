# P20 — 전역 UI: 라벨/제목류 텍스트 2줄 방지(1줄 초과 시 말줄임)

## 목적

사용자 피드백(2026-09-27): 앱의 화면 어디서든 텍스트(제목, 라벨, 배지 텍스트 등)가 2줄로 줄바꿈되는 것을 보기 싫다고 지적했습니다. 1줄을 넘어가면 줄바꿈 대신 끝에 말줄임표(...)를 붙여 자르도록 변경해야 합니다. 현재 P12.x 리뷰에서 `.todo-title`, `.project-card-name`, `.memo-list-title` 등 개별 제목류는 이미 처리됐지만, 전 화면 공통으로 쓰이는 `.card-title`(모든 카드 헤더 제목)과 `.schedule-holiday-name`, `.backlog-status-source-title`, `.backlog-status-group-title`, `.backlog-status-task-owner`, `.backlog-source-label` 같은 일부 라벨류가 아직 처리되지 않았습니다. 이들을 전부 찾아서 처리합니다.

## 쉬운 설명

앱의 각 화면에서 프로젝트명, 할일 텍스트, 메모 제목, 일정 라벨 등 여러 가지 짧은 텍스트가 나타납니다.

**현재의 문제**:
- 텍스트가 길면 자동으로 2줄로 줄바꿈됨
- 사용자가 이를 원하지 않음

**P20이 하는 일**:
1. **CSS에서 줄바꿈 방지 규칙 추가**: `white-space: nowrap` + `text-overflow: ellipsis` + `overflow: hidden`를 활용
2. **영향 범위 확인**: 모든 제목과 라벨류(`.card-title`, `.schedule-holiday-name`, `.backlog-status-source-title` 등)를 찾아 적용
3. **콘텐츠 영역은 제외**: 메모 본문 같은 원래 여러 줄 표시가 목적인 영역(`<textarea>`, 긴 설명 텍스트)은 그대로 둠

## 필요한 입력

- **기존 CSS 선택자 확인**: `src/index.css`의 기존 클래스 정의
  - `.card-title` — 모든 카드 헤더 제목 스타일
  - `.card-header` — 카드 헤더 컨테이너 (배지 배치)
  - `.schedule-holiday-name` — 일정 화면의 휴일 라벨
  - `.backlog-status-source-title` — 백로그 화면의 소스(외부 프로젝트) 제목
  - `.backlog-status-group-title` — 백로그 화면의 상태 그룹 제목
  - `.backlog-status-task-owner` — 백로그 작업의 외부 데이터(소스/상태/담당자 라벨)
  - `.backlog-source-label` — 설정 탭에서 등록된 외부 소스 라벨
  - `.backlog-weekly-summary` — 백로그 주간 요약 텍스트
  - `.backlog-source-summary-counts` — 백로그 소스 요약 카운트
  - 기타 발견되는 제목/라벨류
- **다양한 화면에서 사용되는 컴포넌트**: 대시보드, 프로젝트, 할일, 메모, 일정, 백로그, 설정 등

## 결과물

### 1. 전역 제목/라벨 클래스에 말줄임 스타일 추가 및 수정 (`src/index.css`)

#### 1.1 기본 제목 클래스들

```css
.card-title {
  /* 모든 카드 헤더 제목 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}

.content h1 {
  /* 페이지 제목 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}
```

#### 1.2 일정/백로그 라벨 클래스들

```css
.schedule-holiday-name {
  /* 일정 화면의 휴일 라벨 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}

.backlog-status-source-title {
  /* 백로그 소스(외부 프로젝트) 제목 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}

.backlog-status-group-title {
  /* 백로그 상태 그룹 제목 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
  /* 배지 없는 사용처 */
  white-space: nowrap;
}
```

#### 1.3 백로그 외부 데이터 라벨 (Critical-Reviewer High 반영)

```css
.backlog-status-task-owner {
  /* 백로그 작업의 외부 데이터 (소스/상태/담당자 라벨) */
  max-width: 200px;  /* 또는 적절한 폭 제한 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}

.backlog-source-label {
  /* 설정 탭의 등록 소스 라벨 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}
```

#### 1.4 백로그 요약 클래스들

```css
.backlog-weekly-summary {
  /* 백로그 주간 요약 텍스트 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
}

.backlog-source-summary-counts {
  /* 백로그 소스 요약 카운트 */
  /* 주의: flex 컨테이너에서 text-overflow:ellipsis가 먹지 않는 CSS 사양 문제
     해결책: 텍스트만 포함하는 내부 스팬(또는 div)을 별도로 만들고
     배지는 형제 요소로 분리해서 항상 보이도록 함 */
  display: flex;
  gap: 8px;
}

.backlog-source-summary-counts > span:first-child {
  /* 텍스트 전용 스팬 */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
  flex: 1;
}
```

#### 1.5 대시보드 프로젝트명 (Critical-Reviewer High 반영)

```css
.project-row-name {
  /* 대시보드 진행중 프로젝트 이름 (기존에는 클래스 없는 맨 span) */
  white-space: nowrap;
  text-overflow: ellipsis;
  overflow: hidden;
  flex: 1;  /* 형제 배지와의 레이아웃 균형 */
}
```

### 2. 배지/카운트 컨테이너 안정화 및 헤더 레이아웃 개선

```css
}
```

### 3. 적용 범위 요약

- **기본 제목**: `.card-title`, `.content h1`

### 4. 제외되는 영역 (의도적으로 변경 안 함)

```css

  white-space: normal;  /* 유지 */
}

/* 프로젝트/할일 설명 텍스트영역 — 여러 줄 입력이 목적 */

/* 프로젝트/할일 설명 표시 영역 — 여러 줄 표시가 목적 */
```
