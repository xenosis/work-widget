# P23 — 일정 탭: 월간/주간 전체 기간 일정 리스트 추가

## 목적

사용자가 일정 탭에서 월간 또는 주간 보기를 할 때, 달력을 클릭해가며 하나하나 일정을 확인하는 것이 아니라 **그 기간 전체 일정을 한 번에 스크롤로 훑어볼 수 있게** 하는 기능입니다. 특히 반복 일정이 여러 날짜에 걸쳐 나타날 때, 각 발생 날짜마다 어떤 일정들이 있는지 한눈에 파악하기 위한 보조 도구입니다.

## 쉬운 설명

지금까지 일정 탭은:
1. **월간/주간 달력** — 각 날짜에 점으로 "일정이 있다/없다"만 표시
2. **날짜별 상세 카드** — 특정 날짜를 클릭해야만 그 날의 모든 일정을 볼 수 있음
3. **수정/삭제** — 상세 카드에서만 가능

**P23이 하는 일**:

달력 아래에 **읽기 전용 리스트** 추가:
- **월간 보기 시**: 그 달(1일 ~ 말일)의 모든 일정을 날짜순으로 나열
- **주간 보기 시**: 그 주(7일)의 모든 일정을 날짜순으로 나열
- **반복 일정 전개**: 예를 들어 "매주 화요일" 반복 일정이 있으면, 보여주는 기간의 모든 화요일에 따로따로 표시됨
- **읽기 전용**: 목록 자체에서는 수정/삭제 불가 — 수정하려면 여전히 달력에서 날짜를 선택해 상세 카드를 띄워야 함

## 필요한 입력

- **기존 일정 데이터**: 이미 `src/screens/Schedule.jsx`와 `data.schedules` 배열이 작동 중이어야 함
- **날짜 계산 유틸**: `getMonthGrid()`, `getWeekDates()` 등 기존 `scheduleGrid.js` 함수들이 월간/주간 범위를 올바르게 판정해야 함
- **카테고리 팔레트**: 각 일정의 카테고리 색상을 표시하기 위해 `categoryPalette.js`가 준비돼 있어야 함

## 결과물

### 1. 새 컴포넌트: `ScheduleRangeList.jsx`
- `getScheduleRangeDates()`: 현재 보는 월간/주간 범위의 날짜 목록을 계산하고 내보냄
  - 월간: `getMonthGrid()`로 달력 데이터를 얻은 후, **그 달에만 속한 날짜**(`inCurrentMonth`)만 필터링
  - 주간: `getWeekDates()`로 7일 목록을 직접 사용
  - 12월(연 경계) 케이스도 테스트로 검증
- `ScheduleRangeGroup` 서브컴포넌트: 한 날짜의 일정들을 그룹으로 표시
  - 날짜 제목 (예: "2026-09-27")
  - 그 날의 모든 일정을 카드 형태로 나열
  - 각 일정: 카테고리 색 바 + 제목 + "반복" 배지(있을 경우)
- 전체 구조:
  ```jsx
  <ScheduleRangeList 
    view={view}              // "month" | "week"
    monthCursor={...}         // {year, month}
    weekAnchor={weekAnchor}   // "YYYY-MM-DD"
    schedules={data.schedules}
    categories={data.schedule_categories}
  />
  ```

### 2. 유틸 함수: `getSchedulesInRange()` 추가 (`src/lib/scheduleGrid.js`)
- 주어진 날짜 목록과 일정 배열을 입력받아, 날짜별로 그룹화된 결과를 반환
- 일정이 하나도 없는 날짜는 결과에서 제외 (목록이 비어 있는 날짜로 늘어지지 않도록)
- 반복 일정은 `getSchedulesForDate()` 로직을 타서 각 날짜의 발생 여부를 올바르게 판정
- **반환 형식**: `{ groups: [{ date: "2026-09-27", items: [...schedules] }, ...], droppedCount: 0 }`
  - `groups`: 실제로 일정이 있는 날짜들만 포함
  - `droppedCount`: id가 없거나 데이터 손상된 일정의 개수(빈 상태 판정과 count 표시에서 일관됨)

### 3. 화면에 삽입: `src/screens/Schedule.jsx`
- 기존 구조 유지:
  ```jsx
  <ScheduleMonthView ... />
  // 또는
  <ScheduleWeekView ... />
  
  // P23에서 추가:
  <ScheduleRangeList view={view} monthCursor={monthCursor} weekAnchor={weekAnchor} ... />
  ```
- 두 뷰와 상세 카드 사이, 또는 그 아래 위치

### 4. CSS 스타일 (`src/index.css`)
- `.schedule-range-groups` — 그룹 컨테이너
  - 날짜별 구분이 명확하도록 간격 추가
- `.schedule-range-group` — 한 날짜의 블록
  - 배경/경계선/패딩
- `.schedule-range-date` — 날짜 제목 (예: "2026-09-27")
  - 강조 텍스트 스타일
- `.schedule-item-row`, `.schedule-item-title` 등 — 개별 일정 항목
  - 기존 `ScheduleDateDetail` 스타일과 일관성 유지
  - 카테고리 색 바 (`.schedule-item-colorbar`)

### 5. 기존 스타일 개선 (P20 관련 잔여 수정)
- `.empty-text`: "등록된 일정이 없습니다" 같은 빈 상태 메시지
  - `nowrap` + `text-overflow: ellipsis` 추가 (메모 탭의 안내 문구가 2줄 되지 않도록)
- `.schedule-dot-legend` / `.schedule-dot-legend-item` — 달력 범례(점 색 설명)
  - `flex-wrap: wrap` + 각 항목에 `white-space: nowrap` (범례 항목 내부 줄바꿈 방지)
  - 수평 공간이 좁을 때도 범례 텍스트가 손실되지 않도록

### 6. 데이터 손상 및 제목 안정성 처리
- **id 없는 일정**: `.data-issue-notice`로 통지 추가 (ScheduleDateDetail과 동일한 경고 표시)
- **비정상 제목**: `title`이 문자열이 아니거나 비어 있을 때 `'(제목 없음)'` 대체 (손상 데이터로 인한 크래시 방지)
  - `getScheduleCellSummary()` 함수와 동일한 처리 로직 적용
- **UI 텍스트 표시 개선**: P20 후속 조치로 5곳에 `title` 속성 추가
  - `.empty-text` 요소와 UI 지시/경고 문구들이 마우스 호버 시 tooltip으로 전체 텍스트 노출
  - 기존 text-truncation(ellipsis)으로 잘려 보이던 부분이 이제 마우스로 확인 가능
