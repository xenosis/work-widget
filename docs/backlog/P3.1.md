# P3.1 — 날짜 그룹핑(오늘/이번주/나중) UI

## 목적

모든 할일들을 due_date 기준으로 3개 그룹으로 필터링해서 구분된 섹션에 표시한다.

## 쉬운 설명

todos 배열을 오늘/이번주/나중으로 분류해서 각 그룹을 별도 섹션으로 표시한다.

## 필요한 입력

- 할일 데이터 구조 (B3.2)
- 날짜 계산 로직

## 결과물

Todos.jsx: 세 섹션으로 구분된 할일 목록

## 선행 작업

- P1.1, P1.2: 날짜 그룹핑 패턴 참고
