# P3.1 — 날짜 그룹핑(오늘/이번주/나중) UI

## 목적

모든 할일들을 due_date 기준으로 3개 그룹으로 필터링해서 구분된 섹션에 표시한다.

## 쉬운 설명

todos 배열의 모든 항목을 다음과 같이 분류: 오늘(due_date가 오늘인 할일), 이번주(내일~이번주 말), 나중(다음주 이후 또는 due_date 없음). 각 그룹을 별도 섹션으로 표시하되, 프로젝트 구분은 하지 않는다.

## 필요한 입력

- 할일 데이터 구조 (work-widget-requirements.md B3.2)
- 날짜 계산 로직

## 결과물

Todos.jsx의 레이아웃: 세 섹션으로 구분된 할일 목록, 각 섹션 헤더 (오늘, 이번주, 나중)

## 선행 작업

**P6.3** — 데이터 검증/정규화 로직 (데이터 무결성 보장).

## 수행 순서에서의 위치

P3 내에서 가장 먼저 구현.

## done_when을 확인하는 방법

1. 할일전체 화면을 본다
2. 세 섹션(오늘, 이번주, 나중)이 분리되어 표시되는가?
3. 테스트 데이터로 각 그룹에 할일이 정확하게 분류되는가?
