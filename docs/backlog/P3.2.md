# P3.2 — 완료 체크(취소선 유지) + 숨김 토글

## 목적

할일을 완료로 체크해도 목록에서 사라지지 않고 취소선으로 표시하며, 별도의 숨김 버튼으로 안 보이게 전환할 수 있게 한다.

## 쉬운 설명

체크박스 클릭 시 completed = true로 저장, 화면에 취소선 표시. 할일이 사라지지 않으므로 언제든 다시 체크 풀 수 있음. "숨김" 버튼으로 화면에서 임시로 가려짐.

## 필요한 입력

- todo 데이터 구조 (completed 필드)
- UI 상태 관리 (숨김 목록 추적)

## 결과물

Todos.jsx: 체크박스, 텍스트(완료 시 취소선), 숨김 버튼
