# P3.2 — 완료 체크(취소선 유지) + 숨김 토글

## 목적

할일을 완료로 체크해도 목록에서 사라지지 않고 취소선으로 표시하며, 별도의 숨김 버튼으로 안 보이게 전환할 수 있게 한다.

## 쉬운 설명

전형적인 할일 앱의 동작: 1) 체크박스 클릭 시 completed = true로 저장, 화면에 취소선 표시, 2) 할일이 사라지지 않으므로 언제든 다시 체크 풀 수 있음, 3) "숨김" 버튼으로 화면에서 임시로 가려짐 (저장되지 않음)

## 필요한 입력

- todo 데이터 구조 (completed 필드)
- UI 상태 관리 (숨김 목록 추적)

## 결과물

Todos.jsx의 각 할일 항목: 체크박스, 텍스트 (완료 시 취소선 스타일), 숨김 버튼

## 선행 작업

**P3.1** — 그룹핑 UI 완료.

## 수행 순서에서의 위치

P3 내에서 P3.1 이후.

## done_when을 확인하는 방법

1. 할일의 체크박스를 클릭한다
2. 취소선이 표시되는가?
3. 할일이 목록에서 사라지지 않는가?
4. 다시 체크를 풀 수 있는가?
5. 숨김 버튼을 클릭하면 할일이 화면에서 사라지는가?
