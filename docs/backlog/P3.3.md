# P3.3 — 화면 내 할일 추가(프로젝트 지정)

## 목적

할일전체 화면에서 새 할일을 추가할 때 소속 프로젝트를 지정하는 기능을 구현한다.

## 쉬운 설명

프로젝트 화면에서는 프로젝트가 이미 정해져 있으므로 할일 제목만 입력했다. 할일전체 화면에서는 프로젝트를 먼저 선택해야 한다.

## 필요한 입력

- projects 목록 (select에 표시)
- 새 할일 추가 시 project_id 설정

## 결과물

Todos.jsx: 프로젝트 선택 dropdown, 할일 제목 입력, 추가 버튼

## 선행 작업

- P3.1: 화면 레이아웃

## 수행 순서에서의 위치

P3 내에서 P3.1 이후 병렬 진행 가능

## done_when을 확인하는 방법

프로젝트를 선택하고 할일 제목을 입력한 뒤 엔터/버튼으로 새 할일이 해당 프로젝트에 추가되는지 확인
