# P3.4 — 정렬 로직(마감일→우선순위)

## 목적

할일들을 마감일과 우선순위에 따라 정렬한다.

## 쉬운 설명

1차 정렬: due_date(마감일이 가깝다), 2차: priority(상→중→하), 3차: due_date 없는 할일을 맨 뒤로.

## 필요한 입력

- todo 데이터 구조 (due_date, priority 필드)
- 날짜 비교 로직

## 결과물

Todos.jsx 정렬 로직: 각 그룹(오늘/이번주/나중) 내에서 정렬 적용

## 선행 작업

- P3.1: 그룹핑

## 수행 순서에서의 위치

P3 내에서 P3.1~P3.3 이후

## done_when을 확인하는 방법

같은 그룹 내에서 마감일 순으로 정렬되고, 같은 마감일 할일들은 우선순위 순으로 정렬되며, 마감일 없는 할일은 맨 뒤로 감
