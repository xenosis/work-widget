# P3.5 — 할일 수정/삭제

## 목적

할일전체 화면에서 기존 할일의 정보를 수정하거나 완전히 삭제할 수 있도록 한다.

## 쉬운 설명

각 할일 항목마다 수정/삭제 버튼을 추가한다. 수정을 누르면 폼이 나타나고, 삭제를 누르면 2단계 확인 후 할일을 완전히 제거한다.

## 필요한 입력

- B3.2 (Todo 스키마)
- B2.2 (할일전체 화면)
- P3.3 (할일 추가) 참고

## 결과물

- Todos.jsx에 수정/삭제 UI 추가
- src/lib/todoMutations.js (updateTodo/deleteTodo)
- src/components/TodoEditForm.jsx

## 선행 작업

- P3.3: 할일 추가

## 수행 순서에서의 위치

P3 범위 내 마지막 기능 작업

## done_when을 확인하는 방법

1. 각 할일 행에 수정/삭제 버튼 확인
2. 수정 시 폼이 나타나고, 저장하면 즉시 반영
3. 앱 재시작 후에도 수정 사항 유지
4. 삭제 시 2단계 확인 후 제거
5. 앱 재시작 후에도 삭제 유지
