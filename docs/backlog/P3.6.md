# P3.6 — 트레이 재표시 시 할일전체 화면 데이터·날짜 재조회

## 목적

트레이에서 숨겼다 다시 열 때, 오늘/이번주/나중 그룹이 최신 데이터와 현재 날짜 기준으로 다시 계산되어 표시되어야 한다.

## 쉬운 설명

Todos.jsx는 마운트 시에만 data.json을 읽는다. 하지만 앱은 X버튼 시 창을 숨기기만 하므로, 트레이에서 다시 열어도 마운트되지 않는다. 따라서 며칠을 띄워뒀다 다시 열면 '오늘'이 며칠 전의 '오늘'로 표시된다. Windows show 이벤트 시 data.json과 날짜를 다시 읽도록 갱신해야 한다.

## 필요한 입력

- P1.6: 대시보드 갱신 패턴
- Todos.jsx의 useAppData 훅
- Electron main.js의 show 이벤트

## 결과물

- Todos.jsx의 데이터 재조회 트리거 추가
- 트레이 재표시 시 날짜 재계산 로직

## 선행 작업

- P1.6: 대시보드 데이터 재조회

## 수행 순서에서의 위치

P3 내에서 P3.1 이후, P1.6과 유사한 시기에 구현

## done_when을 확인하는 방법

앱 실행 후 오늘/이번주/나중 그룹이 현재 날짜 기준으로 정확하고, 트레이에 숨겼다 열 때 그룹이 재계산되는지 확인
