# P3 — 할일전체 화면 (B2.2)

## 목적

모든 할일을 한곳에서 볼 수 있는 화면을 구현한다. 할일들을 오늘/이번주/나중으로 날짜 기준으로 그룹핑하고, 각 할일의 완료 여부를 체크할 수 있으며, 필요시 숨김 처리할 수 있다.

## 쉬운 설명

전체 todos 배열을 due_date 기준으로 3개 그룹으로 나눈다: 오늘 마감, 이번주 마감, 나중. 완료된 할일은 취소선으로 표시되지만 목록에 남아있다. 숨김 버튼으로 안보이게 할 수도 있다.

## 필요한 입력

- P0 완료: 앱 기동 완료
- P6.3 필요: 스키마 검증 (손상된 데이터 방어)
- work-widget-requirements.md의 B2.2, B4.2 섹션

## 결과물

src/screens/Todos.jsx — 할일 전체 화면: 날짜별 그룹핑, 완료 체크 인터랙션, 숨김 토글 기능, 할일 추가 입력

## 선행 작업

**P0** — 기본 스캐폴딩 완료 필수.

## 수행 순서에서의 위치

P0 완료 후 시작 가능. P3 내에는 4개의 하위 작업(P3.1~P3.4)이 있으며, 모두 완료되어야 P3이 done.

## done_when을 확인하는 방법

**하위 항목 P3.1 ~ P3.4가 모두 done 상태이면 P3도 완료.**
