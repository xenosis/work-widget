# P3 — 할일전체 화면 (B2.2)

## 목적

모든 할일을 하나의 화면에서 보고 관리할 수 있는 화면을 구현한다. 오늘/이번주/나중으로 날짜 기준 그룹핑하고, 완료 체크, 체크된 항목 숨김, 새 할일 추가 등의 기능을 제공한다.

## 쉬운 설명

프로젝트별로 흩어져 있는 할일들을 모두 한곳에서 보는 화면이다. 마감일을 기준으로 오늘/이번주/나중 세 그룹으로 자동 정렬되고, 완료되면 취소선이 그어진다.

## 필요한 입력

- 요구사항 B2.2: 할일전체 화면 흐름
- P0 완료: 기본 앱 프레임워크
- P6: 날짜 그룹핑, 정렬 함수
