# P4.1 — 목록/편집 2단 레이아웃

## 목적

메모 화면의 2단 레이아웃(좌측 목록, 우측 편집창)을 구현한다.

## 쉬운 설명

좌측에 메모 목록, 우측에 선택한 메모의 내용을 표시하고 편집할 수 있게 한다.

## 필요한 입력

- 메모 데이터 구조(B3.3)
- React state 관리

## 결과물

src/screens/Memos.jsx의 2단 레이아웃과 src/index.css의 관련 클래스

## 선행 작업

없음

## 수행 순서에서의 위치

P4 내에서 가장 먼저 구현

## done_when을 확인하는 방법

1. 메모 화면에서 좌측에 메모 목록, 우측에 제목+본문 input 확인
2. 좌측 메모 클릭 시 우측이 그 메모로 전환
3. "+ 새 메모" 클릭 시 빈 메모 추가 및 선택
4. 창 기본 크기에서 레이아웃이 깨지지 않음
