# P4.2 — 메모 CRUD IPC 연동

## 목적

메모 생성/수정/삭제를 data.json에 반영한다. 메모 데이터를 실제로 저장해서 앱 재시작 후에도 유지된다.

## 쉬운 설명

지금까지 메모는 메모리에만 있었습니다. 이제 메모를 저장하면 data.json의 memos 배열에 기록되고, 앱을 다시 시작해도 계속 있게 됩니다.

## 필요한 입력

- P0.8 완료: IPC가 작동함
- P4.1 완료: UI 레이아웃 준비됨

## 결과물

Memos.jsx의 CRUD 로직: 메모 추가/수정/삭제 시 window.api.saveData() 호출, data.json에 영구 저장

## 선행 작업

**P0.8** — Electron 앱이 실행되고 IPC가 작동함.
**P4.1** — 메모 UI 레이아웃 완료.

## 수행 순서에서의 위치

P4 내에서 P4.1 이후.
