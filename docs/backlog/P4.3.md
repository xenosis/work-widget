# P4.3 — 프로젝트 태그 표시

## 목적

메모 목록에서 프로젝트에 속한 메모는 프로젝트명을 태그로 표시한다.

## 쉬운 설명

메모 목록의 각 항목에 프로젝트명 태그를 표시해 프로젝트명을 한눈에 알 수 있게 한다.

## 필요한 입력

- P4.1 완료: 목록 UI
- projects 배열에서 프로젝트명 조회 로직

## 결과물

Memos.jsx: 각 메모 항목 옆에 프로젝트명 태그 표시

## 선행 작업

- P4.1: 메모 목록 UI

## 수행 순서에서의 위치
