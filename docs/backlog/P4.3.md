# P4.3 — 프로젝트 태그 표시

## 목적

메모 목록에서 프로젝트에 속한 메모는 프로젝트명을 태그로 표시한다. 프로젝트가 없는 메모는 태그 없음.

## 쉬운 설명

메모 목록에서 각 메모 항목을 보면, "어느 프로젝트에 속하는 메모인가"를 한눈에 알 수 있도록 태그를 표시합니다. 예를 들어 "마케팅 프로젝트"에 속한 메모는 "마케팅" 태그가 보입니다.

## 필요한 입력

- P4.1 완료: 목록 UI 준비됨
- projects 배열에서 프로젝트명 조회 로직

## 결과물

Memos.jsx의 목록 부분: 각 메모 항목 옆에 프로젝트명 태그 표시 (project_id가 있을 때만)

## 선행 작업

**P4.1** — 메모 목록 UI 완료.

## 수행 순서에서의 위치

P4 내에서 P4.1 이후.

## done_when을 확인하는 방법

1. 메모 목록을 본다
2. 프로젝트에 속한 메모에 프로젝트명 태그가 보이는가?
3. 태그는 실제 프로젝트명인가? (project_id가 아닌 프로젝트명)
4. 프로젝트 없는 메모에는 태그가 없는가?

## 확인 필요

P4.1의 critical-reviewer 지적: 현재 메모 목록에서 프로젝트 태그가 project_id를 그대로 문자열로 표시 중입니다. 이 태스크에서는 projects 배열에서 프로젝트명을 조회해서 태그를 표시하는 로직으로 변경해야 합니다. (지금은 "proj-1" 같은 id가 보이고 있으므로 프로젝트명으로 교체 필요)
