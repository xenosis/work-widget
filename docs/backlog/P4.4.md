# P4.4 — 메모 소속 프로젝트 지정 UI

## 목적

메모 편집 화면에서 소속 프로젝트를 지정하거나 변경할 수 있게 한다.

## 쉬운 설명

메모를 편집할 때 select 드롭다운에서 "전체 메모" 또는 특정 프로젝트를 선택할 수 있다.

## 필요한 입력

- P4.2: 메모 CRUD 기본 기능
- B2.3: 프로젝트별/전체 메모 구분
- getUsableProjects() 함수

## 결과물

Memos.jsx의 편집창에 프로젝트 select 추가

## 선행 작업

- P4.2, P4.3

## 수행 순서에서의 위치

P4 범위 내 마지막 단계: P4.2 → P4.3 → P4.4

## done_when을 확인하는 방법

1. 편집창에 프로젝트 select 확인
2. 초기값이 메모의 현재 project_id를 정확히 반영
3. "전체 메모"로 해제 시 project_id=null 저장
4. 프로젝트 선택 시 메모 목록에 즉시 태그 표시
5. 앱 재시작 후에도 project_id 유지
