# P4 — 메모 화면 (B2.3)

## 목적

좌측에 메모 목록, 우측에 편집창을 두는 2단 레이아웃으로 메모 기능을 구현한다. 프로젝트별 메모와 전체 메모를 구분하며, 메모를 생성/수정/삭제할 수 있다.

## 쉬운 설명

Notion 스타일의 메모 앱처럼, 왼쪽에 메모 목록이 있고 오른쪽에 선택된 메모의 제목과 내용을 편집할 수 있는 창이 있습니다. 메모는 프로젝트에 속할 수도, 속하지 않을(전체 메모) 수도 있습니다.
