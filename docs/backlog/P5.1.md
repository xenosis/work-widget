# P5.1 — 캘린더 라이브러리 선정

## 목적

월간/주간 뷰를 구현하기 위해 적합한 React 캘린더 라이브러리를 조사해서 선정하고 설치한다.

## 쉬운 설명

캘린더를 0부터 만들기는 복잡하므로, 이미 만들어진 라이브러리(예: react-big-calendar, react-calendar 등)를 찾아서 프로젝트에 추가합니다.

## 필요한 입력

- React 캘린더 라이브러리의 주요 옵션 비교 (npm, github 등에서 조사)
- 월간/주간 뷰 둘 다 지원하는지 확인

## 결과물

- 선정된 캘린더 라이브러리 이름 (예: react-big-calendar)
- package.json에 의존성 추가
- npm install 완료
