# P5.2 — 월간 캘린더 뷰

## 목적

월간 캘린더 뷰를 구현한다. 현재 달의 모든 날짜가 표시되고, 각 날짜에 해당하는 일정들이 보인다.

## 쉬운 설명

일정 화면에 달력이 나오고, 각 날짜 칸에 그 날에 있는 일정들이 나열된다.

## 필요한 입력

- P5.1 완료: 캘린더 함수 구현
- schedules 데이터 구조 이해 (B3.4)

## 결과물

Schedule.jsx의 월간 뷰: 캘린더 렌더링, 각 날짜에 일정 표시, 이전달/다음달 네비게이션

## 선행 작업

- P5.1: 캘린더 함수

## 수행 순서에서의 위치

P5 내에서 P5.1 이후

## done_when을 확인하는 방법

1. 월간 캘린더가 표시됨
2. 현재 달의 모든 날짜가 보임
3. 각 날짜에 일정이 표시됨
4. 이전달/다음달 버튼으로 월 이동 가능
