# P5.2 — 월간 캘린더 뷰

## 목적

캘린더 라이브러리를 사용해서 월간 뷰를 구현한다. 현재 달의 모든 날짜가 표시되고, 각 날짜에 해당하는 일정들이 보인다.

## 쉬운 설명

일정 화면 기본은 달력이 나오는 달력 보기입니다. 현재 달의 모든 날씨가 표시되고, 각 날짜 칸에 그 날에 있는 일정들이 나열됩니다.

## 필요한 입력

- P5.1 완료: 캘린더 라이브러리 설치됨
- schedules 데이터 구조 이해 (work-widget-requirements.md B3.4)

## 결과물

Schedule.jsx의 월간 뷰: 캘린더 형식 렌더링, 각 날짜에 일정 표시, 이전달/다음달 네비게이션

## 선행 작업

**P5.1** — 캘린더 라이브러리 선정 및 설치.

## 수행 순서에서의 위치

P5 내에서 P5.1 이후. P5.3(주간 뷰)이 탭을 통해 월간 뷰와 전환.

## done_when을 확인하는 방법

1. 일정 화면에서 월간 캘린더가 표시되는가?
2. 현재 달의 모든 날짜가 보이는가?
3. 테스트: 일정을 data.json에 추가하면 캘린더의 해당 날짜에 표시되는가?
4. 이전달/다음달 버튼으로 월 이동이 가능한가?
