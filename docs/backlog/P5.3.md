# P5.3 — 주간 뷰 + 상단 탭 전환

## 목적

주간 뷰를 추가로 구현하고, 상단 탭으로 월간 뷰와 주간 뷰를 전환할 수 있게 한다.

## 쉬운 설명

캘린더 라이브러리가 주간 뷰도 제공한다면, 그것을 사용해서 일주일 단위의 뷰도 구현합니다. 탭을 눌러 "월간" ↔ "주간"을 전환할 수 있습니다.

## 필요한 입력

- P5.2 완료: 월간 뷰가 작동함
- 선택한 캘린더 라이브러리의 주간 뷰 옵션

## 결과물

Schedule.jsx에 추가: 주간 뷰 컴포넌트, 상단 탭 UI (월간/주간 버튼), 탭 클릭으로 뷰 전환

## 선행 작업

**P5.2** — 월간 뷰 완료.

## 수행 순서에서의 위치

P5 내에서 P5.2 이후.

## done_when을 확인하는 방법

1. 일정 화면에 상단 탭(월간/주간)이 보이는가?
2. 월간 탭을 클릭하면 월간 뷰가 표시되는가?
3. 주간 탭을 클릭하면 주간 뷰가 표시되는가?
4. 주간 뷰에서 일정들이 올바르게 표시되는가?
