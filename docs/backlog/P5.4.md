# P5.4 — 반복 일정(요일 지정) 등록

## 목적

일정을 등록할 때 반복 요일을 지정하는 기능을 구현한다. "매주 월, 수, 금" 같이 특정 요일들에 반복되는 일정을 등록할 수 있게 한다.

## 쉬운 설명

일정을 새로 추가할 때, "이건 일회성인가, 반복인가?"를 선택하고, 반복이면 "어떤 요일에 반복되는가?"를 지정합니다. 예를 들어 월요일과 금요일 체크박스를 선택하면 매주 월, 금에 반복되는 일정이 됩니다.

## 필요한 입력

- schedules 데이터 구조 (is_recurring, recurrence_days 필드) 이해
- UI: 요일 선택 체크박스

## 결과물

Schedule.jsx의 일정 추가 폼: is_recurring 토글, recurrence_days 요일 선택 체크박스 (월~일), 저장 로직

## 선행 작업

**P5.2** — 캘린더 뷰가 표시됨.

## 수행 순서에서의 위치

P5 내에서 P5.2~P5.3 이후.

## done_when을 확인하는 방법

1. 새 일정을 추가하는 폼을 본다
2. "반복" 옵션을 선택한다
3. 요일 선택 UI가 나타나는가?
4. 월, 수, 금을 선택하고 저장한다
5. 캘린더에서 매주 월, 수, 금에 일정이 나타나는가?
6. 앱을 재시작해도 반복 일정이 유지되는가?
