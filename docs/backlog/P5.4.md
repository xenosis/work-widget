# P5.4 — 반복 일정(요일 지정) 등록

## 목적

일정 화면에서 매주 특정 요일에 반복되는 일정(예: 매주 월요일 회의)을 하나의 규칙 레코드로 저장하고, 매번 렌더링할 때 자동으로 해당 요일들에 표시되어야 한다. 회차별 레코드 없이 규칙 하나만 관리하므로, P5.5(수정)와 P5.6(삭제)은 이 설계 위에서 자동으로 성립한다.

## 쉬운 설명

일정을 추가할 때 "반복" 옵션을 켜고 요일(월~일)을 체크박스로 선택하면 규칙이 저장된다. 다음 주와 다다음 주에도 같은 요일에 자동으로 표시된다. 규칙 하나를 수정하면 모든 회차가 함께 바뀌고, 삭제하면 모두 사라진다. 한 번의 작업으로 반복/비반복 생성, 타입 전환, 수정, 삭제를 모두 지원한다.

## 필요한 입력

- P5.2 완료: getSchedulesForDate 함수가 반복 규칙을 전개할 수 있음
- P5.3 완료: 월간/주간 뷰 전환 인프라
- B3.4 스키마: schedules 배열의 is_recurring, recurrence_days, title, start_date 필드
- IPC 연동: window.api.loadData/saveData 통해 데이터 저장/로드

## 결과물

- ScheduleAddForm.jsx: 일회성/반복 통합 추가 폼(반복 체크박스+요일 칩, 세로 flex 레이아웃)
- ScheduleEditForm.jsx: 일정 수정 폼(기준일 명시, '모든 회차 적용' 경고)
- DeleteScheduleButton.jsx: 2단계 삭제 확인(반복이면 '모든 회차가 함께 삭제됩니다' 경고)
- scheduleFactory.js, scheduleMutations.js: 반복/비반복 레코드 생성, 수정, 삭제 순수 함수 (vitest 테스트 포함)
- Schedule.jsx: handleAddSchedule/handleEditSchedule/handleDeleteSchedule 메서드 + saving state 가드
- 관련 CSS (.schedule-add-form, .schedule-form-row 등)

## 선행 작업

- P5.2: 반복 일정 계산 함수(getSchedulesForDate가 recurrence_days 전개 가능)
- P5.3: 월간/주간 뷰 전환 인프라

## 수행 순서에서의 위치

P5 내 완전한 반복 일정 CRUD 구현. 이 작업으로 P5.5(수정 시 일괄 반영)와 P5.6(삭제 + 비반복 CRUD)도 구현 차원에서 자동 충족되므로, P5.5/P5.6은 이 문서화를 참고해 검증하면 된다. 2026-09-24 완료, critical-reviewer 지적으로 420px 레이아웃 오버플로와 화면 단위 저장 경합 2건이 추가로 수정됨.

## done_when을 확인하는 방법

1. npm run lint 통과(eslint .)
2. npm test 통과(vitest 152개, scheduleFactory/scheduleMutations 테스트 포함)
3. npm run build 성공(dist/ 생성)
4. npm run dev로 Electron 앱 기동 후 Schedule 탭 진입
5. "일정 추가" 폼에서 "매주 반복" 체크박스 출현 확인
6. 오늘 요일을 선택, 제목 입력 후 저장 → 캘린더에 오늘 dot 표시, 상세 보기에 일정 노출 확인
7. 다음 달로 이동 → 같은 요일에 dot 표시 확인
8. 같은 요일의 다음 회차에서 수정 → 현재 자리에서 바로 반영 확인('모든 회차에 적용' 경고 문구 노출)
9. 삭제(2단계 확인) → dot 사라짐 확인
10. 앱 재시작 후 data.json 확인 → 규칙 레코드가 저장되어 있고, 일회성 일정은 유지, 반복 삭제는 유지되는지 확인
