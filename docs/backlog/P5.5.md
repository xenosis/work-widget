# P5.5 — 반복 일정 수정 시 전체 회차 일괄 반영

## 목적

반복 일정의 규칙(recurrence_days 등)을 수정할 때, 그 규칙에 해당하는 모든 미래 회차에 일괄 반영되도록 구현한다. 특정 회차만 예외 처리하는 기능은 없다.

## 쉬운 설명

매주 월, 수, 금에 반복되는 "팀 미팅" 일정을 수정해서 "월, 금"으로 바꾸면, 이제부터 일어날 모든 미팅이 월, 금로 바뀝니다. 이미 지난 회차는 그대로 두고, 미래 회차만 규칙을 적용합니다.

## 필요한 입력

- P5.4 완료: 반복 일정 등록 기능
- 규칙 수정 로직 (is_recurring = true인 항목의 recurrence_days 변경)

## 결과물

Schedule.jsx의 수정 로직: 반복 일정을 수정할 때 규칙을 업데이트하면, 그 규칙이 미래의 모든 발생에 적용됨

## 선행 작업

**P5.4** — 반복 일정 등록 완료.

## 수행 순서에서의 위치

P5 내에서 P5.4 이후.

## done_when을 확인하는 방법

1. 반복 일정을 수정한다
2. recurrence_days를 변경한다 (예: ["월", "수", "금"] → ["월", "금"])
3. 저장한다
4. 캘린더에서 앞으로의 회차가 새 규칙을 따르는가?
5. 이미 지난 회차는 변경되지 않는가?
