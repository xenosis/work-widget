# P5.6 — 일정 삭제 + 비반복(일회성) 일정 CRUD

## 목적
반복 일정 삭제와 비반복 일정의 전체 생성/수정/삭제가 필요하다(critical-reviewer가 P2.5 리뷰 중 발견). P5.4에서 반복/비반복 통합 등록이 이미 구현되었으므로, 남은 부분은 삭제와 비반복 CRUD의 상세 검증이다.

## 쉬운 설명
일회성 일정(예: 내일 오후 3시 면접)과 반복 일정(매주 월요일 회의) 둘 다 추가/수정/삭제할 수 있다. 반복 일정을 삭제하면 모든 미래 회차가 한 번에 사라진다.

## 필요한 입력
- P5.4 완료: ScheduleAddForm/EditForm/DeleteButton이 반복/비반복 통합 구현
- B3.4 스키마: is_recurring=false 비반복 일정
- B2.4 요구사항: 반복 일정 삭제 시 모든 회차 소멸, 특정 회차만 예외는 없음

## 결과물
P5.4에서 이미 구현됨:
- ScheduleAddForm.jsx: is_recurring 토글로 일회성/반복 선택
- ScheduleEditForm.jsx: 둘 다 수정 가능
- DeleteScheduleButton.jsx: 2단계 삭제 확인
- scheduleMutations.js의 removeSchedule 함수

## 선행 작업
- P5.4 (반복 일정 등록): done. 같은 폼/함수로 비반복도 이미 통합 처리

## 수행 순서에서의 위치
P5 내 CRUD의 Delete와 비반복 관련 부분. P5.4의 통합 구현으로 이미 충족되었지만, 실제 동작 확인과 문서화 필요.

## done_when을 확인하는 방법
1. npm run dev로 Electron 앱 기동
2. Schedule 탭 → 일정 추가 폼
3. "반복" 토글 OFF → 일회성 일정 추가(특정 날짜, 제목)
4. 그 날짜에만 표시, 다른 날짜엔 안 보임 확인
5. 일회성 일정 수정(제목/날짜 변경) → 저장 후 반영 확인
6. 비반복 일정 삭제(2단계 확인) → 사라짐
7. 반복 일정 등록 후 삭제 → 모든 회차 함께 사라짐 확인
8. 앱 재시작 후 모든 변경 사항 유지 확인
