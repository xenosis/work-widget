# P5.7 — 일정 화면 트레이 재표시/자정 경과 시 오늘·선택 날짜 재동기화

## 목적

Schedule.jsx의 monthCursor/weekAnchor/selectedDate 상태가 초기 마운트 시 오늘을 기준으로 1회만 설정되어, 사용자가 창을 켜둔 채 자정을 넘기거나 트레이에서 재표시할 때 데이터는 재조회되지만 그리드는 어제를 계속 보여주는 문제를 해결한다. 다만 사용자가 임의로 다른 달/주를 탐색하는 능력과 자동 리셋의 균형을 맞춰야 하므로 정책 결정 후 구현한다.

## 쉬운 설명

밤 10시에 9월 30일을 보고 있다가 창을 켠 채로 자정이 지나 10월 1일이 되면, 화면이 자동으로 오늘(10월 1일)로 돌아가야 할까? 아니면 사용자가 보던 9월 30일을 계속 보여줘야 할까? 확정된 정책은: **오늘이 실제로 바뀐 경우에만 자동으로 오늘로 리셋**한다. 덕분에 사용자가 9월을 보다가 자정 전 트레이를 내렸다가 다시 띄우면 여전히 9월을 보게 되고, 실제로 다음날이 되어 창을 띄우면 새 오늘로 리셋된다.

## 필요한 입력

- **P5.3 완료**: monthCursor, weekAnchor, selectedDate 상태 관리 인프라
- **B5.1 윈도우 특성**: hide()는 destroy() 아님 (컴포넌트 마운트 상태 유지, 따라서 state가 유지됨)
- **요구사항 B2.4**: 일정 화면의 월간/주간 뷰 정책
- **정책 결정(2026-09-25)**: 실제 오늘이 바뀐 경우에만 리셋하기로 확정

## 결과물

- **Schedule.jsx**: knownToday state 추가, React 렌더 중 상태 조정 패턴으로 today와 knownToday 비교 후 다르면 monthCursor/weekAnchor/selectedDate를 오늘 기준으로 리셋
- **electron/main.js**: 'focus' 이벤트를 notifyDataChanged에 연결해 창 포커스 시에도 날짜 변화 감지
- **src/lib/scheduleGrid.js**: todayResetCursors 순수함수로 추출 (vitest 2개 케이스)

## 선행 작업

- **P5.3**: 주간/월간 뷰 인프라 완료

## 수행 순서에서의 위치

P5 내 마지막 cleanup 작업. P5.1~P5.6 기능이 완성된 후, 사용자 경험 개선 단계. 원래는 needs_info 상태였으나 2026-09-25 사람 결정으로 정책이 확정되고 2026-09-24T23:40:34Z에 구현 완료됨. 이제 P5의 7개 하위 작업 모두 done이므로 P5 부모도 done.
