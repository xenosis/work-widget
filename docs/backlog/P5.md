# P5 — 일정 화면 (B2.4, 루틴 포함)

## 목적

사용자가 자신의 일정(schedule)을 월간/주간 뷰로 조회하고, 종일(시간 없음) 일정과 반복 일정(요일 지정, 회차별 예외 없음)을 등록·수정·삭제할 수 있는 화면을 구현한다. 이는 work-widget의 5개 주요 화면 중 하나이며, 대시보드(P1)가 '오늘 일정'으로 요약만 보여주는 것과 달리 여기서는 전체 일정을 관리할 수 있어야 한다.

## 쉬운 설명

사용자가 "일정" 탭을 클릭하면 월간 캘린더(달력)가 뜬다. 월간 뷰에서 각 날짜에 일정이 있으면 점으로 표시되고, 날짜를 클릭하면 그 날의 일정 목록이 아래에 나타난다. 상단 탭으로 "주간" 뷰로 전환하면 한 주일이 가로로 7일 펼쳐지며 같은 방식으로 일정을 볼 수 있다. 일정을 추가하려면 날짜를 클릭한 상태에서 "일정 추가" 버튼을 누르고, 제목과 반복 여부(매주 반복/일회성)를 선택한다. 반복 일정은 "월/화/수/목/금/토/일" 중 원하는 요일을 눌러 저장하면 그 요일마다 자동으로 나타난다. 이미 저장한 일정은 클릭해서 수정하거나 삭제할 수 있다.

## 필요한 입력

- **데이터 저장 계층(P0)**: data.json에 schedules 배열을 읽고 쓸 수 있어야 함
- **IPC 연동(P1.5와 동일 패턴)**: electron/preload.js의 window.api.loadData/saveData
- **일정 그리드 계산(P5.1)**: 월간/주간 캘린더 그리드를 생성하는 scheduleGrid.js의 순수함수들
- **요구사항 문서(B2.4, B3.4)**: 월간/주간 뷰, 종일 일정, 반복 일정(recurrence_days) 스키마 정의

## 결과물

- **src/screens/Schedule.jsx**: 메인 화면 (탭 전환, 렌더러 컨테이너)
- **src/components/ScheduleMonthView.jsx, ScheduleWeekView.jsx, ScheduleDateDetail.jsx**: 뷰별 컴포넌트
- **src/components/ScheduleAddForm.jsx, ScheduleEditForm.jsx**: 일정 추가/수정 폼
- **src/lib/scheduleGrid.js**: 월/주 그리드 계산, 반복 일정 노출 판정 (vitest)
- **src/lib/scheduleFactory.js, src/lib/scheduleMutations.js**: 일정 생성/수정/삭제 로직 (vitest)
- **src/index.css**: schedule-* 스타일 (월간/주간 셀, 점 표시, 날짜 선택 테두리)

## 수행 순서에서의 위치

이 작업은 P0(기초 인프라) 다음의 P1(대시보드)·P2(메모)와 병렬로 진행되는 주요 화면 중 하나다. P0 완료 후 언제든 착수 가능하며, 일정 화면이 완성되면 사용자가 전체 업무 흐름을 일관되게 경험할 수 있다. 이후 P7(위젯 운영, 트레이/백업)과 P8(패키징)은 이 화면을 포함한 모든 기능이 안정화된 후 진행된다.

## done_when을 확인하는 방법

이 작업의 done_when은 "하위 항목 전부 done"이므로, P5.1부터 P5.7까지 7개 모든 하위 작업이 done인지 확인:

```bash
node scripts/backlog/cli.js list | grep '"id"' | grep 'P5\.' 
# 위 결과의 각 항목에 대해
node scripts/backlog/cli.js show P5.1 P5.2 P5.3 P5.4 P5.5 P5.6 P5.7
# 모두 status: done 확인
```

또는 npm run dev로 앱을 띄워:
1. "일정" 탭 클릭 → 월간 캘린더 표시
2. 상단 탭으로 주간/월간 전환 → 정상 작동
3. 날짜 클릭 → 하단 일정 상세 표시
4. "일정 추가" 버튼 → 제목 입력, 반복/비반복 선택 후 저장
5. 저장된 일정이 달력에 표시되고, 반복일정은 여러 주에 표시됨
6. 수정/삭제 후 즉시 화면에서 사라지고 앱 재시작 후에도 유지
