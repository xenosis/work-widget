# P5 — 일정 화면 (B2.4, 루틴 포함)

## 목적

월간/주간 탭으로 전환 가능한 캘린더 뷰를 구현하고, 일회성 일정과 반복 일정(루틴)을 모두 표시한다.

## 쉬운 설명

일정 화면은 캘린더로 되어 있습니다. 탭을 눌러 월간 뷰와 주간 뷰를 전환할 수 있고, 일정을 등록/수정할 때 반복 요일을 지정해서 "매주 월, 수, 금"처럼 반복되는 일정도 만들 수 있습니다.

## 필요한 입력

- P0 완료: 앱이 실행됨
- work-widget-requirements.md의 B2.4, B3.4 섹션

## 결과물

src/screens/Schedule.jsx — 일정 화면: 월간/주간 캘린더 뷰 선택 탭, 캘린더 렌더링, 반복 일정 데이터 표시

## 선행 작업

**P0** — 기본 스캐폴딩 완료 필수.

## 수행 순서에서의 위치

P0 완료 후 시작 가능. P5 내에는 5개의 하위 작업(P5.1~P5.5)이 있으며, 모두 완료되어야 P5가 done.
