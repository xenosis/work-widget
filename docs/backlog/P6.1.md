# P6.1 — Project.progress 계산 함수

## 목적
프로젝트에 소속된 할일들의 완료 비율을 저장하지 않고 조회할 때마다 순수하게 계산하는 함수를 구현한다(B3.1 원칙).

## 쉬운 설명
"프로젝트의 진행률 = (완료된 할일 개수 / 전체 할일 개수) × 100"을 정수 %로 계산한다. 소속 할일이 없으면 0%. 이 값은 data.json에 저장하지 않는다.

## 필요한 입력
- B3.1/B3.2 스키마: projects, todos 배열 구조
- Todo.project_id, Todo.completed 필드 이해

## 결과물
- src/lib/projectProgress.js: calculateProjectProgress(projectId, todos) 함수
- vitest 회귀테스트 (7개 케이스: 0%, 67%, 100%, 소속없음, 배열 null/undefined 방어)

## 선행 작업
없음

## 수행 순서에서의 위치
P6 내 가장 먼저 구현된 항목. P1.3/P2.1/P2.4가 이 함수를 사용한다.

## done_when을 확인하는 방법
1. src/lib/projectProgress.js에 calculateProjectProgress 함수 존재 확인
2. npm test 실행 → projectProgress.test.js의 7개 테스트 모두 PASS
3. 수동 검증: 
   - 3개 할일 중 2개 완료 → 67%
   - 2개 할일 모두 완료 → 100%
   - 할일 0개 → 0%
   - null/undefined 입력 → 에러 없이 0%
