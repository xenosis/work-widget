# P6.2 — 프로젝트 상태 자동 전환 로직

## 목적

프로젝트의 모든 할일이 완료되면 프로젝트 상태를 자동으로 "완료"로 전환하고, 완료된 프로젝트에 새 할일이 추가되거나 완료된 할일이 재개되면 다시 "진행중"으로 자동 전환한다. "보류"는 수동으로만 설정한다.

## 쉬운 설명

프로젝트 상태 규칙: 1) 해당 프로젝트의 모든 할일이 완료(completed = true) → status = "완료", 2) 완료된 프로젝트에 미완료 할일 추가 → status = "진행중" 자동 전환, 3) "보류"는 사용자가 수동으로만 설정 가능.

## 필요한 입력

- P6.1 완료: progress 계산 함수 (완료 여부 판단에 참고)
- projects와 todos의 관계 이해

## 결과물

프로젝트 상태 전환 로직: 할일 CRUD 시점에 호출되는 함수, 프로젝트 status를 규칙에 따라 변경

## 선행 작업

**P6.1** — Progress 계산 함수 완료.

## 수행 순서에서의 위치

P6 내에서 P6.1 이후. P2.5(프로젝트 CRUD)에서 이 로직을 활용.

## done_when을 확인하는 방법

1. 프로젝트의 모든 할일을 완료한다
2. 프로젝트 status가 "완료"로 변경되는가?
3. "완료" 프로젝트에 새 미완료 할일을 추가한다
4. status가 "진행중"으로 다시 변경되는가?
5. 프로젝트를 "보류"로 수동 설정하면 자동 전환되지 않는가?
