# P6.2 — 프로젝트 상태 자동 전환 로직

## 목적
프로젝트에 속한 모든 할일이 완료되면 자동으로 '완료' 상태로 전환하고, 완료된 프로젝트에 미완료 할일이 추가되거나 할일을 미완료로 변경하면 자동으로 '진행중'으로 복귀하는 규칙을 구현한다. '보류' 상태는 수동으로만 변경 가능하다(B4.3 규정).

## 쉬운 설명
프로젝트 상태가 규칙에 따라 자동으로 바뀌어야 하는데, 먼저 그 규칙을 순수 함수(`deriveProjectStatus`)로 구현한다. 이 함수는 "현재 상태 + 프로젝트의 할일 목록"을 받아서 B4.3의 규칙에 따라 "다음 상태"를 계산한다. 예: 모든 할일이 체크됐으면 완료→완료, 미완료 할일이 하나라도 있으면 완료→진행중, 보류면 어떤 할일 상태든 보류 유지.

## 필요한 입력
- P6.1(projectProgress.js) 완료: 프로젝트 진행률 계산 함수 필요
- 요구사항 B4.3: 프로젝트 상태 자동 전환 규칙 정의 문서

## 결과물
`src/lib/projectStatus.js`의 `deriveProjectStatus(currentStatus, projectId, todos)` 함수:
- 입력: 현재 상태(진행중/완료/보류), 프로젝트 ID, 전체 할일 배열
- 출력: 계산된 다음 상태
- 내부에서 projectId로 필터링해 소비처가 전체 배열을 잘못 넘겨도 방어 (P6.1과 동일 계약)

## 선행 작업
P6.1 — 프로젝트 진행률 계산 함수

## 수행 순서에서의 위치
P6은 데이터 계층 순수 로직을 구축하는 단계다. P6.1이 진행률을, P6.2가 상태 전환 규칙을 구현하면, 실제로 이 상태 변경이 저장되는 시점(P3.1 할일 체크박스 / P2.5 저장 경로)은 다른 작업들이 담당한다. 현재 이 함수는 테스트로만 검증되고 어떤 화면/IPC 핸들러에서도 아직 호출되지 않는다.

## done_when을 확인하는 방법
1. `npm test`를 실행하고 projectStatus.test.js의 모든 케이스가 PASS하는지 확인 (11개 케이스)
2. B4.3 규칙 검증:
   - 모든 할일 완료(completed=true 전부) → status = "완료"
   - 미완료 할일이 하나 이상 → status = "진행중" (또는 이미 진행중이면 유지)
   - status = "보류" → 할일 상태와 무관하게 "보류" 유지
   - undefined/enum 밖 값 → 정규화해서 "진행중"으로 처리
