# P6.4 — data.json 레코드 단위 필드 기본값/마이그레이션

## 목적

P6.3은 최상위 구조(4개 배열 키) 손상만 방어했습니다. 구버전 data.json의 레코드들(projects, todos, memos, schedules 배열의 각 항목)에 B3에서 추가된 신규 필드가 누락되어 있으면, 그 필드들을 기본값으로 채워주는 로직을 구현합니다. 이를 통해 구형 파일 형식도 최신 코드와 호환되게 합니다.

## 쉬운 설명

만약 과거 버전에서 저장한 todo에 priority 필드가 없다면, 최신 코드가 그것을 읽을 때 undefined가 되어 렌더링에서 죽을 수 있습니다. 이 작업에서는 로드 시점에 누락된 필드를 기본값으로 채워서(예: priority = "중"), 코드가 항상 안전하게 필드를 접근하도록 합니다.

## 필요한 입력

- P6.3 완료: 최상위 구조 검증 로직
- work-widget-requirements.md의 B3 섹션 (전체 필드 정의) 검토
- 각 필드의 기본값 결정

## 결과물

electron/dataStore.js의 정규화 함수에 레코드 단위 필드 검증/기본값 채우기 로직 추가

## 선행 작업
