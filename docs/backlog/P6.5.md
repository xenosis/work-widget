# P6.5 — 테스트 러너 도입(vitest)

## 목적
src/lib의 순수 함수들(projectProgress/projectStatus/dateRange)을 자동으로 검증하는 테스트 러너를 도입하여 회귀 버그를 방지한다.

## 쉬운 설명
npm test를 실행하면 모든 순수 함수의 단위테스트가 자동으로 실행된다. 이전에는 수동 node 실행에만 의존했고 gate가 없어 검증 누락 위험이 있었다.

## 필요한 입력
- P6.1/P6.2 완료: 함수와 검증 케이스
- vite 5 호환 vitest 버전

## 결과물
- package.json: vitest devDependency, "test": "vitest run" 스크립트
- src/lib/*.test.js: projectProgress(7), projectStatus(11), dateRange(10) 테스트
- vitest 실행 시 30+ 테스트 모두 PASS
- .claude/hooks/stop-full-check.js에 vitest 자동 실행 추가

## 선행 작업
- P6.1 (진행률 계산): done
- P6.2 (상태 자동 전환): done

## 수행 순서에서의 위치
P6 인프라의 마지막. 이후 task들의 gate에 "npm test" 지정 가능해진다.

## done_when을 확인하는 방법
1. npm test 실행 → 30+ 테스트 PASS
2. npm run lint 통과
3. npm run build 통과 (테스트 파일 미포함)
4. vite.config.js에 test.include=['src/**/*.test.js'] 명시
5. 의도적 실패 추가 → npm test 실패 보고 → 원복 후 PASS 재확인

## 확인 필요
- vitest와 vite 5, Electron 환경 호환성 (현재 확인됨)
- 테스트 커버리지 범위: src/lib 순수함수만 (DOM 테스트는 jsdom 미설치로 제외)
