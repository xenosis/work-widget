# P6 — 데이터 계층 공통 로직 (B3/B4.3)

## 목적

여러 화면에서 공유하는 데이터 처리 로직들(progress 계산, 프로젝트 상태 자동 전환, 스키마 검증)을 구현한다.

## 쉬운 설명

대시보드, 프로젝트 화면, 할일 화면 등 여러 곳에서 같은 로직이 필요합니다. 예를 들어 프로젝트의 진행률을 계산하는 방식, 모든 할일이 완료되면 프로젝트 상태를 자동으로 "완료"로 바꾸는 규칙 등을 한곳에서 구현해서 여러 화면이 공유하게 합니다.

## 필요한 입력

- work-widget-requirements.md의 B3 (데이터 구조), B4.3 (상태 전환 규칙), B6.1 (progress 계산)

## 결과물

- src/lib/projectProgress.js — progress 계산 함수
- src/ 또는 electron/에 프로젝트 상태 자동 전환 로직
- electron/dataStore.js — 스키마 검증/정규화 로직

## 선행 작업

**P0** — 기본 스캐폴딩 완료 필수.

## 수행 순서에서의 위치

P6은 인프라 작업이므로 P1~P5와 병렬 진행 가능. P6.1(progress 계산)은 P1.3, P2.4 등에서 필요하므로 먼저 완료되어야 함.

## done_when을 확인하는 방법
