# P7.1 — 실제 트레이 아이콘 리소스 적용

## 목적

현재 임시 빈 아이콘(nativeImage.createEmpty())을 실제 아이콘 파일로 교체한다.

## 쉬운 설명

지금은 트레이에 아무것도 보이지 않습니다. 실제 아이콘 이미지(PNG, ICO 등)를 만들거나 가져와서 트레이에 표시하는 것입니다.

## 필요한 입력

- 아이콘 이미지 파일 (PNG 또는 ICO)
- Electron의 nativeImage API 이해

## 결과물

- assets/ 폴더에 아이콘 이미지 파일
- electron/main.js에서 아이콘 파일을 로드해서 Tray에 적용
