# P7.2 — Windows 시작프로그램 자동 등록

## 목적

Windows 시작(로그인) 시 위젯이 자동으로 실행되도록 등록한다. 요구사항 Part A의 "Windows 시작 시 자동 실행(서비스 또는 시작 프로그램 등록)" 항목을 구현한다.

## 쉬운 설명

사용자가 PC를 켜고 Windows에 로그인할 때마다 이 업무 위젯이 자동으로 실행되도록 설정한다. Electron의 `app.setLoginItemSettings()` API를 사용해서 이를 구현한다. 다만 개발 과정에서 실수로 개발 버전이 자동 실행되도록 등록되는 일을 피하고, 사용자가 Windows 설정에서 직접 끈 자동 실행을 앱이 자꾸 다시 켜도록 짜증나게 하지 않도록 최초 1회만 등록한다.

## 필요한 입력

- Electron 메인 프로세스 파일(`electron/main.js`)
- `app.isPackaged` 검사를 통해 배포 빌드 여부 판정
- `app.getPath('userData')` 사용 가능한 환경(Electron 런타임)
- 실제 설치본 빌드 환경(P8.1/electron-builder 완료)

## 결과물

- `electron/autoLaunch.js`: 순수 Node.js 함수들 (`getAutoLaunchFlagPath`, `hasRegisteredAutoLaunch`, `markAutoLaunchRegistered`) — Electron 런타임 없이도 테스트 가능하게 설계됨
- `electron/autoLaunch.test.js`: vitest 기반 유닛 테스트 (플래그 파일 존재 여부 판정, 중복 호출 멱등성 확인 등 3개 케이스)
- `electron/main.js` 수정: `configureAutoLaunch()` 함수 추가, `app.whenReady()` 콜백에서 호출
- `userData` 하위에 `auto-launch-registered.flag` 마커 파일 생성 (처음 실행 시 한 번만, 다음 실행부터는 이 파일 존재 확인으로 등록 건너뜀)

## 선행 작업

없음 (deps가 비어 있음)

## 수행 순서에서의 위치

P7(트레이/시작프로그램/백업/창상태) 중 하나. P7.1(트레이 아이콘), P7.3(자동 백업), P7.4(창 동작 검증), P7.5(창 위치/크기 저장)와는 병렬로 진행되며, 최종 검증은 P8.2(설치본 테스트)에서 이루어진다. P7.6(단일 인스턴스 락)은 이 작업의 완료로 인해 새로 생기는 "중복 실행" 위험에 대응하기 위해 deps=P7.2로 의존한다.

## done_when을 확인하는 방법

**최종 검증 완료 (2026-09-25)**

사용자가 Windows 개발자 모드를 활성화한 후, 다음과 같이 검증했다:

1. **실제 패키지 빌드로 검증**:
   - `electron-builder --dir --win`으로 배포용 `.exe` 빌드 (work-widget.exe)
   - Playwright로 그 exe를 직접 실행
   - 앱 실행 중에 `app.isPackaged === true` 상태 확인
   - `configureAutoLaunch()` 호출되었음을 확인

2. **시작프로그램 등록 상태 확인**:
   - `app.getLoginItemSettings().openAtLogin === true` 확인
   - 등록된 `launchItems[0].path`가 빌드된 exe 경로와 정확히 일치 확인

3. **버그 발견 및 해결**:
   - **버그**: 원래 `package.json`의 `productName='업무 위젯'`(공백 포함)이 exe 파일명으로 그대로 사용되면서 Windows 레지스트리 Run 키에 경로가 잘려 등록되는 문제 발생
   - **해결**: `package.json`에 `build.executableName='work-widget'`을 추가해 exe 파일명과 표시 이름을 분리
   - **재검증**: 수정 후 다시 빌드했을 때 경로가 완전히 일치하는 것을 확인

4. **정리**:
   - 검증 후 등록된 로그인 항목, 플래그 파일, 테스트용 userData 디렉토리 전부 정리
   - 사용자의 실제 시작 프로그램에 흔적을 남기지 않음
