# P7.2 — Windows 시작프로그램 자동 등록

## 목적

Electron 앱을 Windows 시작 시 자동으로 실행되는 프로그램으로 등록한다.

## 쉬운 설명

사용자가 PC를 부팅할 때마다 이 위젯이 자동으로 실행되도록 설정하는 것입니다. electron-builder의 NSIS 옵션이나 app.setLoginItemSettings API를 사용합니다.

## 필요한 입력

- electron-builder 설정 (package.json build 섹션) 또는 app.setLoginItemSettings API
- Windows 레지스트리의 "HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run" 경로 이해

## 결과물

- package.json의 build.nsis 섹션에 startup 설정 추가, 또는
- electron/main.js에서 app.setLoginItemSettings() 호출

## 선행 작업

**P0.2** — package.json 준비됨.

## 수행 순서에서의 위치

P7 내에서 독립적.

## done_when을 확인하는 방법

1. Windows에서 "설정 > 앱 > 시작프로그램"을 확인한다
2. "work-widget"이 목록에 있고 활성 상태인가?
3. 또는 Windows 레지스트리의 Run 폴더에 항목이 있는가?
4. PC를 재부팅한다
5. 로그인 후 자동으로 앱이 실행되는가?
