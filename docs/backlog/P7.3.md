# P7.3 — 데이터 자동 백업

## 목적

정기적으로 data.json을 백업해서, 사용자가 데이터를 실수로 손상시켰을 때 복구할 수 있도록 한다.

## 쉬운 설명

매일 1회(또는 다른 주기로) data.json을 복사해서 backup/ 폴더에 저장합니다. 오래된 백업(예: 7일 이상)은 자동으로 삭제해서 저장 공간을 관리합니다.

## 필요한 입력

- electron/dataStore.js의 getDataPath() 함수
- fs 모듈의 copyFile, unlink 등 파일 작업 API
- 백업 주기 설정 (일단 "하루 1회" 기본값)

## 결과물

- electron/ 또는 별도의 백업 로직 파일: 매일 특정 시간에 실행되는 백업 함수
- app.userData/backups/ 폴더에 날짜별 백업 파일 저장
- 오래된 백업 정리 로직

## 선행 작업

**P0.3** — dataStore.js 완료 (loadData, saveData 함수).

## 수행 순서에서의 위치

P7 내에서 독립적. 앱 기동 후 백업 로직이 주기적으로 실행.

## done_when을 확인하는 방법

1. 앱을 실행한다
2. 일정 시간 경과 후 app.userData/backups/ 폴더를 확인한다
3. 백업 파일이 생성되었는가?
4. 파일명에 날짜/시간 정보가 포함되어 있는가?
5. 여러 날을 거친 후, 오래된 백업이 자동으로 삭제되는가?
