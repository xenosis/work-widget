# P7 — 위젯 운영 동작 (B5)

## 목적

Electron 앱의 운영 단계 기능들(트레이 아이콘, Windows 시작 프로그램 자동 등록, 데이터 백업)을 구현한다.

## 쉬운 설명

앱이 실행되는 방식, 트레이에 보이는 아이콘, Windows 부팅 시 자동 시작, 정기적 백업 등 "프로그램이 어떻게 실행되고 관리되는가"와 관련된 작업들입니다.

## 필요한 입력

- P0.8 완료: 앱 기동 완료
- work-widget-requirements.md의 B5 섹션

## 결과물

- 실제 트레이 아이콘 리소스
- electron-builder 또는 app.setLoginItemSettings로 Windows 시작프로그램 등록
- 데이터 자동 백업 로직

## 선행 작업

**P0** — 기본 스캐폴딩 완료 필수.

## 수행 순서에서의 위치

P0~P5의 기능이 충분히 구현된 후 진행. P7 내에는 3개의 하위 작업(P7.1~P7.3).

## done_when을 확인하는 방법
