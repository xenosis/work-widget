# P8.1 — electron-builder 설정 다듬기

## 목적

배포용 빌드에 필요한 메타데이터(앱 이름, 버전, 아이콘, 제조사 등)를 package.json의 build 섹션에 설정한다.

## 쉬운 설명

설치본을 만들 때 "앱 이름이 뭔가", "버전이 뭔가", "어떤 아이콘을 쓸 건가" 등을 지정해야 합니다. 이 정보들을 package.json에 적어두면, electron-builder가 그것을 기반으로 설치본을 만듭니다.

## 필요한 입력

- 앱 이름 ("work-widget")
- 버전 (예: "1.0.0")
- 아이콘 파일 경로
- 배포사 정보 (예: 회사명)

## 결과물

package.json의 build 섹션: appId, productName, files, directories, win (Windows 배포 설정), nsis (설치관리자 설정) 등

## 선행 작업

**P0.2** — package.json 작성 (기본 구조).
**P7.1** — 아이콘 이미지 준비.

## 수행 순서에서의 위치

P8 내에서 P8.1 → P8.2 순.
