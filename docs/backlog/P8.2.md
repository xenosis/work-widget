# P8.2 — 로컬 배포 빌드 테스트

## 목적

`npm run dist`로 생성한 실제 배포 설치본(.exe 인스톨러)을 설치하고 실행해서, P8.1(메타데이터와 아이콘), P7.1(트레이 아이콘), P7.2(자동 실행), P7.5(창 위치/크기 복원), 그리고 기본 CRUD 동작이 실제 설치 환경에서 모두 정상 작동하는지 최종 검증한다.

## 쉬운 설명

개발 중에는 `npm run dev`로 테스트하지만, 실제 사용자에게 전달할 설치본은 다르다. 설치본이 진정으로 설치되는 환경(진짜 Windows 로그인, 시작메뉴, 제거 목록 등)에서 제대로 작동하는지 마지막으로 확인한다. P7과 P8.1의 여러 기능이 "설치 후 실제로" 작동하는지도 한 번에 확인한다. 최종적으로 사용자가 PC를 재시작해서 로그인했을 때 위젯이 자동으로 뜨는 것을 직접 확인했으므로, 완전히 배포 준비가 완료되었다는 의미다.

## 필요한 입력

- P8.1(electron-builder 설정 다듬기) 완료: 앱 아이콘, 메타데이터(appId, author, productName, executableName)가 `package.json`에 설정, `electron/assets/app-icon.ico` 존재
- `npm run dist`가 성공적으로 실행될 수 있는 Windows 개발자 모드 또는 관리자 권한 환경 (심볼릭 링크 생성 가능)
- 실제 로그아웃/재로그인을 할 수 있는 Windows 환경
- P7.1, P7.2, P7.5의 코드 구현 완료 및 개발 모드 검증 완료
- 설치본에서 CRUD 기본 동작 테스트용 샘플 데이터 입력 권한

## 결과물

이 작업은 "최종 검증"이므로 새로 만들어지는 코드/파일은 없다. 다만:

- `npm run dist` 실행으로 생성되는 설치 파일: `out/work-widget Setup 1.0.0.exe`
- 실제 설치 후 생성/확인되는 파일들:
  - `Program Files/업무 위젯/` (또는 %LOCALAPPDATA%\Programs\work-widget\): 설치된 앱 파일들
  - `AppData/Local/work-widget/`:
    - `data.json` (실제 프로젝트/할일/일정/메모 데이터 저장)
    - `window-state.json` (창 위치/크기 상태)
    - `auto-launch-registered.flag` (자동 시작 등록 확인용 플래그)
    - `backups/data-YYYY-MM-DD.json` (일일 자동 백업본)
- 최종 검증 기록: backlog.json의 P8.2 log에 5개 항목 충족 기록

## 선행 작업

- **P8.1**(electron-builder 설정 다듬기): 완료 — 메타데이터와 아이콘이 설정되어야 `npm run dist`가 올바르게 진행되고, P8.2에서 이를 검증할 수 있음

## 수행 순서에서의 위치

P8(패키징/배포)의 최종 단계이자, 전체 위젯 개발의 최종 검증 단계다. P8.2가 완료되면 "개발 완료" 판정이 가능해진다. 또한 이 작업은 다음 세 작업의 "설치본 환경에서의 최종 검증"을 일괄 담당한다:
- **P7.1**(트레이 아이콘): 설치본의 트레이에 아이콘이 표시되는지 확인 — 완료됨
- **P7.2**(자동 실행): 실제 로그인 시 자동 실행되는지, API 설정이 올바른지 확인 — 최종 충족됨
- **P7.5**(창 위치/크기 복원): 종료 후 재실행 시 이전 상태가 복원되는지 확인 — 완료됨

P8.2가 완료됨으로써 backlog 전체(P0~P11.1, 70개 task) 완료.
