# P8.2 — 로컬 배포 빌드 테스트

## 목적

npm run dist를 실행해서 생성된 설치본으로 실제 설치/실행 테스트를 진행한다.

## 쉬운 설명

npm run dist를 실행하면 dist/out/ 같은 폴더에 .exe 또는 .msi 설치본이 생깁니다. 그 설치본을 실제로 다운로드/설치해서, 설치된 앱이 정상적으로 작동하는지 확인합니다.

## 필요한 입력

- P8.1 완료: package.json build 설정 완료
- npm run dist 명령 실행 (또는 npm run build 후 electron-builder 별도 실행)

## 결과물

- dist/out/ 폴더의 .exe 또는 .msi 설치본
- 설치 테스트 기록 (성공/실패 여부)

## 선행 작업

**P8.1** — electron-builder 설정 완료.

## 수행 순서에서의 위치

P8 내에서 P8.1 이후 최종 단계.

## done_when을 확인하는 방법

### 1단계: 빌드 및 패키징 실행
npm run build, npm run dist 실행

### 2단계: 빌드 성공 확인
- exit code가 0인가?
- 에러 메시지가 없는가?

### 3단계: 설치 프로그램 생성 확인
dist-electron/Work Widget Setup *.exe 파일이 존재하고 크기가 100MB 이상인가?

### 4단계: 설치 실행
- 생성된 .exe 파일을 실행
- "설치" 버튼을 클릭

### 5단계: 설치된 앱 실행 확인
- 앱 창이 뜨는가?
- 사이드바 메뉴가 표시되는가?
- 기본 기능들(화면 전환, 데이터 로드)이 작동하는가?

### 6단계: 제거 테스트
- Windows 설정에서 앱 제거 가능한가?
