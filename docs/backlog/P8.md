# P8 — 패키징/배포

## 목적

electron-builder를 최종 설정하고, Windows .exe 설치 프로그램을 생성해 실제로 동작하는지 검증한다.

## 쉬운 설명

개발 중엔 `npm run dev`로 실행하는데, 실제 배포를 위해서는 Windows .exe 설치 파일이 필요하다. electron-builder가 이를 자동화한다. P8은 설정을 마무리하고 생성된 설치 파일이 정말 잘 동작하는지 확인하는 phase다.

## 필요한 입력

- P0.7, P0.8 완료: vite build 성공, Electron 앱 기동 확인
- P7 완료(권장): 트레이 아이콘, 자동 백업 등 운영 기능 — deps에는 없으나 실제론 설치본에서 검증 시 필요

## 결과물

- `package.json`의 `build.files`, `build.directories`, `build.extraMetadata` 등 electron-builder 설정 완성
- `npm run dist` 실행으로 생성되는 `out/work-widget Setup 1.0.0.exe` (또는 해당 버전의 .exe)
- 설치 후 앱 동작 검증 완료
