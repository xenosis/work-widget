# P8 — 패키징/배포

## 목적

electron-builder를 사용해서 배포용 설치본을 생성하고, 로컬에서 테스트한다.

## 쉬운 설명

지금까지는 개발 모드(npm run dev)로 앱을 실행했습니다. 실제 사용자에게 배포하려면 설치 가능한 형태로 빌드해야 합니다. electron-builder가 자동으로 Windows 설치본(.exe, .msi)을 만들어줍니다.

## 필요한 입력

- P0.7 완료: vite build 성공
- package.json의 build 섹션 설정
- app 이름, 버전, 아이콘 등 메타데이터

## 결과물

- dist/out/ 폴더에 생성된 .exe 또는 .msi 설치본
- 배포 가능한 빌드

## 선행 작업

**P0.7** — vite build 성공.
**P0.8** — electron 앱 기동 테스트 완료.

## 수행 순서에서의 위치

P0~P7의 모든 기능이 충분히 구현된 후 진행. P8 내에는 2개의 하위 작업(P8.1~P8.2).

## done_when을 확인하는 방법
