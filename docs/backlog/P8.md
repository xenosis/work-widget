# P8 — 패키징/배포

## 목적

electron-builder를 최종 설정하고, Windows .exe 설치 프로그램을 생성해 실제로 동작하는지 검증한다. 설치 후 앱 메타데이터(이름, 게시자, 아이콘)가 Windows 설치 목록에 정확히 표시되고, 트레이 아이콘, 자동 시작, 백업 등 모든 배포 후 기능이 정상 작동함을 확인한다.

## 쉬운 설명

개발 중엔 `npm run dev`로 실행하는데, 실제 사용자가 설치할 수 있도록 Windows .exe 설치 파일이 필요하다. electron-builder가 이를 자동화한다. P8은 앱 아이콘과 메타데이터(게시자, 앱 이름)를 package.json에 정확히 설정하고(P8.1), 생성된 설치 파일을 실제로 설치해서 앱이 정말 잘 동작하는지 확인하는(P8.2) 최종 배포 준비 단계다.
